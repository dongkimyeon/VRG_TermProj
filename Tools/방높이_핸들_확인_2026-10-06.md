# 수동 방 천장 높이 핸들 직접 확인

XY 모서리 편집은 사용자 정상 보고를 반영했다. 신규 높이 실제 마우스/픽셀 렌더/OS 포커스는 미확인이다. 기존 도구 입력 실패를 반복하지 않았다.

1. L_Test 배치 모드에서 정상 확인한 수동 방을 적용하고 방 창을 닫는다. 방 범위 편집을 켜고 카메라를 비스듬한 측면으로 이동해 천장 중앙 점/수직 화살표와 천장 범위 선을 확인한다. 자동 모드에서는 편집이 막혀야 한다.
2. 천장 중앙 점을 위아래로 끌어본다. 높이만5cm 스냅으로 미리보기하고 XY/장비/실제 격자는 유지한다. 클릭만 하면 높이/기록이 변하지 않아야 한다. 높이를 읽는 바닥→천장 수직선과 계획Z 셀 수를 확인한다.
3. 유효 높이에 놓은 후 Ctrl+Z/Y로 이전/다음 높이를 복원한다. 미리보기 중에는 Undo/카메라/장비/XY 드래그가 막혀야 한다. Esc는 미확정만 취소하며 유휴 Esc는 편집 종료다.
4. 장비/쿨러/덕트보다 낮거나 자원 한도를 넘게 높여본다. 빨강/거절 이유가 나오고 놓아도 설정/기록은 유지돼야 한다. 위에서 거의 수직으로 내려보면 높이 드래그를 시작하지 않고 시선 안내를 표시해야 한다. 카메라 각도를 바꾸면 다시 시작할 수 있어야 한다.
5. 드래그 중 패치/Enter 전환·포커스 상실은 취소하고, 돌아온 뒤 기존 편집이 복귀해야 한다. 유휴 상태에서 숫자 창을 열면 핸들 모드는 닫힌다.
6. 확정한 높이를 `vrg.Layout.Save RoomHeight`로 저장하고 높이를 바꾼 뒤 `vrg.Layout.Load RoomHeight`한다. 높이/XY 복원·기록 초기화/핸들 종료를 확인한다. 다음 시뮬레이션 진입 때만 실제 격자가 적용된다. 콘솔은 `~`로 열고 닫는다.

보고 예: `방 높이 핸들 직접 확인: 표시/5cm/XY 유지/확정/거절/Esc/Undo·Redo/저장/입력 복귀 [정상 또는 실패 절차]`.
천장 범위 선은 미리보기 표시이며 천장 고체 판·외부 열 교환·플레넘·FPS는 구현/검증 범위가 아니다.
