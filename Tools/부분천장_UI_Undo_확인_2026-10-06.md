# 부분 천장 추가 UI·Undo/Redo 직접 확인

사용자가 부분 천장 UI·Undo/Redo 직접 절차 전체 정상으로 보고했다(2026-10-06). 해당 직접 확인 범위이며 AI의 새 캡처/로그/FPS 측정으로 확대하지 않는다. 기존 도구 실패는 반복하지 않았다. 아래 절차는 저장 연결 전 UI 확인 기록이며 새 저장 복원 확인은 별도다.

1. L_Test 배치 모드의 자동 방에서는 부분 천장 추가 버튼이 비활성인지 확인한다. 기존 방 설정에서 유효한 수동 방을 적용하면 버튼이 활성화되어야 한다.
2. ‘부분 천장 추가’를 열고 현재 방 안의 장비 없는 작은 XY 사각형과 판 높이를 입력한다. 높이는0보다 크고 방 천장보다 낮아야 한다. 고정 예제 좌표 대신 현재 방·장비에 맞춘다. 텍스트 변경/Enter만으로 판을 추가하지 않아야 한다.
3. ‘추가’를 누른다. 요청 XY/높이와 계산 최소/최대·두께·셀 수가 보여야 한다. 닫으면 청록색 요청 사각형과 주황색 계산 셀 상자가 보이고 장비 클릭·카메라가 정상 동작해야 한다. 실제 고체는 시뮬레이션 진입 전까지 유지한다.
4. 같은 창에서 높이0, 방 밖 범위, 장비/덕트를 막는 높이를 각각 시도한다. 이유가 보이고 판 목록·방·격자·기록이 바뀌지 않아야 한다. 계산 가능한 충돌 후보는 셀 범위/두께도 표시한다. Esc는 미확정 입력만 버리고 확정된 판은 유지한다.
5. 창을 닫고 Ctrl+Z로 추가 한 건을 취소, Ctrl+Y로 복원한다. 기록 복원도 현재 방/장비를 검증한다. 숫자 창이 열린 동안 Ctrl+Z/Y·장비/카메라 단축키가 실행되지 않아야 한다. 다음 시뮬레이션 진입에만 현재 목록의 판이 공기 고체로 적용된다.
6. 패치 진입/외부 모드 변경은 창을 닫고, 배치 복귀 후 다시 열 수 있어야 한다. 판 표시는 장비 선택을 가로막지 않아야 한다. 현재 저장 연결은 CLAUDE.md 최신 천장 저장 절을 따른다. 이 직접 보고는 새 저장/Load·새 실행 확인까지 포함하지 않는다.

보고 예: `부분 천장 UI·Undo 직접 확인: 버튼/입력/추가/거절/범위 표시/취소/Undo·Redo/입력 복귀 [정상 또는 실패 절차]`.
판 선택/삭제/드래그·판 저장·배기 구멍/유출·외부 열 교환/플레넘·FPS는 이번 범위 밖이다.
