# 소음 시뮬레이션 계획

작성일 2026-11-24

현재 상태는 N1 음원 계산 기반 구현·수치 검증 완료다. 사용자가 현재 브랜치에서 분기해 발표자료 39쪽의 소음 구상을 구체화하도록 요청했다. 작업 브랜치는 `codex/noise-simulation`이며 시작점은 `ba2836f`다. N0 자료 조사와 N1 독립 음원 계산 API·신규6종/관련11종 검증까지 완료했고 다음은 N2 실외 연결이다. 제품별 다중속도 실측 곡선 대조는 자료 후속으로 남아 있다. 조사 내용은 [N0 작업 기록](../docs/기록/10_소음.md)을 따른다.

## 1. 목표와 제안 범위

기존 냉각 시뮬레이션이 계산하는 장비 운전점과 배치를 입력받아, 사람이 있는 위치의 소음과 바깥 수신점의 소음을 계산한다. 다음 질문에 답하는 것을 목표로 한다.

- 랙 부하와 팬 회전수가 변할 때 어느 통로의 소음이 얼마나 달라지는가.
- 설비 팬 일부가 고장 나 나머지가 더 빨리 돌 때 냉각과 소음이 어떻게 함께 변하는가.
- 실외 장비의 위치·대수·운전 조건에 따라 부지 경계 수신점의 기여도가 어떻게 달라지는가.
- 동일한 시간 구간에서 온도·냉각 전력·소음이 어떻게 달라지는가.

첫 구현 순서는 자료가 확인된 실외 드라이쿨러 → 실내 랙·CRAH·CDU → 화면·리포트 연결로 제안한다. 실내와 실외는 각각 필요한 전달 모델을 갖는다. 공간 소음 지도와 수신점 시계열을 우선 산출물로 삼고, 실제 스피커로 팬 소리를 재생하는 기능은 후속 후보로 둔다.

## 2. 현재 코드에서 받을 수 있는 입력

| 대상 | 확인한 입력과 코드 | 소음 연결 전 보완할 부분 |
|---|---|---|
| 랙·스파인 장비 팬 | `Simulation/Thermal/RackThermalTypes.h`의 슬롯별 `SlotFanSpeedRatio`, 팬 전력과 전원·도킹 상태, `RackThermalModel.h`의 팬 운전점 | 실제 팬 또는 장비 전체의 음향 자료와 방사 위치·방향 연결 |
| 실외 FWS·CW 드라이쿨러 | `Simulation/Plant/DryCooler.h`의 60 Hz Liebert 940형 기준, `FacilityPlant.h`의 팬 비율·운전/고장 상태와 장비 telemetry | 설비 유닛 수와 유닛당 팬 수를 구분하고 실제 배치 위치 연결 |
| 칠러·트림 칠러 | `Simulation/Plant/Chiller.h`와 설비 운전 상태·부하 | 압축기와 팬 등 방사 부위별 자료, 부하별 음향 곡선 |

경로는 `Source/VRG_TermProj/` 기준이다. 위 값의 존재는 소음 모델 구현 완료를 뜻하지 않는다. N0에서 단위·집계 범위·runtime 상태를 코드와 대응시켰다. 실제 적용 시 사용할 truth API와 ID/위치, 제어 상태의 시점을 N0 작업 기록에 정리했다.

## 3. 음향 데이터와 출처 관리

### 3.1 기록할 필드

장비 형식·모델·주파수·정격 RPM/풍량/압력·운전 모드와 음향 값의 시험 조건을 함께 저장한다. 제조사 PDF의 판본·표·페이지·URL, 조사 날짜, 원자료 단위와 변환 과정도 기록한다.

- 음향 파워 레벨 `Lw`는 기준 `1e-12 W`, 음압 레벨 `Lp`는 기준 `20e-6 Pa`를 명시한다.
- 전체 장비, 단일 팬, 흡입/토출/케이싱별 값의 집계 범위를 표시한다.
- 옥타브 대역 파워와 A 보정된 총량 `LwA`를 구분한다. 대역별 자료가 있는 경우 그 자료를 우선 사용한다.
- 음압 자료에는 거리·측정면·방사 방향·반사 환경을 붙인다. 조건을 확인한 경우에만 전달 모델과 함께 역산한다.
- 제조사 정격, 다른 제품을 빌린 대체값, 추정 입력, 미확보를 표시한다. 미확보 음원의 기여는 누락 개수와 함께 보고하고 부분 합계임을 표시한다.
- 실제 정지한 음원의 선형 파워는 0이다. 자료 누락과 정지를 서로 다른 상태로 표현한다.

### 3.2 이번 조사에서 확인한 시작 자료

기존 드라이쿨러 코드와 같은 Vertiv Liebert 940, 60 Hz Standard 모델의 Table 2.1에 **장비 전체 `LwA = 97.4 dB`, 5 ft에서 `LpA = 81.5 dBA`, 팬 8개**가 있다. PDF 11쪽, 문서 표기 7쪽이다. 정격 음향 값과 측정거리부터 등록하고, 모델 내 유닛·팬 집계가 맞는지 확인한 뒤 적용한다. 50 Hz 표와 Quiet-Line 표는 별도 사양이다. [Vertiv Technical Design Manual, Table 2.1](https://www.vertiv.com/48ea08/globalassets/shared/liebert-air-cooled-direct-drive-drycoolers-technical-design-manual_00.pdf)

여러 음원으로 유닛을 분할하면 각 음원의 선형 파워 합이 원래 유닛 파워가 되게 분배한다. 동일한 팬 8개로 균등 분배하는 가정은 `Lw_fan = Lw_unit - 10 log10(8)`이다. 실제 팬별 차이는 자료를 확보해 교체한다. N0 코드 대조 결과 시나리오의 '24개'는 드라이쿨러 유닛 수다. 정격이 같은 유닛24대는 팬192개에 해당하며, 실제 음원 수는 runtime 유닛 집계에서 가져온다.

N0에서 대표 팬 음압·QM9700 소음·PCW 대역별 파워 후보·CDU 자료의 측정량 혼재·별도 칠러 제품 자료를 확인했다. 채택/추정/미확보 상태와 사용 조건은 N0 작업 기록을 따른다. 실내 장비의 실제 SKU별 음향 파워와 다중 운전점 자료는 후속 조사 항목이다.

## 4. 계산 모델

### 4.1 기본 단위와 합성

계산 내부는 m·s·Hz·W·Pa를 사용하며 기존 K 온도와 공통 `SimTime`을 따른다. 음향 파워는 전기입력·발열과 구별해 관리한다. LwA를 선형화한 값은 A 보정 등가 파워로 표시하며, 주파수 보정 전 음향 파워나 열 장부 입력으로 사용하지 않는다.

```text
SoundPowerW = 1e-12 * 10^(LwDb / 10)
MeanSquarePressurePa2 = (20e-6)^2 * 10^(LpDb / 10)
LpSumDb = 10 * log10(sum(MeanSquarePressurePa2) / (20e-6)^2)
```

독립적인 비상관 장비 소음은 평균제곱 음압을 합산한다. 동일 음원 둘은 `10 log10(2)`만큼 증가하는 해석 기준을 사용한다. A 보정은 각 대역에 한 번 적용한 뒤 에너지로 합산한다. 총 `LwA`만 있는 자료는 광대역 예비 계산에 사용하며 대역별 전달 결과와 구분한다. [OSHA Technical Manual, Noise](https://www.osha.gov/otm/section-3-health-hazards/chapter-5)

음원 없음은 선형 파워 0과 `NoSources`로 표현한다. 로그의 0, NaN, 무한대는 직렬화 전에 상태로 분리한다. 매우 큰/작은 값의 합산은 최대 레벨을 기준으로 스케일링해 수치 범위를 유지한다.

### 4.2 운전점과 소음의 연결

제조사의 RPM·풍량·압력·부하별 음향 곡선을 우선 보간한다. 동일 팬의 같은 시스템 곡선에서 속도를 바꿀 때 다음 관계를 후보로 사용한다.

```text
Lw2 = Lw1 + 50 * log10(Speed2 / Speed1)
```

이 관계의 적용 구간과 오차를 제조사 다중 운전점 자료로 검사한다. 실속, 극저속, 다른 팬·케이싱·압축기·펌프, 주파수 대역 이동은 따로 다룬다. 대역별 자료에 단순히 동일 보정을 더하는 근사는 추정 모델로 표시한다. [AMCA Basics of Fan Noise](https://www.amca.org/assets/resources/public/assets/uploads/FINAL-_AMCA_Fan_Noise_RG.pdf), [ebm-papst RadiPac & Radifit catalog](https://www.ebmpapst.com/content/dam/ebm-papst/loc/americas/us/local-literature/Product_Catalog_EC_centrifugal_fans_RadiPac_2_RadiFit_Edition_2023_10_.pdf)

실제 전원 차단·팬 고장·대기 장비 기동과 현재 회전수를 입력받는다. 고장 때 소음이 무조건 커지거나 작아진다고 정하지 않고, 남은 장비의 제어 결과를 다시 합산한다. 회전수만으로 설명되지 않는 모터·압축기 잔여 소음은 해당 구성요소 자료를 등록했을 때 함께 계산한다.

### 4.3 실외 전달

N2는 자유장 점음원의 거리 감쇠와 비상관 다중 음원 합성으로 시작한다.

```text
AdivDb = 20 * log10(DistanceM / 1 m) + 11
LpDb = LwDb + DirectivityDb - AdivDb
```

전구면·반구면 방사의 가정과 지향성을 명시한다. 지면 반사를 지향성과 별도 반사 경로 양쪽에 중복 적용하지 않는다. 큰 장비는 파워를 보존해 여러 위치로 분할하고, 음원 내부·근접 수신점에는 점음원식의 유효 범위를 표시한다. 거리 0을 임의로 1 m로 바꾸어 정상 결과처럼 표시하지 않는다.

N3에서 ISO 9613-2 계열의 대역별 전달로 확장한다. 입력에는 음원·수신점 높이, 외기 온도·상대습도, 지면 특성, 건물·차음벽과 반사/회절 경로를 포함한다. 부지 경계는 사용자 정의 선과 수신점 높이로 받는다. `Aatm`, `Agr`, `Abar` 등 실제 구현한 감쇠 항과 기상 조건을 리포트에 적는다. 공개 개요로 확인한 범위를 바탕으로 구현 항목을 정하고, 조항·시험 예제 대조가 필요한 부분은 조사 항목으로 남긴다. [ISO 9613-2:2024 공식 개요](https://www.iso.org/standard/74047.html)

주파수 자료가 없는 장비는 N2의 예비 결과와 자료 누락을 표시한다. N3에서 필요한 실제 대역 자료 또는 출처가 표시된 대체 스펙트럼을 확보해 계산한다. 현재 습도 물리는 없으므로 상대습도는 음향 모델의 환경 입력으로 기록한다.

### 4.4 실내 전달과 작업 위치

실내는 직접음과 방의 반사·흡음을 포함한다. 첫 모델 후보는 대역별 직접음 + 확산 잔향장이다.

```text
RoomConstantM2 = SurfaceAreaM2 * MeanAbsorption / (1 - MeanAbsorption)
LpBandDb = LwBandDb + 10 * log10((Directivity / (4*pi*DistanceM^2)
             + 4/RoomConstantM2) * 1 m^2)
```

흡음률은 면적 가중 대역값으로 입력한다. 재질 흡음률·개방면·부분 천장과 확산장 가정의 적합성을 N0/N4에서 조사한다. 방이 거의 무흡음이거나 복잡하게 구획됐을 때는 모델 적용 상태를 표시한다. 벽 너머 직접음에는 경로 판정을 적용하고, 잔향장은 연결 공간별로 계산한다. 랙 사이 차폐, 문·구멍 전달, 실내외 전달은 각각 모델 지원 범위를 적는다. [Arup Strutt Room Constant](https://strutt.arup.com/help/Building_Acoustics/RoomConstant.htm)

수신점은 작업 통로의 지정 높이와 선택 위치로 정의한다. 귀 높이는 조정 가능한 사용자 입력이며 초기 데모값을 정하면 추정으로 표시한다. 파장에 따른 회절·간섭·정재파와 구조 진동은 후속 확장 후보다. 기존 25 cm 공기 격자와 별도로 소음 수신점의 간격과 계산 범위를 설정한다.

### 4.5 시간 평균과 비교

```text
LAeqT = 10 * log10(sum(10^(LA_i/10) * Dt_i) / sum(Dt_i))
```

누적에는 공통 시뮬레이션 시간 구간을 사용한다. 일시정지 중에는 누적하지 않고 `R` 재시작과 새 실행에서는 이력을 초기화한다. 순간 소음 지도, 일정 위치의 `LAeq,T`, 계산 구간을 함께 저장한다. 이동 작업자의 노출량은 수신점 경로와 체류시간을 입력한 후속 기능으로 둔다. 법정 판정은 적용 지역·시간대·평가법이 정해졌을 때 별도로 검토한다.

## 5. 코드 연결과 산출물 제안

아래 구조는 계획이다. N1의 `Simulation/Acoustics/NoiseSource.h/.cpp`와 독립 계산 API를 구현했으며 게임 수집·진단 명령·표시·웹 API는 이후 단계다.

- `Simulation/Acoustics/`에 일반 C++ 음원 데이터, 운전점 보정, 전파·수신점 계산을 둔다. 액터는 값 스냅샷과 m 단위 위치를 넘긴다.
- 음원은 장비 ID·구성요소·실제 위치·방향·회전수·활성 상태·자료 출처를 갖는다. 자동 배치와 실제 액터의 이중 등록을 검사한다.
- `Tick`과 `DrainWarmupSteps`의 동일한 완료 스텝 경로에서 음원 상태를 수집한다. 소음 누적은 매 구간의 상태와 dt를 반영하고, 지도 표시는 그 스냅샷을 읽는다.
- 위치·벽·수신점이 바뀔 때 전달 계수를 갱신하고, 운전 중에는 음원 파워와 가중 합을 갱신하는 구조를 먼저 측정한다. 워커에는 UObject 대신 배열 값을 전달한다.
- 게임·웹·리포트는 같은 결과 스냅샷을 사용한다. 범례에 `LpA dB`, 수신점 높이, 시간 구간, 적용 모델, 미확보 음원 개수를 표시한다.
- A/B에는 냉각 온도·IT·냉각 전력과 함께 같은 위치·같은 시각 구간의 소음을 넣는다. 배치 변경 시 수신점은 같은 세계 좌표 또는 명시적인 대응점을 사용한다.
- 진단 명령 후보는 `vrg.Noise.Status`, `vrg.Noise.Show`, `vrg.Noise.Probe`, 웹 경로 후보는 `/api/noise`다. 매개변수는 구현 단계에서 정한다.
- 저장은 음향 설정·출처·수신점·부지 경계를 대상으로 하며 이전 v2 배치 파일의 새 필드 누락을 허용한다. 실행 중 누적 상태는 리포트에 둔다.

## 7. 검증 문제와 타당성 확인

| 검사 | 대조할 값·단위 |
|---|---|
| dB 왕복·무음·자료 누락 | 파워 W/평균제곱 음압 Pa² 왕복, 누락과 0 상태, NaN/무한대·잘못된 기준값 거절 |
| 같은 비상관 음원 2개·10개 | 각각 `10 log10(2)`와 `10 dB` 증가 |
| 자유장 같은 음원 거리 2배 | `20 log10(2) dB` 감소. 실내 잔향 포함 문제는 별도 기준 사용 |
| 동일 팬 회전수 반감 | 채택한 근사에서 `50 log10(0.5) dB`, 제조사 다른 운전점과 대조 |
| 유닛 음원 분할 | 부분 선형 파워 합/전체 파워, 무차원. 팬 수를 두 번 곱하는 결함 검사 |
| 실외 경로 | 항별 손계산·독립 예제의 수신점 dB 차, 대역 합성/A 보정 단일 적용 |
| 실내 흡음·차폐 | 방 상수 m², 같은 조건 흡음 변화·직접 경로 차단, 서로 다른 공간의 잔향 분리 |
| 시간 평균 | 일정 소음은 같은 LAeq, 두 소음 구간의 에너지 가중 해석값, 벽시계 배속 변화와 무관한 같은 SimTime 결과 |
| 단일·병렬·재실행 | 같은 입력 수신점 dB/선형 파워 차, 순서 변경과 종료·다시 시작. 동시성은 별도 점검 |
| 결합 회귀 | 소음 수집 켬/끔의 열 J·물 m³·압력 Pa·온도 K·운전점 차와 기존 허용 기준 |
| 표시와 보정 | 모델 스냅샷=웹/리포트, 제조사 시험 조건의 재현. 현장 측정이 생기면 위치·배경소음·기기 조건까지 기록 |

제조사의 근거리 음압 표는 장비 크기·방향과 시험 환경을 확인해 검증한다. `LwA=97.4 dB`에서 자유장식으로 1.5 m 음압을 계산한 값을 무조건 81.5 dBA와 일치시키는 보정은 하지 않는다. 합성·거리 식을 통과한 사실과 실제 장비/공간의 예측 정확도는 각각 기록한다.

## 8. 시연 시나리오

1. 정상 → IT 부하 변경 → 랙 팬 제어 변화 → 통로 수신점·온도·팬 전력 비교.
2. 드라이쿨러 일부 고장 → 남은 장비 속도와 기여도 합산 → 부지 수신점/공급 수온 비교.
3. 폭염 또는 `heatwave` → 실제 팬·칠러 상태 변화 → 냉각·소음 시계열. 팬 정지와 압축기 기여도는 각각 표시.
4. 같은 장비·부하에서 마당 배치 변경 → 고정된 경계 수신점 비교.
5. 흡음·차음 변경 → 동일 수신점 비교. 적용 모델과 대역 자료 상태를 표시.

모든 시나리오는 기존 냉각·전원 상태에서 소음을 계산한다. 총음압 증감의 방향과 발생 시각은 결과로 확인한다.
