# 부분 천장 전체 XY 이동 직접 확인

기존 높이 핸들은 사용자 정상 보고다. 아래 신규 판 내부 드래그의 실제 마우스/화면/OS 포커스는 NullRHI 검사와 별개이며 직접 확인이 필요하다. FPS는 측정하지 않는다.

1. L_Test 배치 모드에서 기존 정상 확인한 수동 방/판을 준비한다. 초기 배치 시험 예: 방 X[-4,10], Y[-3,8], 높이3.75m / 판 X[-3.75,-3.25], Y[-2.75,-2.25], 높이3.0m. 시험 기하이며 시설 규격/기본값이 아니다. 현재 장비와 겹치면 빈 곳에 판을 준비한다.
2. 숫자 창·패치·방 범위 편집을 닫고 ‘천장 선택·삭제’를 켠다. 판 상자 내부를 클릭 후 놓으면 선택만 된다. 높이/XY는 바뀌지 않고 Undo 기록이 늘지 않아야 한다. 빈 곳 클릭은 선택 해제다.
3. 카메라를 판 위에서 비스듬히 아래를 보도록 옮기고 확대한다. 초록 모서리 네 점/중앙 높이 점에서 떨어진 판 내부를 누른 채4px 이상 드래그한다. 판 전체가 같은 XY 변위로 움직이고 가로·세로 크기와 높이는 유지돼야 한다. 최초 누른 점의 오프셋은 유지하며, 최소 XY 기준점이5cm 격자로 스냅한다. 미리보기 중 기존 확정 판/장비는 원래 위치에 남는다.
4. 요청 XY·높이, 실제 계산 범위/두께/셀 수가 안내에 나오고 유효 후보는 앞쪽 굵은 주황 선이어야 한다. 손을 놓으면 한 장만 확정된다. Ctrl+Z/Y로 이전/이동 위치를 복원한다. 기록 복원 뒤 선택이 해제되므로 다시 클릭해 선택한다.
5. 모서리 점을 드래그하면 반대 모서리를 고정한 크기 편집, 중앙 점을 드래그하면 XY를 고정한 높이 편집이어야 한다. 핸들의 시선 계산이 거절돼도 판 전체 이동으로 대신 시작하면 안 된다.
6. 전체 이동 중 방 밖 또는 장비/CRAH/덕트와 겹치는 곳으로 가져가면 빨강과 이유가 나타난다. 놓아도 원래 판이어야 한다. 취소/거절은 기록을 늘리지 않는다. 교점 계산이 불능이면 임의로 이동/확정되지 않아야 한다.
7. 드래그 중 Delete·Ctrl+Z/Y·장비/카메라 조작이 차단되는지 확인한다. Esc 한 번은 이동만 취소하고 천장 편집 유지, 유휴 Esc는 편집 종료다. 종료 뒤 일반 장비/카메라 조작이 복구돼야 한다.
8. 이동 중 숫자 창/패치를 열거나 모드를 바꾸거나 포커스를 다른 창으로 옮기면 미확정 이동이 취소돼야 한다. 다음 시뮬레이션 진입에는 확정된 목록만 실제 고체 셀로 반영된다.
9. 확정 뒤 콘솔(~)에서 `vrg.Layout.Save CeilingMoveCheck` → 판 위치 변경 → `vrg.Layout.Load CeilingMoveCheck`를 실행한다. 저장된 위치/크기/높이, 편집·선택 종료와 기록 초기화를 확인한다. 새 실행에서도 같은 Load로 복원되는지 확인한다. Save는 미리보기를 저장하지 않는다.
10. 같은 기하의 판 두 장을 준비해 한 장을 이동한다. 원래 위치에 다른 한 장의 선이 남고, 이동한 판은 새 위치에 표시돼야 한다. 같은 거리의 중복 판은 기존처럼 첫 목록 항목이 선택된다.

보고 예: `부분 천장 전체 XY 이동 직접 확인 결과: [정상]` 또는 실패 단계와 예상/실제 동작. 이동 시 계산 셀 수는 요청 크기가 같아도 셀 경계와의 정렬에 따라 달라질 수 있다. 기존 실패 화면 도구는 재시도하지 않는다.
