# 벽면 CRAH 추가 직접 확인 (2026-10-06)
현재 결과: Editor 빌드 성공, 영향받은 고유11종 최종 무경고 성공. 같은/새 월드 Load·자동/실제 추가·중간 실패 원복·포트/열수지/압력은 Automation 확인(정량·단위 CLAUDE.md 최신 절).
실제 화면 확인: 배치 버튼/시뮬레이션 숨김, 주황 미리보기·R·Esc, 빈 곳 클릭 생성·Ctrl+Z/Y, 동일 위치 빨강·클릭 거절, Enter 전환 취소. 마지막 Undo로 원래 배치 복귀. Alt+Print Screen PNG는 Saved/PerimeterCrahAddition_*.png(커밋 제외). FPS 미측정.
남은 직접 확인만: 미리보기 중 패치 창 진입→취소, 이미 실제 쿨러인 상태에서 한 대 더 추가→Undo/Redo, 저장 버튼→같은 파일 반복 Load→새 L_Test Load. 장비 수/종류 유지·중복 없음·Load 뒤 Ctrl+Z로 이전 기록이 실행되지 않는지 확인한다. 아래 전체 절차는 참고용이며 이미 확인한 항목을 반복할 필요 없다.

1. L_Test 배치 모드에서만 벽면 CRAH 추가 버튼이 보이는지 확인한다. 기존 인로우 버튼도 유지되어야 한다.
2. 벽면 버튼→커서 미리보기→R90°→Esc: 실제 장비/자동 전환은 없어야 한다. 기존 장비/자동 쿨러와 중첩하면 빨강·클릭 거절이어야 한다.
3. 빈 곳 클릭: 벽면형 한 대와 필요한 기존 자동 전환만 생성된다. 기존 쿨러는 종류·위치 그대로 유지되어야 한다. 벽에 자동 부착하지 않는다.
4. Ctrl+Z/Y로 전환+추가를 한 번에 취소/복원한다. 이미 실제 쿨러가 있으면 새 한 대만 취소/복원한다. 패치/모드 전환은 미확정 미리보기를 취소해야 한다.
5. 저장 후 같은 파일을 두 번 Load, 새 L_Test에서도 두 번 Load: 종류·설정·변환/출처 유지·중복 없음·과거 Undo/Redo 기록 초기화를 확인한다.

드라이버 안내는 아니오. 화면 기록은 Alt+Print Screen → 클립보드 PNG 저장 → 이미지 확인. 같은 도구 실패/기존 캡처 API는 반복하지 않는다. 정량 열수지/압력·포트 유량은 자동화 검사 범위이며 화면으로 정상상태/FPS를 판정하지 않는다.
