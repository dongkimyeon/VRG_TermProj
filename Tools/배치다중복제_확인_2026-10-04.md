# 다중 랙 복제 확인 (2026-10-04)

복제 시작 시 모든 선택이 랙인지 확인하고 원본별 설정/전체 변환의 값만 보관한다. 첫 선택 랙을 기준으로5cm 스냅한 XY 평행 이동을 적용하고 상대 위치·높이·방향·스케일을 유지한다. 그룹 미리보기 R은 차단한다. 실제 랙/배관 생성은 전체 충돌 검사를 통과한 클릭 확정 때만 한다.

확정/Undo/Redo는 기존 다중 생명주기 검증·원복·재구축을 재사용한다. 원본별 설정을 가진 네이티브 랙에 새 ID/이름을 부여한다. 원본의 온도·적분·시계·참조를 복사하지 않는다. Blueprint 사용자 정의 상태 복제는 지원하지 않는다.

Editor64.21s 성공. 그룹 복제/단일 복제 미리보기/랙 생명주기3건 성공(기존 단일 fixture의 축 근사 경고2 유지). 그룹 위치오차0cm, 랙2→4→2→4와 한 기록, 설정/배열 독립·원본 불변·새 모델 시계/누적 입력 에너지0 확인. 둘째 충돌·혼합 선택 및 둘째 생성 액터 파괴 주입에서 전체 거절/부분 생성 제거·원본 선택/스택 불변을 검사했다. 공유 Spawn에 deferred 생성/FinishSpawning 후 유효성 검사를 추가했다.

목적지 상자 표시에서 기존 스케일 누락을 확인해 실제 스케일을 반영했다. 충돌 판정이나 장비 크기/변환은 변경하지 않았다. 단일 복제 R과 기존 추가 동작은 유지한다.

물리·저장 검증 및 단일 복제 실제 화면 회귀는 최종 빌드 뒤 기록한다. 전체 테스트/FPS는 이번 범위 밖이다. 로그/리포트는 `Saved/Build_RackGroupDuplication.log`, `Saved/Logs/RackGroupDuplication_Tests.log`, `Saved/Automation/RackGroupDuplication`이며 커밋하지 않는다.

## 직접 확인 절차

현재 API는 Shift 유지+클릭 옵션이 없고 이전 사각형/드래그 입력도 실패했다. 같은 실패를 반복하지 않는다. 자동화 호출을 실제 그룹 UI 확인으로 계산하지 않는다.

1. 배치 모드에서 서로 다른 설정의 기존/추가 랙 두 대를 Shift+클릭하고 Ctrl+D를 누른다.
2. 원본과 겹치면 두 목적지 모두 빨강이며 클릭해도 생성되지 않아야 한다. 빈 곳에서는 두 주황 상자의 상대 위치와 높이/방향/스케일을 확인한다.
3. 그룹 미리보기에서 R은 방향을 바꾸지 않고, Esc는 생성 없이 취소해야 한다. 패치 열기/모드 전환도 취소해야 한다.
4. 다시 Ctrl+D 후 유효 위치를 클릭하면 두 랙/분기가 함께 생긴다. Ctrl+Z/Y로 함께 제거/복원되는지 확인한다.
5. 랙+CDU를 함께 선택하면 Ctrl+D가 거절돼야 한다. 단일 랙 복제 R은 계속 작동해야 한다.
6. 복제한 상태를 저장하고 불러오면 전체 랙이 복원되고 반복 불러오기에서 중복이 없어야 한다. 불러오기 뒤 Ctrl+Z는 기록 없음으로 거절돼야 한다.

임의 Blueprint 콜백의 외부 부작용과 자원 고갈로 원복까지 실패하는 상황은 검증하지 않았다. 기존 다중 생명주기의 원복 한계는 CLAUDE.md를 따른다.
