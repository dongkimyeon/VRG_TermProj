## 슬롯 전원 기반

`FRackThermalInput.SlotPowered`는 runtime C++ 입력이다. 빈 배열은 기존 전체 전원 켬 동작, 비어 있지 않으면 정확한 슬롯 수가 필요하다. 잘못된 길이는 StepInternal에서 상태/장부 변경 전에 거절한다. `SlotPoweredOf`/`IsSlotPowerInputValid`로 같은 규칙을 사용한다. SledDocked와 구분하며 도킹·기하·밸브·배관 번호를 변경하지 않는다.

꺼진 슬롯은 부품 전기 발열·팬 전기입력·강제 공기 유량0이며 팬 override로 우회되지 않는다. 저장 열·열용량·냉각수 접촉은 유지한다. 전원 차단을 탈착으로 구현하지 않았으므로 콜드플레이트 잔열 냉각과 자연대류를 계속 계산한다. 기존 coupling의 슬롯 유량/열원 판독 경로를 그대로 사용한다.

살아 있는 DC 부하 합계에 기존 LossFractionOfRackLoad를 적용하므로 컴퓨트 차단은 관련 PSU 변환 손실을 줄인다. 꺼진 전원 셸프 자신의 팬/손실도0이다. **셸프 간 손실 재분담·전력 여유/용량·배전 회로·셸프에서 다른 슬롯으로의 연쇄 차단은 이번에 모델링하지 않는다.** 기존 고정 분율을 유지하므로 공급 셸프가 꺼진 상황의 실제 총효율/공급 가능성을 검증한 것으로 해석하면 안 된다.

Actor.ResetSim은 슬롯 전원을 켬으로 초기화하고 도킹 상태는 유지한다. 입력 배열은 UPROPERTY/UI/저장 필드에 추가하지 않으며 CaptureLayoutSettings의 상태 복사 범위를 확장하지 않는다. Pause/Resume나 구멍 수리에는 전원 복구를 연결하지 않는다.

## 실제 물 관측 → 랙 슬롯 차단

`ConfigureWaterImpactObservation`은 기존 읽기 전용 API로 유지한다. 실제 차단은 C++ `ConfigureRackWaterTripResponse(Policy, OtherPowered, Reason)`로 따로 명시한다. 운영 정책은 자동 제공하지 않으며 기본 미설정/실제 차단 비활성 상태를 유지한다. OtherPowered는 기존 전체 관측 대상 순서의 명시적 입력이고, native 랙 슬롯은 실제 SlotPowered AND 도킹 연결 여부로 대체한다. 미정인 다른 장비 통전을 발열/탈착에서 추정하지 않는다.

공통 Tick/RunSteps의 EvalBeforeStep 이후, 수력/열/물 적분 **전** `RackWaterPowerBeforeStep`을 호출한다. 이전 물 endpoint에서 확정된 Tripped/Damaged 중 native 슬롯만 골라 전원을 끈다. 랙 전체 상자나 미분류 분사만으로 전체 랙을 끄지 않는다. 다른 슬롯·CDU·CRAH·스파인 입력은 바꾸지 않는다.

모든 weak 참조·ID/변환/슬롯 기하·전원 입력을 먼저 검증하고, 현재 관측 시각의 전원 동기화를 임시 상태 모델에서 확인한 뒤 전원과 장부를 확정한다. stale/불량 자료는 freshness=false/이유를 남기고 부분 차단하지 않는다. 기존 단계에서 이미 꺼진 슬롯은 그대로 유지하고 중복 차단 사건을 추가하지 않는다.

공통 SimTime으로 TripTimeS(시간 문턱 교차)·ObservedTimeS(물 endpoint에서 확정)·AppliedTimeS(다음 적분 시작)를 기록한다. 현재 dt 안에서 발생한 전이는 다음 endpoint 이후 적분에만 적용하므로 소급 전력/열 장부를 다시 쓰지 않는다. 이번 측정은 판정→적용5ms, 기존 dt20ms의0.25였다. 관측→적용 시뮬레이션 시간차는0이며 실제 물리 결과는 그 이후 스텝부터 바뀐다. 이를 substep 안의 즉시 전기 차단으로 표현하지 않는다.

`FWaterImpactModel.SetPowerAtCurrentTime`은 이미 관측한 시각과 정확히 같은 시각에서 통전 비트만 갱신한다. 시계/물 이력/사건은 진행하지 않는다. 이 경계 동기화 뒤 기존 hold 방식으로 다음 구간을 판독하므로 전원이 꺼진 과거 구간을 통전 상태로 잘못 적분하지 않는다. 일반 외부 관측 갱신 API의 기존 endpoint 의미는 유지한다.

구멍 수리로 복구하지 않는다. 입력 전원은 꺼진 채 잔열 냉각과 실제 물 이동/손상 판독을 계속한다. 새 실행의 Rack.ResetSim은 전원을 초기화하고, 새 물 레지스트리는 정책/차단 사건/응답 활성화를 지운다. 단순 정책 재설정이나 배치 모드 전환으로 꺼진 입력을 임의로 켜지 않는다. 물 소스 없는 실행 중 결합 재구축은 기존 재진입 진단을 유지한다.
