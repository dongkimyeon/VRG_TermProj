## 전원 기반과 장부

`ACoolingDistributionUnitActor.SetPumpPowered`는 저장하지 않는 실행 중 전기 명령이다. 속도 명령·장비 존재·밸브와 구분한다. Room 공통 재고 스텝에서 기존 행/CDU 배정대로 망의 전원 상태를 동기화하고 dirty 재풀이한다. 망/번호를 다시 만들거나 유량을 직접 쓰지 않는다. CDU/HX/재고가 남으므로 무CDU 라디에이터 대체를 켜지 않는다. 새 실행은 native CDU 전원과 기존 재고 초기화를 복원한다.

정지는 기존 펌프 곡선의 능동 양정 항만0으로 만든다. 속도 설정과 `-CurveCoeff * Flow * abs(Flow)`는 유지해 외부 압력에 따른 정방향/역류를 풀 수 있다. 이는 기존 속도0 곡선의 재사용이며 **정지 임펠러의 실제 저항을 보정한 모델은 아니다**. 공개 펌프 근거는 CLAUDE D8/기존 참고값을 재사용했고 새 계수/체크밸브·물성/고장 문턱은 도입하지 않았다. 정지 저항의 기존 곡선 연장은 미보정 근사로 남긴다.

정지 전기입력은0이다. 외부 압력의 수동 손실을 발전으로 세지 않는다. 기존 설비 활성 경로의 CDU 펌프 열은 같은 getter로0이 되며, 설비 비활성 모드에 없던 펌프 열이나 손실 열 분배를 새로 추가하지 않는다.

## 명시적 응답과 시계

- `ConfigureCduWaterTripResponse(Policy, OtherPowered, Reason, bIncludeRackResponse=false)`로 정책과 CDU 응답을 명시적으로 설정한다. 마지막 인자true는 같은 정책/기준에서 랙 응답도 함께 활성화한다.
- 기존 `ConfigureRackWaterTripResponse`는 랙만, `ConfigureWaterImpactObservation`은 읽기 전용이다. 설정 API는 새 정책/기준을 구성하며 단순 enable 토글이 아니다. 운영 정책은 기본 미설정/응답 비활성이다.
- 실제 native CDU 루트의 기존 W2/W3 자료와 실제 전원 명령을 관측한다. 구멍 열림으로 노출/전이를 만들지 않는다. stale ID/변환/장비 매핑은 기존 진단으로 거절한다.
- 랙/CDU 후보 상태를 함께 사전 검증한 뒤 다음 공통 스텝 시작에 적용한다. Room 수력 재풀이→기존 열/공기 결합 순서는 Tick/RunSteps가 공유한다.
- `FWaterCduPowerCut`은 TripTimeS(문턱 교차), ObservedTimeS(물 endpoint 확정), AppliedTimeS(다음 적분 시작)를 기록한다. 현 endpoint의 실제 통전 비트만 동기화하고 과거 열/물 장부를 소급하지 않는다.
- 수리로 재통전하지 않으며 새 실행은 전원·정책·사건/기준을 초기화한다. 기존 랙 응답/관측을 유지하고 다른 장비를 제어하지 않는다.

## 확인한 실패와 해결

1. 첫 컴파일의 CDU 전방 선언 누락과 시험 코드 정리 중 중괄호 누락은 각각 수정했다. 빌드 중 소스는 변경하지 않았다.
2. 첫 외부 압력 정지 시험은0 초기 유량에서 Newton 스텝을 거절했다. 같은 수동 곡선/압력 seed로 부호 있는 초기추측을 구하도록 보완했다. 해석 유량을 실제 해로 지정하지 않는다.
3. 실제 분사 원점이 다른 장비 내부여서 그 장비에 물이 흡수됐고, 뒤에는 대상 CDU가 기존 물 도메인 밖이었다. 제품의 충돌/경계를 완화하지 않고 장비 밖 실제 W1 지점과 도메인 안 시험 배치로 수정했다. 기존 auto-fit의 CDU 포함 범위를 확장하지 않았다.
4. 설비 공급수가 초기 냉각수보다 따뜻한데 “정지하면 정상보다 즉시 더 뜨거워야 함”을 가정한 시험을 수정했다. 부호 있는 정상 대비 차이와 초기값 대비 열 축적을 각각 검사한다. 온도를 강제하거나 허용치를 바꾸지 않았다.
5. **종료 시점 통과를 선언한 뒤 로그 대조에서 누수 중 수력 실패364회를 발견했다.** 수리 후 수렴해서 종료 시점 검사가 놓쳤다. 완료를 보류하고 매 공통 스텝 검사·첫 실패 중단·worst node/배관 진단을 추가했다.
6. 직전 수렴점 재사용만으로는 해결되지 않아 그 후보는 되돌렸다. 전원 변경은 첫 기반처럼 기존 초기추측을 무효화한다. worst node130의 질량 오차2.898e-6m³/s, 배관 Δp1.845e-5Pa에서 Jacobian floor1e-3Pa가 지배했다. 정지 펌프가 있는 경우 비영 압력차는 정확한 기존 도함수,0/분해 불가능 차압은 기존 정규화를 사용했다. 질량 오차2.431e-12m³/s/정규화7.152e-10까지 개선됐지만 기존1e-10에 미달했다.
7. 큰 충전 압력187366Pa끼리 빼며 작은 차압의 반올림 한계에 도달했다. 정지 펌프가 있는 **연결 성분만**, 고정 노드 평균 피에조 압력에 대한 상대 double 좌표로 풀도록 보완했다. 정상 성분은 기존 static 좌표다. 같은 Newton/LU·미지수 개수·double·방정식·수렴 기준/반복 예산을 유지한다. 위상/밸브/경계 변경과 재시작 때 그래프에서 datum을 갱신하고 외부 getter/누수 오리피스는 기존 gauge Pa로 환산한다. 두 수를 더 정밀한 타입으로 바꾼 것이 아니라 기준 좌표를 이동한 것이다.

큰 gauge 값의 출력끼리 다시 빼면 작은 차압 정보가 일부 반올림될 수 있다. 내부/계측 계산은 `PiezometricDropPa`·`GetPipeFlowM3s`·`GetPumpDeltaPPa`를 사용하며, 화면/웹 gauge 숫자를 빼서 작은 차압을 재계산하지 않는다. 이 출력 의미는 단위 변경이 아니다.
