# 방 설정 UI·Undo/Redo 직접 확인

구현/영향 Automation 8종은 성공했다. L_Test 실행과 배치 전용 방 설정 버튼 표시는 Alt+Print Screen으로 확인했다. 도구 클릭 실패로 남았던 아래 절차는 사용자가 2026-10-06 직접 정상 확인했다고 보고했다. 사용자 보고를 로그/캡처/FPS 측정으로 확대하지 않는다. 같은 도구 실패/캡처 API를 반복하지 않았다.

1. L_Test를 실행하고 배치 모드에서 `방 설정 (m)`을 누른다. 드라이버 안내가 뜨면 아니오로 진행한다. 자동 맞춤이면 숫자 칸은 비활성이다.
2. 수동 방을 체크하고 XY 최소/최대·천장을 m로 입력한다. 처음 값은 현재 격자를 참고한 초안이며 장비/자동 CRAH·덕트 포함 검증을 반드시 거친다. 특정 테스트의 합성 좌표를 L_Test 규격으로 복사하지 않는다.
3. 적용 전에는 기존 방/장비/격자가 유지되는지 확인한다. 천장0 또는 잘못된 숫자를 적용하면 빨간 이유가 나오고 설정은 유지돼야 한다. 값 수정 후 필요한 모든 영역을 포함하는 방을 적용하면 실제 계획 최소/최대·셀 수/h가 표시돼야 한다. 축128셀을 넘으면 거절되므로 이유에 따라 조정한다.
4. 숫자 칸에 포커스가 있을 때 W/R/G/T/D/Delete/Enter를 입력해도 장비 조작·카메라·시뮬레이션 전환이 실행되지 않아야 한다. 문자 때문에 숫자가 잘못됐으면 적용만 거절된다. 숫자 칸의 Ctrl+Z/Y는 텍스트 편집이며 세계 배치 기록과 구분한다.
5. 적용 후 값을 다시 수정하고 Esc로 닫는다. 미확정 초안은 버리고 마지막 적용은 유지돼야 한다. 다시 열어 확인하고 닫기 버튼도 확인한다. 닫은 뒤 장비 선택과 우클릭 카메라가 정상 복귀해야 한다.
6. 창을 닫은 상태에서 Ctrl+Z로 이전 방 설정, Ctrl+Y로 적용 설정을 복원한다. 창을 다시 열어 모드/숫자/계획을 확인한다. 같은 값 재적용/잘못된 적용/초안 종료는 새 기록을 만들지 않는다. 새 유효 설정을 적용하면 기존 Redo가 비워진다.
7. 창을 닫고 시뮬레이션에 진입하면 계획한 실제 격자가 적용돼야 한다. 배치로 돌아와도 기록을 유지한다. 현재 장비를 포함할 수 없는 설정으로 Undo/Redo하면 거절 이유를 표시하고 설정/기록을 유지해야 한다(자동화에서는 확인 완료).

저장 제한: 방 설정은 이번 저장 형식에 추가하지 않았다. 기존 Load는 현 실행의 방 설정을 유지하고 장비/방 Undo/Redo 기록을 모두 비운다. 새로 실행한 월드는 방을 별도로 설정하지 않으면 자동 맞춤이다.

보고 예: `방 설정 직접 확인: 창/입력/적용·거절/계획/Esc·닫기/포커스/Ctrl+Z·Y/모드 전환 [정상 또는 실패 절차]`.
기존 격자/열수지·타당성 기준과 실제 빌드/검사 결과는 CLAUDE.md 최신 방 설정 절을 따른다. 화면만으로 수치 보존이나 시설 전체 정확도를 판정하지 않는다.
