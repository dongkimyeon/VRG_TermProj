# 스파인 단일 복제 직접 확인 (2026-10-05)

이번 Ctrl+D 복제 실제 UI는 미검증이다. 기존 클릭 도구의 `coordinate input geometry is unavailable` 오류에 환경 변화 근거가 없어 반복하지 않았다. 이전 스파인 삭제 절차의 사용자 정상 보고는 새 복제 확인으로 확대하지 않는다. 드라이버 안내는 아니오로 진행한다.

## 직접 절차

1. L_Test 배치 모드에서 콘솔 `vrg.Layout.Save spine_before_clone`으로 원배치를 보관하고 콘솔을 닫는다. 기존 스파인 한 대 선택 → Ctrl+D. 원본은 그대로 있고 목적지 상자만 커서를 따라야 한다. 원본과 겹치면 빨강/클릭 거절, 빈 목적지는 주황이어야 한다.
2. R로 미리보기만 90° 회전하고 Esc로 취소한다. 원본과 장비 개수는 그대로여야 한다. 다시 복제를 시작해 빈 위치를 클릭하면 한 대만 추가되고 원본의 스위치/슬롯 설정·높이·스케일을 유지해야 한다. 방향은 미리보기 R 결과를 따른다.
3. Ctrl+Z로 복제만 제거, Ctrl+Y로 같은 설정·위치의 복제 한 대를 복원한다. 제거 후 다른 장비를 복원 위치에 옮기면 Redo는 전체 거절되어야 한다. 그 장비를 비킨 후 재시도하면 복원되어야 한다.
4. 실행 중 추가한 스파인에서도 Ctrl+D → Esc 및 클릭 확정 → Undo/Redo를 확인한다. 미선택/스파인 다중/랙+스파인 혼합 선택, 편집·패치 창·시뮬레이션 중에는 새 복제를 시작하지 않아야 한다. 복제 미리보기 도중 패치 창/시뮬레이션 진입은 미리보기를 취소해야 한다.
5. 기존 패치 배정 조건에 맞는 줄 옆에 복제하고 케이블/패치 장비 반영을 확인한다. 각 줄의 스파인 배정 순서에 따라 추가 스파인이 실제 케이블을 받지 않을 수 있다. 기존 미연결 진단을 숨기면 안 된다. 냉각수 배관은 추가하지 않는다.
6. `vrg.Layout.Save spine_cloned`로 저장한다. 원배치 Load → 복제 파일 Load → 같은 파일 재Load 및 새 L_Test 실행에서 Load해 원본/복제 유지·중복 없음·이전 Undo/Redo 초기화를 확인한다. 완료 후 원배치를 Load한다. 임시 파일은 Saved/Layouts에 있으며 레벨 에셋은 변경하지 않는다.

결과는 기존/추가 원본, 미리보기/R/Esc/충돌, 확정/원본 유지, Undo/Redo, 입력 차단/전환 취소, 케이블, 반복/새 실행 Load로 나눠 정상 또는 관찰 결과를 알려주면 된다. 문제 발생 시 입력 순서와 대상 종류를 함께 적는다.

## 검증 범위

자동화 결과·측정 단위/정규화는 CLAUDE.md의 최신 스파인 복제 절을 따른다. NullRHI 축소 fixture의 보존/압력 검사는 실제 L_Test 전체 열운전·정상상태/FPS 검증을 대신하지 않는다. 네이티브 단일 스파인만 지원하며 다중 스파인/Blueprint/다른 장비 복제는 이번 범위 밖이다. 저장 형식은 기존 v2와 deletedSpines를 그대로 사용하고 온도·적분·시계는 복사/저장하지 않는다.
