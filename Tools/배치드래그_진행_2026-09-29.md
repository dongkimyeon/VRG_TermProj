# 단일 장비 드래그 진행 (2026-09-29)

## 범위와 조작

- 배치 모드에서 장비를 왼쪽 버튼으로 누르고 이동한다. 4픽셀 이상 움직이면 주황 상자로 미리보기한다.
- 바닥 XY를 5 cm 간격으로 맞추고 원래 Z·회전·스케일을 유지한다. 누른 위치와 장비 원점 사이 오프셋을 보존한다.
- 놓으면 실제 액터를 한 번 이동한다. 미리보기 중에는 실제 액터와 배관이 움직이지 않는다.
- Esc, F, 패치 창 열기, 모드 전환, 우클릭, 뷰포트 이탈/포커스 상실은 미확정 이동을 취소한다.
- 클릭만 하면 비격자 위치도 그대로다. 빈 곳 클릭은 선택 해제. 드래그 중 휠/G/T는 이동과 충돌하지 않게 막는다.
- 수치는 사용자 지정 격자와 UI 제스처 설정이다. 새 물성·추정 물리 수치는 추가하지 않았다.
