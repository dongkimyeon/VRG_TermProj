## 사용자 승인된 보존식 정정

회수 매니폴드에서 새는 물은 이미 트레이 출구를 통과했다. 따라서 트레이 출구 합에 모든 내부 누수를 더하면

- 랙 공급 유량 = 랙 회수 유량 + 모든 내부 누수.
- 각 트레이 입구 유량 = 트레이 출구 유량 + 트레이 내부 누수.
- 공급/회수 매니폴드의 각 티: 유입 = 유출 + 해당 티 누수.

- 앞/뒤 바닥 도착 누적량에서 W3가 이미 받은 양을 뺀 델타만 AddWater로 전달하고, 성공할 때만 전달 완료를 기록한다. 격자 밖·막힌 곳·미구성 격자/잘못된 위치는 대기량을 유지하고 재시도한다. W3의 기존 벽 근처 열린 셀 탐색 정책은 그대로다.

- 기존 LiveLeakSites에 실제 H.Leaks의27트레이×5지점을 **외부/설비 뒤에** 추가했다. 기존 외부 지점 번호는 유지한다. RackIndex는 방 routed 순서, Tray는 높이순 액랭27대 번호, Slot은 열모델37슬롯 번호이며 서로 바꿔 쓰지 않는다.
- key=`rack:<0부터 랙>:tray:<0부터 액랭 트레이>:<plate|supply_connector|return_connector|supply_manifold|return_manifold>`. 출력된 정확한 label(따옴표)과 지점 번호도 받는다. 내부망이 없는 랙별 가상 라디에이터/공랭 스파인에는 내부 지점을 만들지 않는다.
- L 크기 순환을 재사용한다. 조준이 내부면 **1mm→3mm→기존 호스9.525mm 파단→수리0→끔**, 외부면 기존5/30mm를 유지한다. 1/3mm는 승인 계획의 추정 시나리오이며 실제 파손 문턱/물성 값이 아니다. 새 기본 물성/저항/감지 사양 없음.
- B는 비어 있던 키다. 앞면(+local X)은 플레이트→공급 커넥터→회수 커넥터, 뒷면은 공급→회수 매니폴드. 커서 레이를 랙 로컬 좌표로 변환해 실제 슬롯 높이에 맞춘다. 공랭 슬롯/빈 공간은 액랭 이웃으로 강제 보정하지 않는다. 측면/평행 시선은 내부 조준을 거절한다.
- SetLiveLeak은 내부면 기존 Room.SetInternalLeakHoleDiameterM만 호출한다. 구멍 크기만 바꾸며 번호/위상/열·물 재구축 없음. FaultMonitor에 지점 이름/위치/공통 시각을 기록한다. 내부 분사 방향 변경은 거절(W2 없음).
- `vrg.Leak.Sites` 기본은 외부만, `vrg.Leak.Sites rack N`은 해당 랙 내부135개만 출력한다. `vrg.Leak.At <key> <mm>`, `vrg.Leak.Repair <key|all>`, `vrg.Eval.Event <t> leakat <key> <mm>`은 같은 SetLiveLeak 경로다. 기존 좌표 At/leakat은 **외부만** 유지해 가까운 내부 지점으로 뜻하지 않게 바뀌지 않는다. 전체 목록 ID는 레이아웃 순서가 바뀌면 달라질 수 있으므로 별도 영속 저장 식별자로 해석하지 않는다.
- L/B/클릭은 패치·콘솔·숫자 창의 입력 소유권을 따르고 우클릭 비행 중 클릭 적용은 막는다. 누수 도구가 켜진 동안 E 탈착을 막고 Esc로 끈 뒤 기존 E 경로를 유지한다. Enter 배치 전환 시 기존 도구 종료/포커스 경로를 재사용한다.

### 상태 표시와 단위
- GetRackLeakStatus는 SI의 읽기 전용 렌더 스냅샷이다. 선택 지점의 **풀이된** 누수 유량, 슬롯 현재 보유/뒤쪽 누적 노출, 랙 전체 보유/이동 중, 바닥 누적 도착/W3 완료/대기, 기존 트레이 냉각수 K와 부호 있는 입·출구 m³/s, 기존 FInstrumentBank의 준비/경보/시각을 읽는다. 조회 시 물을 이동시키거나 센서를 Advance하지 않는다.
- 누수 도구로 조준한 내부 랙만 패널과 젖은 슬롯 앞면 윤곽을 표시한다. 청록=현재 보유>0, 보라=뒤쪽 누적 노출>0(보유0). 누적 노출은 여러 높이를 통과한 이력이며 재고가 아니므로 물 장부에 더하지 않는다. 내부 열린 지점은 빨강/조준은 노랑, 닫힌 내부 수천 개를 항상 그리지 않는다. `vrg.Water.Show 0`은 기존 물 디버그와 슬롯 윤곽을 숨긴다.
- 지점/슬롯 윤곽은 앞뒤 면 위 **도식 앵커**이며 실제 커넥터 CAD/3D 내부 수막이 아니다. 기존 배관 수력 노드 좌표/높이를 수정하지 않는다. UI만 mm/L/L/s/°C로 변환한다.
- 센서 정상/경보 유지 상태와 시각은 기존 모의 계측값이며 설치/문턱/지연 추정을 패널에 명시한다. 초기화 전은 준비 중, 아직 경보가 없으면 미감지(정상 보장 아님). 기존 온도 라벨의 누수 경보 표시에도 접촉 센서를 포함한다. 수리해도 물/노출/경보를 지우지 않는다.
