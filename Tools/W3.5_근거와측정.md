## 사용자 승인된 보존식 정정

회수 매니폴드에서 새는 물은 이미 트레이 출구를 통과했다. 따라서 트레이 출구 합에 모든 내부 누수를 더하면
회수 매니폴드 누수를 두 번 센다. 2026-10-28 사용자 승인으로 다음을 각각 검사한다.

- 랙 공급 유량 = 랙 회수 유량 + 모든 내부 누수.
- 각 트레이 입구 유량 = 트레이 출구 유량 + 트레이 내부 누수.
- 공급/회수 매니폴드의 각 티: 유입 = 유출 + 해당 티 누수.

## 기존 압력 예산과 보정

`InRowLoopBuilder`는 공급과 회수에 각각 `1.7e10 Pa·s²/m⁶`를 쓴다.
따라서 랙 전체 기준은 `3.4e10`, 2.3 L/s에서 179860 Pa이다. 한쪽만 사용하면 절반으로 잘못 보정된다.
외부 공급/회수는 각각 전체 저항의 1%, 랙 내부는 98%로 배분한다(**추정**).
내부 세로 매니폴드의 각 설계 유량으로 누적 손실을 계산하고, 남은 압력 예산에서 UQD 공급/회수 저항을 뺀 값을
플레이트·호스의 보정 저항으로 사용한다. 플레이트 중간 누수 지점 양쪽에 반씩 배분하는 것도 **추정**이다.
이 계산은 초기 저항 보정에만 쓰며, 실행 중 유량은 기존 스케일링 Newton 방정식으로 푼다.

### 열 통합 전에 확인된 사항

양압 회수 매니폴드의 물도 누수 지점으로 역류한다. 열 이류는 음의 유량을 0으로 자르지 않고 실제 상류 수온을 사용해야 한다.
트레이 물을 하나의 잘 섞인 체적으로 가정하면 누수는 열도 운반하므로, 하류 유량 감소만으로 즉시 칩 온도 상승을 단정할 수 없다.
2026-10-28 이 점을 사용자에게 보고했고, 사용자는 현재 작업을 커밋한 뒤 계속 진행하도록 요청했다.
온도 상승을 강제하지 않고 역류를 포함한 계산 결과를 기록하며, 냉각 상실 조건의 온도 상승은 별도 검증한다(D4).
