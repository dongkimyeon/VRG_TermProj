# 부분 천장 구멍 기반

## 요청 기하와 계산 셀

사용자 요청(2026-10-06)과 기존 천장 계획을 대조했다. 판은 높이를 포함하는 한 Z 셀 층이며, 구멍은 그 판의 표시에서 일부 셀을 제외한다. ‘높이 위 전체 고체’나 외부 배기 경계를 만들지 않는다.

`FRoomCeilingPlate::Holes`의 `LocalMinXYM/LocalMaxXYM`은 판 최소 XY에서 잰 m 거리다. 월드 범위는 `판.MinXYM + 로컬 범위`, Z는 판 높이와 같은 계산 층이다. 판 전체 이동에는 함께 이동하고 높이 변경에는 함께 올라간다. 크기 편집에도 로컬 좌표는 그대로 유지하며 구멍을 비례 확대하거나 잘라내지 않는다. 최소 모서리가 바뀌면 로컬 기준점도 이동한다. 구멍이 새 판 밖으로 나가면 전체 편집을 거절한다.

판 XY는 기존 외향 floor/ceil이다. 구멍은 반대로 XY 발자국 전체가 요청 안에 있는 셀만 선택한다. 격자 원점 o, 셀 크기 h일 때 최소 인덱스는 `ceil((worldMin-o)/h)`, 최대 exclusive는 `floor((worldMax-o)/h)`이다. 계산한 셀 면을 실제 요청 경계와 다시 비교해 부동소수 나눗셈 반올림으로 요청 밖 셀이 열리지 않게 안쪽으로 보정한다. 경계 확대 epsilon은 없다. 실제 개방 XY 면은 h 미만씩 안쪽으로 줄어들 수 있고, Z 두께는 판과 같은 h다. 유한하지 않은 값·역순/영 폭·음수 로컬 최소·판 밖 최대·개방 셀 0개는 이유와 함께 거절한다. 이동 후 격자 정렬이 바뀌어 0셀이 되어도 거절한다. 겹친 구멍은 합집합이며 중복 개방을 세지 않는다.

예시(합성 테스트 기하, 실제 시설 치수가 아님): h0.25m·원점(-5.5,-4.5,0)m, 판 XY[-5.25,-4.25]×[3,4]m·높이2.625m에 로컬 구멍[0.125,0.875]×[0.125,0.875]m를 두면 요청 월드 XY[-5.125,-4.375]×[3.125,3.875]m, 실제 개방 XY[-5,-4.5]×[3.25,3.75]m·Z[2.5,2.75]m의4셀이다. 판16셀 중12셀만 해당 판의 고체로 남는다. `FRoomCeilingPlan::OpenCells`는 글로벌 격자 XY 인덱스 사각형이다. 판 외곽 `ActualBoundsM`은 구멍을 포함한 외곽이며 개방 셀 범위와 구분한다.

## 검증·적용·보존

기존 수동 방/자원 한도·장비 전체 변환·자동 CRAH·필요 덕트 검증을 재사용한다. 장비/덕트와의 양의 체적 겹침은 구멍을 제외한 실제 판 셀로 검사한다. 구멍이 있다는 이유로 나머지 판의 충돌을 완화하지 않는다. 구멍 없는 판은 기존 직사각형 검사 경로를 유지한다.

목록 확정은 배치 메타데이터만 바꾸고 다음 시뮬레이션 진입에 마스크를 재구축한다. 한 판의 구멍 셀은 그 판의 추가 표시만 생략한다. 기존 고체 마스크를 false로 지우지 않으므로 다른 판·벽·장비·콜드아일 지붕 고체는 남는다. 모든 중첩 기하가 비워진 곳만 실제 유체 통로가 된다. 기존 단열 벽/셀 크기/솔버 알림·냉각 재구축 정책을 유지한다. 외부 유출·강제 배기·팬·열 제거·플레넘은 없다. 개방은 내부 상하 공기 연결이다.

기존 전체 판 목록 Undo/Redo는 구멍 배열도 값으로 보존하며 복원 시 전체 후보를 재검증한다. 외부 목록 변경 감지는 구멍 변경도 포함한다. 저장 v2의 각 판에 선택 `holes` 배열을 추가한다. 각 객체는 로컬 `minXM/minYM/maxXM/maxYM` 네 값(m)만 저장한다. `holes`가 없는 저장 판은 구멍 없음, 천장 목록 자체가 없는 이전 파일은 현 전체 목록 유지다. 빈 배열은 구멍 없음이며 반복 Load는 목록을 교체한다. 불러올 방·장비·자동 CRAH·덕트·셀 크기로 전체 목록을 사전 검증하고 실패하면 기존 장비·벽·방·판·공유 기록을 유지한다. 성공한 Load만 기록을 비운다. 온도·적분 상태·시계는 저장하지 않는다.

구멍 UI는 이번 범위에 없다. C++ 목록 API 또는 위 선택 JSON 필드로 데이터를 전달한다. 빌드/자동화·측정 결과와 완료 범위는 CLAUDE.md 최신 구멍 절에 기록한다.

기존 판 편집 설명은 판 외곽 셀 수와 해당 판에서 제외한 개방 셀 수/남은 고체 수·실제 개방 범위를 구분해 표시한다. 다른 고체와 합집합한 최종 개방 수는 이 판별 개방 수보다 작을 수 있다. 구멍의 추가/선택/편집 UI를 새로 만들지는 않았다.
