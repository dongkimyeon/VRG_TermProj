4. 누수 지점 이동 시 특정 랙이 반드시 경보여야 한다던 옛 가정은 새 해에서 유량비0.9953/0.9959로 문턱0.985를 넘지 않는다. 실제 비율→경보 집합 검사는 유지하고, 위치를 바꾸면 수력 영향 방향이 이동하는지 확인한다. 경보 문턱은 변경하지 않는다(D4).
5. 내부 망 수력 잔차에 절대 수온 약300K를 곱하던 CDU 혼합식이 미세한 유령 열을 만들어 기존1e-12 루프 장부 검사를 실패시켰다. 트레이 열 이류와 동일한 초기 수온 기준의 엔탈피 차로 혼합식을 표현한다. 질량이 닫히면 같은 식이며 물성/유량/솔버 허용치/검사 기준을 바꾸지 않는다. 초기 수온 차만으로는 잔차가 남아, 아래와 같이 실제 열 경계 연산자까지 일치시켰다.

초기 조건/예열·측정 시간/실제 RHI·실행 종류·누수 위치·크기를 확정해 결과와 함께 남긴다. NullRHI/RenderOffscreen을 렌더 FPS로 쓰지 않는다.
기존 화면 도구 접근 실패는 재시도하지 않는다. 빌드/회귀 재개 뒤 측정해야 하며 동시 실행 부하를 섞지 않는다.
