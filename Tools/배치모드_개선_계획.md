# 배치 모드 개선 계획 (2026-09-27 기록, 미착수)

지금 배치 모드(CLAUDE.md "배치/시뮬레이션 모드" 절)는 화면 가운데 시선으로 장비를 가리키고 `G`로 잡고 `T`로 돌린다.
장비를 추가하거나 지울 수 없고, 여러 대를 한 번에 옮길 수 없고, 되돌릴 수도 없다.
이 계획은 **UE 에디터 뷰포트처럼 마우스 커서로** 장비를 고르고 옮기고, 랙·CDU·냉각장치를 **추가·삭제**하게 바꾼다.
물리 모델(D1~D10)은 건드리지 않는다. 배치 모드에서는 지금처럼 적분하지 않고, 시뮬레이션 진입 때 전부 다시 구성한다.

## 사용자가 정한 것 (2026-09-27 질의응답)

| 항목 | 결정 |
|---|---|
| 카메라 | **에디터 뷰포트식**: 커서가 항상 보인다. 오른쪽 버튼을 누르는 동안 마우스로 둘러보고 WASD로 비행, Q/E로 아래/위. 휠로 앞뒤 |
| 이동 | **클릭으로 고르고 바닥을 따라 드래그**(5 cm 스냅). 90° 회전. 장비는 바닥에만 놓이며 높이 이동은 없다 |
| 추가 | **배치 모드 전용 팔레트**: 화면 아래 장비 버튼 줄. 누르고 바닥에 놓는다. 시뮬레이션 모드로 가면 사라진다 |
| 편의 기능 | 삭제·여러 개 선택, 실행 취소, 겹침 막기·줄 붙이기, 놓을 때 미리보기 **전부** |

**화면 규칙 예외.** "화면에는 단축키 안내만"(CLAUDE.md "화면 디버그 문구 끔")의 예외로, **배치 모드에서만** 팔레트와 선택·미리보기 표시를 띄운다.
시뮬레이션 모드 화면은 지금 그대로다. 구현 때 CLAUDE.md에 이 예외를 적는다.

## 조작 (안)

| 입력 | 동작 |
|---|---|
| 왼쪽 클릭 | 커서 아래 장비 선택 (빈 곳: 선택 해제) |
| Shift + 왼쪽 클릭 | 선택에 더하기 / 빼기 |
| 빈 곳에서 왼쪽 드래그 | 사각형 선택 (화면에 투영한 장비 상자와 겹치면 선택) |
| 선택한 장비 위에서 왼쪽 드래그 | 선택 전체를 바닥을 따라 이동 (첫 장비 기준 5 cm 스냅, 상대 위치 유지) |
| `R` 또는 드래그 중 휠 | 선택을 90° 회전 (여러 대면 선택 중심 기준) |
| `Delete` | 선택 삭제 |
| `Ctrl+D` | 선택 복제 (옆으로 한 칸 비켜 놓고 바로 드래그 상태) |
| `Ctrl+Z` / `Ctrl+Y` | 실행 취소 / 다시 실행 |
| `Esc` | 드래그·배치 취소, 선택 해제 |
| 오른쪽 버튼 누른 채 | 마우스로 둘러보기 + WASD 비행, Q/E 아래/위, 휠 속도 |
| `F` | 선택 장비가 화면에 들어오게 카메라 이동 (선택 없으면 전체) |
| `Enter` / `C` / `H` | 지금과 같다 (모드 전환 / 컨테인먼트 / 도움말) |

- 지금의 `G`(잡기)·`T`(회전)는 클릭·`R`로 대체하고 뺀다. `R`은 시뮬레이션 모드에서는 지금처럼 리셋이다.
- 시선 조준(화면 가운데)은 시뮬레이션 모드의 `E`(유닛 뽑기)에만 남긴다. 배치 모드의 고르기는 커서 광선으로 한다.
- 기존 픽킹 함수(`PickPlaceableAlongRay`, `PlaceableBoxM`, `FloorPointSnapped`)는 시선 대신 **커서 광선**(`DeprojectMousePositionToWorld`)을 넣어 그대로 쓴다.

## 팔레트

화면 아래 한 줄. 버튼을 누르면 커서에 반투명 미리보기 상자가 붙고, 바닥을 클릭하면 놓인다(`Esc` 취소, `R` 회전).

| 버튼 | 만드는 것 | 초기값 |
|---|---|---|
| GB200 NVL72 랙 | `ARackThermalActor` + `ApplyGb200Nvl72Preset()` | 레벨의 기존 NVL72 랙과 같은 설정(발열·부하율·GJ 표시) |
| 스파인 캐비닛 | `ASpineCabinetActor` | QM9700 기본값 |
| CDU | `ACoolingDistributionUnitActor` | 코드 기본값 |
| 인로우 쿨러 | `ACrahUnitActor` (Kind 인로우) | 풍량 0 = 설계 풍량에서 나눠 받음 |
| 벽면 CRAH | `ACrahUnitActor` (Kind 벽면) | 같음 |

- 물성 기본값은 지금처럼 **코드가 유일한 출처**다. 에셋을 새로 만들지 않는다.
- 팔레트는 UMG 위젯을 코드로 만든다(패치 평면도와 같은 방식, UMG는 이미 Build.cs에 있다).
- 버튼 줄 오른쪽에 현재 선택 요약(개수·종류, 첫 장비 좌표 m·방향 °)과 놓을 수 없는 이유(겹침 등)를 적는다.

## 동작 규칙

**새 장비가 계산에 들어가는 방식.** 방 액터·통합 액터는 이미 매번 레벨 전체를 훑는다(`TActorIterator`).
그래서 실행 중에 만든 랙도 줄 묶기·배관·CDU 배정에 자동으로 들어가고, 시뮬레이션 진입 때 고체·덕트·센서가 붙는다.
배관 메시는 지금 디바운스(0.4 s) + 시간 분할 재구축을 그대로 탄다.

**CRAH 자동 배치 문제.** 손으로 놓은 CRAH가 하나라도 있으면 자동 배치(인로우 8대)가 통째로 꺼진다(`bUsingPlacedCrahs`).
팔레트로 쿨러를 처음 추가하거나 자동 배치 쿨러를 클릭하는 순간, 자동 배치 위치를 **실제 CRAH 액터로 바꿔 놓고**(`SpawnCrahActorsFromLayout`와 같은 일)
거기서부터 편집한다. 사용자 입장에서는 보이던 쿨러가 그대로 있고 하나가 늘어난다. 이 전환도 실행 취소 대상이다.

**겹침 막기.** 장비 상자(`PlaceableBoxM`, 바닥 투영 사각형)가 다른 장비와 겹치면 미리보기를 빨갛게 하고 놓지 않는다.
드래그 중에는 겹쳐도 따라가되 놓을 때 거절하고 원래 자리로 돌린다. 판정 여유 1 cm.
**공기 격자 고체는 겹침을 막지 못했다**(지금은 겹치면 셀이 합쳐질 뿐) — 이 검사가 그 구멍을 막는다.

**줄 붙이기.** 랙을 기존 줄 근처(줄 방향으로 한 칸 안, 뒷면 선이 `RowGroupToleranceM` 안)에 가져가면
그 줄의 방향·뒷면 선에 맞추고 줄 방향 간격을 그 줄의 이웃 간격(L_Test는 0.66 m)에 맞춘다. 가이드 선으로 보여 준다.
`Alt`를 누르고 있으면 붙이기를 끈다.

**삭제.** 배치 모드에서만. 줄의 마지막 랙을 지우면 그 줄과 배관이 사라지고, CDU를 지우면 그 줄들은 다음으로 가까운 CDU 또는 랙별 라디에이터로 간다(지금 규칙).
레벨에 저장된 액터를 지워도 **레벨 에셋은 바뀌지 않는다**(Play 중 월드만). 남기려면 배치 저장을 쓴다.

**실행 취소.** 배치 모드 안에서만, 명령 단위(이동·회전·추가·삭제·복제·CRAH 전환). 명령마다 영향받은 장비의
(종류, 이름, 위치, 방향, 설정) 전후 기록을 쌓는다. 삭제의 취소는 같은 이름·설정으로 다시 만든다. 기록 상한 100개.
시뮬레이션 모드로 가도 기록은 남고, 배치 저장 파일을 불러오면 비운다.

**미리보기.** 반투명 상자 + 바닥 발자국 + 치수(깊이 × 폭 × 높이 m)와 원점 좌표(m), 방향(°). 겹침이면 빨강, 줄 붙이기면 가이드 선.
선택된 장비는 지금의 청록/주황 상자 대신 외곽선 강조로 바꾼다(디버그 상자는 선택 수가 많으면 지저분하다).

**배치 저장·불러오기 확장.** 지금 `VrgLayoutFile`은 이름으로 기존 액터만 옮기고 만들거나 지우지 않는다.
추가·삭제가 생기므로 파일에 장비 **종류와 설정(프리셋)**을 적고, 불러올 때 없는 장비는 만들고 파일에 없는 장비는 지운다.
옛 형식 파일(종류 없음)은 지금처럼 이름으로 옮기기만 한다.

## 방 편집 (2026-09-27 추가: 사용자 요청)

방 크기·벽·천장을 배치 모드에서 바꿀 수 있어야 한다. **VR(HMD)은 구현하지 않는다**(2026-09-27 결정). 조작은 마우스·키보드뿐이다.

지금 상태: 방은 따로 없다. 공기 격자가 Play 시작 때 장비에 자동으로 맞춰지고(`bAutoFitToRacks`), 격자 경계가 곧 벽·바닥·천장이다(단열, 미끄럼 없는 벽 아님).
그래서 "방을 키운다"는 곧 **공기 도메인을 키운다**이고, "벽을 세운다"는 **그 자리의 셀을 고체로 막는다**(컨테인먼트 판과 같은 방식)이다.

| 기능 | 계산에서 하는 일 |
|---|---|
| 방 크기(가로·세로) | 공기 도메인 XY 범위. 방 모서리 핸들을 드래그해 바꾼다. 장비가 방 밖으로 나가면 놓지 않는다 |
| 천장 높이 | 공기 도메인 Z 범위 |
| 벽 추가 | 바닥에서 두 점을 찍어 벽(두께·높이 지정)을 만든다. 겹치는 셀을 고체로. 문 없이 끝이 열린 벽, 칸막이 가능 |
| 천장 설계 | 천장 판(부분 천장·낮은 천장 구역)을 사각형으로 그려 그 높이 위를 고체로. 콜드 아일 지붕과 같은 고체 판 |
| 방 템플릿 | "장비에 자동 맞춤"(지금 동작)과 "직접 정한 방" 중 선택 |

- 벽·천장은 **격자 셀 단위로 막힌다**(0.25 m). 이보다 얇은 벽도 한 셀 두께가 된다. 화면에는 실제 두께 메시를 그리고, 계산 두께를 미리보기에 적는다.
- 벽은 지금 경계처럼 **단열**이다. 벽을 통한 외부 열 교환, 벽 열용량, 문·틈새 누기, 이중 바닥·천장 플레넘(공기 통로)은 모델에 없다.
  천장 환기구로 공기를 빼는 설계는 CRAH 덕트와 같은 구조가 필요해 **이번 범위 밖**이다(열린 질문).
- 방을 키우면 셀 수가 는다. 편집 중에 셀 수와 예상 경로(CPU/GPU 자동 선택 기준 100000셀)를 적고, 축당 128셀 상한을 넘으면 경고한다.
  셀 폭은 지금처럼 `vrg.Air.CellSize`로 정한다. 측정 전에는 프레임을 약속하지 않는다(D10).
- 방·벽·천장도 실행 취소와 배치 저장 파일에 들어간다.
- 새 액터 `ARoomShellActor`(가칭) 하나가 방 범위·벽 목록·천장 판 목록을 m 단위로 들고, 통합 액터가 시뮬레이션 진입 때 공기 격자 범위와 고체 셀로 바꾼다.
  이 액터가 레벨에 없으면 지금처럼 장비에 자동 맞춘다(기존 레벨·테스트 동작 유지).

## 지켜야 할 것

- 규약 1: 커서·카메라 계산은 UE cm, 표시·저장·물리 입력은 m. 변환은 액터 경계에서만.
- 규약 4: 배치 모드에서는 시계·솔버가 멈춰 있다. 편집이 SimTime을 움직이지 않는다.
- 규약 5: 편집은 게임 스레드에서만. 솔버 상태는 시뮬레이션 진입 때 새로 만든다.
- 15 kW 하이브리드 랙은 제거했다(3ae138b). 팔레트 랙은 NVL72이며 장비별 파라미터를 섞지 않는다.
- D10: 드래그 중 프레임을 재서 기록한다. 배관 재구축이 드래그를 끊지 않게 한다(놓은 뒤에만 재구축).

## 단계

1. **커서와 카메라** — 커서 표시, 오른쪽 버튼 비행(WASD·Q/E·휠 속도), `F` 맞추기. 기존 시선 조준은 시뮬레이션 모드 `E`에만.
   검증: 입력 없이 카메라가 움직이지 않는다(기존 시작 이동 진단 로그 유지).
2. **선택·드래그·회전** — 커서 광선 픽킹, 단일/Shift/사각형 선택, 선택 전체 드래그, `R` 회전. 5 cm 스냅.
   검증(자동화): 광선 → 바닥점 → 스냅 좌표, 여러 대 회전 뒤 상대 위치, 드래그 뒤 시뮬레이션 진입 시 새 자리가 고체.
3. **겹침 막기·줄 붙이기·미리보기** — 검증: 겹치는 이동 거절 후 원위치, 줄 붙이기 뒤 줄 묶기 결과에 그 줄로 들어감.
4. **팔레트 추가·삭제·복제** — CRAH 자동 배치 → 실제 액터 전환 포함.
   검증: 랙 한 대 추가 → 줄 랙 수 +1, 배관 분기 +1, 시뮬레이션 진입 뒤 전역 열수지 잔차 기존 기준(< 1e-9) 안, IT 전력이 랙 한 대만큼 증가.
   쿨러 추가 → 쿨러 수 9대(자동 8 + 1), 덕트 유량 적합성 유지. 삭제는 반대.
5. **실행 취소** — 검증: 무작위 명령 N개 뒤 전부 취소하면 처음 배치와 위치 1e-6 cm·방향 1e-6° 안으로 같다. 다시 실행하면 끝 상태와 같다.
6. **방 편집** — 방 크기·천장 높이·벽·천장 판. 검증: 벽 한 장으로 방을 둘로 나누면 벽 셀 법선 속도 0·벽 너머 온도 불변(기존 `Air.Solid.BlocksFlow`와 같은 기준),
   방을 키운 뒤 도메인 범위·셀 수가 설정과 같음, 장비가 방 밖이면 배치 거절, 시뮬레이션 진입 뒤 전역 열수지 잔차 < 1e-9.
7. **배치 저장 확장** — 검증: 추가·삭제한 배치를 저장 → 다른 배치로 바꿈 → 불러오기 뒤 장비 종류·수·위치가 같다. 옛 형식 파일도 읽힌다.
8. **측정·문서** — L_Test에서 드래그 중 프레임, 놓은 뒤 재구축 시간, 랙 추가 뒤 시뮬레이션 결과. CLAUDE.md에 조작표·화면 규칙 예외·한계를 적는다.
