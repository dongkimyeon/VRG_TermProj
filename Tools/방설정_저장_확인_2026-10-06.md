# 방 설정 저장 직접 확인

방 UI·Undo/Redo는 사용자가 정상 확인했다. 이번 저장/Load의 실제 콘솔 입력·새 실행 화면은 미확인이다. 이전 클릭/캡처 도구 실패를 반복하지 않았다. 정량 저장/복원·냉각 검증은 CLAUDE.md 최신 절을 따른다.

1. L_Test 배치 모드에서 정상 확인한 수동 방 값을 적용하고 창을 닫는다. 콘솔(`~`)에서 `vrg.Layout.Save RoomManual`을 실행한다. 콘솔은 명령 입력창이며 `~`로 닫는다.
2. 천장 높이를 다른 유효 값으로 적용하거나 장비/벽을 조금 옮긴 후 `vrg.Layout.Load RoomManual`을 실행한다. 원래 방/장비/벽이 복원돼야 한다. 방 창에서 값을 확인하고 닫은 뒤 Ctrl+Z/Y가 과거 편집을 실행하지 않아야 한다.
3. 같은 Load를 다시 실행해 장비/벽이 중복되지 않는지 확인한다. 시뮬레이션 진입 때 수동 격자 계획이 적용되고, 방을 바꾸거나 Load하는 순간에 계산을 재시작하지 않는지 확인한다.
4. 저장하지 않고 실행 창을 종료한 뒤 L_Test를 새로 실행해 `vrg.Layout.Load RoomManual`을 실행한다. 수동 방과 저장한 장비/벽을 확인한다. 레벨 에셋을 저장할 필요는 없다.
5. 자동 모드를 적용하고 `vrg.Layout.Save RoomAuto`로 저장한다. 다시 수동으로 바꾼 뒤 `vrg.Layout.Load RoomAuto`를 실행하면 자동 모드로 복귀해야 한다.

잘못된 방·최종 배치 불포함·자원 초과·중간 생성 실패·이전 v1/v2 호환은 자동화로 검사한다. 직접 JSON을 손으로 바꿀 필요는 없다. 저장은 `Saved/Layouts/<이름>.json`이며 계산 상태/온도/시계/Undo 기록은 저장하지 않는다. FPS 측정은 별도다.

보고 예: `방 설정 저장 직접 확인: 수동/자동·반복 Load·새 실행·장비/벽 복원·기록 초기화 [정상 또는 실패 절차]`.
