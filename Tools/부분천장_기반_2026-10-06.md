# 부분 천장 판 기반

2026-10-06 사용자 결정: 천장은 셀로 구성해 추후 배기 구멍을 추가한다. 기존 계획의 ‘지정 높이 위 전체 고체’와 ‘한 셀 두께 판’은 다른 모델이다. 이번에는 **판 높이를 포함하는 한 Z 셀 층**으로 확정했다. 위쪽 공기는 유지하며, 낮은 천장 영역 전체를 채우거나 배기 구멍/강제 배출을 만들지 않는다. 판은 현재 단열 고체이며 외부 열 교환·재료 열용량·플레넘은 없다.

## 데이터와 검증

`FRoomCeilingPlate`의 `MinXYM/MaxXYM/HeightM`은 월드 m이다. `ADataCenterSimulationActor::TrySetRoomCeilingPlates`에 목록 전체를 전달하고 성공할 때만 교체한다. 빈 목록은 기존 월드의 동작을 유지한다. 이번 기반의 비어 있지 않은 목록은 명시적인 수동 방이 필요하다. 판을 제거하지 않고 자동 방으로 바꾸는 조작은 거절한다.

실제 장비 외형의 전체 변환과 기존 공기 덕트 경계·새로 계획한 자동 CRAH를 기존 방 검증 API로 확인한다. 요청 사각형/높이는 유한하고 양수이며 수동 요청 방 안이어야 한다. 실제 계산 판 범위와 필요한 장비/덕트 경계가 양의 체적으로 겹치면 이유를 반환한다. 기존 벽처럼 통로를 임의로 비우거나 판을 잘라 적용하지 않는다. 판끼리, 벽, 콜드아일 지붕과의 중복 고체는 합집합으로 처리한다.

기존 격자 h와 축당128셀 자원 정책을 재사용한다. XY는 요청 사각형과 양의 면적으로 겹치는 모든 셀을 포함한다: 최소 `floor((min-origin)/h)`, 최대 exclusive `ceil((max-origin)/h)`. 높이는 `floor((height-originZ)/h)` 셀 한 층이다. 정확한 격자 Z 경계의 높이는 그 경계 위 셀을 선택한다. 계산 판 두께는 h이며 아래/위 면과 요청 높이의 차이는 각각 h 미만/이하이다. XY는 각 경계가 h 미만 외향 확장될 수 있다. 실제 계산 범위는 `FRoomCeilingPlan::ActualBoundsM`으로 확인한다.

예시는 합성 테스트 기하이며 실제 시설 치수가 아니다. h0.25m, 방 원점(-5.5,-4.5,0)m에서 요청 XY[-5.13,-4.61]×[3.13,3.62]m·높이2.63m는 실제 XY[-5.25,-4.5]×[3,3.75]m·Z[2.5,2.75]m의9셀이다. 상부를 채우지 않는다. 셀 크기 변경은 다음 진입 때 판 범위와 통로 검증도 바꾼다.

## 적용과 제한

목록 교체는 배치 모드에서만 가능하고 미리보기/검증 동안 격자·온도·시계·장비·배관을 변경하지 않는다. 실제 고체는 다음 시뮬레이션 진입 전에 재검증하고 기존 재구축 경로에서 반영한다. 장비 이동으로 현재 판이 통로를 막게 되면 진입을 거절한다. 장비·CRAH·콜드아일 지붕·벽을 먼저 표시하고 판을 합집합으로 추가한 뒤 기존 `OnSolidCellsChanged`로 압력/벽 거리 계산을 갱신한다. `GetNumCeilingCells()`는 기존 고체와 겹치지 않는 새 판 셀 수이며 중복 판을 여러 번 세지 않는다. 판 목록을 비워도 현재 격자는 유지하고 다음 진입에만 판 고체가 제거된다.

천장 UI·액터/메시·핸들·Undo/Redo·저장 연결은 후속이다. 기존 v2는 판 목록을 저장하지 않으므로 같은 월드 Load는 현재 목록을 유지하고 새 월드에는 목록이 없다. 현 목록은 기존 파일의 최종 장비/방 검증에도 포함해 잘못된 Load를 거절한다. 기존 장비/벽 저장 필드는 그대로다. 추후 배기 구멍은 판 셀 마스크를 제외하는 기능과 실제 배기 유량/압력·열 경계 조건을 구분해서 구현해야 한다.

빌드/자동화·측정 정규화와 완료 범위는 CLAUDE.md 최신 천장 절을 따른다. 화면 도구 실패 재시도·전체 테스트·FPS 측정은 하지 않는다.
