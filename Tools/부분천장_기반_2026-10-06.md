# 부분 천장 판 기반

2026-10-06 사용자 결정: 천장은 셀로 구성해 추후 배기 구멍을 추가한다. 기존 계획의 ‘지정 높이 위 전체 고체’와 ‘한 셀 두께 판’은 다른 모델이다. 이번에는 **판 높이를 포함하는 한 Z 셀 층**으로 확정했다. 위쪽 공기는 유지하며, 낮은 천장 영역 전체를 채우거나 배기 구멍/강제 배출을 만들지 않는다. 판은 현재 단열 고체이며 외부 열 교환·재료 열용량·플레넘은 없다.

## 데이터와 검증

`FRoomCeilingPlate`의 `MinXYM/MaxXYM/HeightM`은 월드 m이다. `ADataCenterSimulationActor::TrySetRoomCeilingPlates`에 목록 전체를 전달하고 성공할 때만 교체한다. 빈 목록은 기존 월드의 동작을 유지한다. 이번 기반의 비어 있지 않은 목록은 명시적인 수동 방이 필요하다. 판을 제거하지 않고 자동 방으로 바꾸는 조작은 거절한다.

실제 장비 외형의 전체 변환과 기존 공기 덕트 경계·새로 계획한 자동 CRAH를 기존 방 검증 API로 확인한다. 요청 사각형/높이는 유한하고 양수이며 수동 요청 방 안이어야 한다. 실제 계산 판 범위와 필요한 장비/덕트 경계가 양의 체적으로 겹치면 이유를 반환한다. 기존 벽처럼 통로를 임의로 비우거나 판을 잘라 적용하지 않는다. 판끼리, 벽, 콜드아일 지붕과의 중복 고체는 합집합으로 처리한다.

기존 격자 h와 축당128셀 자원 정책을 재사용한다. XY는 요청 사각형과 양의 면적으로 겹치는 모든 셀을 포함한다: 최소 `floor((min-origin)/h)`, 최대 exclusive `ceil((max-origin)/h)`. 높이는 `floor((height-originZ)/h)` 셀 한 층이다. 정확한 격자 Z 경계의 높이는 그 경계 위 셀을 선택한다. 계산 판 두께는 h이며 아래/위 면과 요청 높이의 차이는 각각 h 미만/이하이다. XY는 각 경계가 h 미만 외향 확장될 수 있다. 실제 계산 범위는 `FRoomCeilingPlan::ActualBoundsM`으로 확인한다.

예시는 합성 테스트 기하이며 실제 시설 치수가 아니다. h0.25m, 방 원점(-5.5,-4.5,0)m에서 요청 XY[-5.13,-4.61]×[3.13,3.62]m·높이2.63m는 실제 XY[-5.25,-4.5]×[3,3.75]m·Z[2.5,2.75]m의9셀이다. 상부를 채우지 않는다. 셀 크기 변경은 다음 진입 때 판 범위와 통로 검증도 바꾼다.

## 적용과 제한

목록 교체는 배치 모드에서만 가능하고 미리보기/검증 동안 격자·온도·시계·장비·배관을 변경하지 않는다. 실제 고체는 다음 시뮬레이션 진입 전에 재검증하고 기존 재구축 경로에서 반영한다. 장비 이동으로 현재 판이 통로를 막게 되면 진입을 거절한다. 장비·CRAH·콜드아일 지붕·벽을 먼저 표시하고 판을 합집합으로 추가한 뒤 기존 `OnSolidCellsChanged`로 압력/벽 거리 계산을 갱신한다. `GetNumCeilingCells()`는 기존 고체와 겹치지 않는 새 판 셀 수이며 중복 판을 여러 번 세지 않는다. 판 목록을 비워도 현재 격자는 유지하고 다음 진입에만 판 고체가 제거된다.

수동 방의 ‘부분 천장 추가’ 창에서5필드 m 초안을 입력하고 Add로 한 장을 확정한다. 계산 가능한 후보는 요청/실제 셀 범위·두께·셀 수와 거절 이유를 보여준다. 창을 닫으면 청록 요청 사각형/주황 계산 상자를 충돌 없는 선으로 표시한다. 새 액터나 선택 충돌을 만들지 않는다. 확정 한 건은 기존 공유 Undo/Redo에 전체 목록의 이전/이후 값을 저장하며 현재 방/장비/자동 CRAH/덕트를 재검증한다. 실패나 외부 목록 변경은 기록을 유지한다. 숫자 창의 UIOnly·닫기/입력 복귀 경로를 재사용한다. 직접 UI 절차는 부분천장_UI_Undo_확인_2026-10-06.md를 따른다.

단일 판 선택/삭제는 수동 방의 별도 천장 편집에서만 사용한다. 계산 상자의 전방 최근접 ray를 선택하며 완전히 같은 거리/기하는 첫 목록 인덱스를 선택한다. 초록 강조/선택 번호·판 수로 표시하고 Delete는 RemoveAt 한 장을 기존 검증/전체 목록 Undo·Redo로 기록한다. 숫자/패치/시뮬레이션/다른 편집을 차단하고 Esc로 종료하면 일반 장비 픽/카메라가 복귀한다. 대상과 목록 스냅샷을 확인하며 목록 변경/Undo·Redo/Load 뒤 선택을 해제한다. 판 액터/메시·다중 삭제·핸들은 후속이다. 저장 v2의 선택 settings.roomCeilingPlates는 각 판의 minXM/minYM/maxXM/maxYM/heightM을 m 단위로 저장하는 전체 목록이다. 빈 배열은 목록 제거, 필드가 없는 이전 v1/v2는 현 목록 유지다. 순서와 중복 기하의 값도 그대로 복원하며 반복 Load는 덧붙이지 않는다. 불러올 방/장비/자동 CRAH/덕트와 저장된 셀 크기로 후보 목록을 사전 검증하고 기존 모든 생성/변환/삭제 성공 뒤 방과 함께 교체한다. 실패는 방/판/장비/벽/기록을 유지하고 성공 Load만 공유 기록을 비운다. 실제 고체는 다음 진입에만 적용한다. 기존 장비/벽 저장 필드는 그대로다. 추후 배기 구멍은 판 셀 마스크를 제외하는 기능과 실제 배기 유량/압력·열 경계 조건을 구분해서 구현해야 한다.

빌드/자동화·측정 정규화와 완료 범위는 CLAUDE.md 최신 천장 절을 따른다. 화면 도구 실패 재시도·전체 테스트·FPS 측정은 하지 않는다.


기존 판 UI·Undo/Redo는 사용자 직접 전체 정상 보고를 반영했다. 저장/Load·새 실행도 사용자 직접 정상 보고를 반영했다. 선택/삭제도 사용자 직접 정상 보고다. 새 XY 핸들 UI는 별도 직접 절차 미확인이다. 저장 영향7종/따뜻한 실패 원복·같은/새 월드 냉각 결과는 CLAUDE.md 최신 저장 통합 절을 따른다.

삭제 영향6종/거절·따뜻한 상태 보존·18→9→0셀 및 같은/새 월드 냉각 결과는 CLAUDE.md 최신 삭제 통합 절을 따른다. 마지막 판을 삭제해도 수동 방 자체는 유지한다.

## 2026-10-06 선택 판 XY 모서리

선택·삭제 직접 절차는 사용자 정상 보고다. 선택한 요청 사각형에만 네 점을 표시하고 기존 방 코너 delta/5cm 스냅을 공유한다. 반대 모서리/높이는 유지하며, 교차 범위를 뒤집어 정렬하지 않고 검증 거절한다. 미리보기 후보는 전체 목록의 해당 인덱스만 교체해 기존 API로 검증한다. 확정 한 건은 기존 전체 목록 공유 기록/저장 v2를 사용한다. 외부 목록 변화는 선택/드래그를 무효화하고 직접 확정한 경우만 새 목록 스냅샷으로 같은 인덱스를 유지한다. 실제 격자/온도/시계 적용은 다음 진입이다.
Esc는 드래그 취소 후 편집 유지, 유휴 때 편집 종료다. Delete/Undo/Redo/장비/카메라는 드래그 중 막고 숫자/패치/모드/성공 Load는 미확정을 취소한다. 실제 XY 핸들 화면 확인은 부분천장_XY핸들_확인_2026-10-06.md 절차로 남긴다. 기존 앞 절의 핸들 미지원은 이번 XY 범위로 대체되며 높이/전체 이동/다중 편집/배기는 후속이다. 빌드/측정 결과는 CLAUDE.md 최신 절을 따른다.

XY 확정/기록/저장 통합은 고유 영향6종 무경고 성공이다. 같은/새 월드에서 두 판 중 한 항목만 편집한 목록 복원·기록 초기화·다음 진입9→16셀과 기존 IT/냉각/열수지/압력·타당성을 확인했다. 자세한 측정·단위/정규화는 CLAUDE.md 최신 절을 따른다. 높이/전체 이동/다중/구멍은 후속이며 신규 UI 직접 확인은 미확인이다.

## 2026-10-06 선택 판 높이
선택한 판 중앙 높이 점은 기존 방의 수직축 최근접 계산·잡기 오프셋·5cm 높이 스냅을 공유한다. XY/목록 순서/다른 중복 판은 유지하고 모든 미리보기·검증·확정·취소는 XY와 같은 경로다. 거의 평행한 시선은 계산/확정을 거절하며 안정 시선 복구 시 다시 검증한다. 저장 스키마와 한 Z층 적용 정책은 유지한다. 실제 신규 화면은 부분천장_높이핸들_확인_2026-10-06.md 절차로 남긴다. 기존 XY 직접 정상은 사용자 보고다. 빌드/측정 결과는 CLAUDE.md 최신 절을 따른다.

높이 확정/기록/저장·냉각 통합은 고유 영향6종 무경고 성공이다. 중복 판 한 장 높이만 변경·XY 유지·Undo/Redo·거절/취소/no-op 기록 유지·같은/새 월드 반복 Load와 다음 진입9→18셀(Z10/11)을 확인했다. 측정/단위/정규화·한계는 CLAUDE.md 최신 절을 따른다. 기존 XY 직접 정상은 사용자 보고이며 신규 높이 UI는 직접 미확인이다. 전체 이동/다중/배기·물리 확장은 후속이다.
