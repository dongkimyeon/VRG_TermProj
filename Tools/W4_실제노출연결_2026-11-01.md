# W4 실제 물 관측 연결 (2026-11-01)

W3.5 성능 검사/최적화 유예와 D10·성능 미충족·전체 미완료 기록을 유지한다. W4 전체 완료도 아니다. 기존 32fa0a7/a3ff4ff의 독립 기반을 재사용한다. 이번 변경은 관측과 상태 판독만 연결하며 실제 발열/팬/펌프/코일을 멈추지 않는다.

## 자료 대응

- `DataCenterWaterExposure.cpp`: 액터 경계에서 기존 lifecycle Identity에 종류 접두사(rack/spine/cdu/crah/plant)를 붙여 대상 ID를 만든다. 자동 CRAH는 해당 실행의 배치 인덱스 `auto/crah/<n>`이며 새 실행 때 다시 대응한다.
- 기존 BuildSprayGeometry가 실제로 만든 계산 상자와 함께 ID/장애물 인덱스/weak 액터/변환을 기록한다. W2 표시 이름이나 형상·물리를 바꾸지 않는다. native CRAH는 기존 배치에 원본 weak 참조만 추가한다.
- Binding.SourceName은 기존 표시 이름, EquipmentId는 식별자다. W3 FFloorFlood.SourceObstacle은 기존 원본 상자 인덱스 메타데이터이며 같은 이름의 여러 설비/바닥 기록을 혼동하지 않는다. 이전 수심 계산/받은 물량·고체 표시는 그대로다.
- 침수 접촉 높이는 계산 상자의 월드 최저 Z 또는 실제 슬롯 기하의 8개 변환 꼭짓점 중 최저 Z에서 기존 footprint의 평균 bed 높이(바닥 Z 포함)를 뺀 값이다. m 단위, 음수 간극은0. 부품 접점/전기 부품 위치를 새로 추정하지 않는다.
- W3 footprint가 없거나 비어 있으면 침수는 미가용 비트와 진단으로 남긴다. 외부/매달린 장비의 수심을0으로 관측했다고 주장하지 않는다. W2가 슬롯을 구분할 수 없는 경우 기존 미분류 진단을 유지한다. 내부 슬롯에는 기존 랙 인덱스/정확한 native 슬롯 자료만 연결한다.

## 공통 스텝과 수명

EnterSimulationMode에서 W2/W3/내부 물 초기화 후 공통 SimTime의 baseline을 잡는다. SprayAfterStep의 내부 물→W2→W3 처리가 모두 끝난 뒤 `Clock.GetSimTimeS()+DtS`로 한 번만 관측한다. Clock.CompleteStep 전 endpoint이며 Tick과 RunSteps가 같은 함수를 쓴다. 물이 없어도 관측은 진행한다. baseline은 적분 횟수에 세지 않고 이후 확정 관측만 센다.

배치 진입/결합 재구축은 관측 레지스트리·정책·상태·누적 기준을 무효화한다. 새 시뮬레이션 진입에서 물 자료와 함께 다시 초기화한다. 기존 W2/W3 기하를 새로 만들지 않은 실행 중 결합 재구축은 관측을 계속 적용하지 않고 재진입이 필요하다는 진단을 남긴다. 관측 때문에 물리 재시작/물 재배분을 강제로 하지 않는다.

weak 액터 소멸/ID·변환·치수·슬롯 수/기하 변경, 내부 물 스텝 거절, 잘못된 source/시간/자료는 거절한다. 마지막 유효 노출/상태/시계/횟수를 부분 갱신하지 않는다. 거절 뒤 `IsWaterExposureCurrent()==false`와 진단을 확인해야 한다. 이전 snapshot을 최신 상태로 해석하면 안 된다.

## 명시적 정책

기본은 **정책 미설정/상태 미계산**이다. `HasWaterImpactPolicy()`와 freshness를 확인한다. 정상(Normal)을 미설정의 대체 표기로 쓰지 않는다.

C++ `ConfigureWaterImpactObservation(Policy, Powered, Reason)`에 전체 대상 순서와 일치하는 명시적 통전 관측을 공급한다. 기존 모델에 모든 장비의 전기 통전 상태가 정의돼 있지 않아 탈착·발열량만으로 통전을 추정하지 않는다. 운영 정책과 전기 회로는 이번에 새로 확정하지 않았다. 정책의 근거/추정 입력은 W4-1 규칙을 그대로 따른다. 관측 최대 간격이 공통 dt보다 작으면 설정을 거절한다.

`SetWaterImpactPowerObservation`의 새 값은 다음 endpoint 입력이며 기존 left-hold 정책에 따라 과거 구간에 소급 적용하지 않는다. 새 실행/배치 진입/재구축에서 정책도 지워 대상 순서가 바뀐 통전 배열을 재사용하지 않는다. 정책/통전은 저장 파일·UI·웹으로 확장하지 않았다.

판독은 기존 FWaterImpactModel의 임시 사본에서 검증하고 노출과 함께 확정한다. 모델 거절 시 어느 쪽도 부분 게시하지 않는다. 트립/손상은 관측상 상태일 뿐 물리 전원 차단 명령을 전달하지 않는다. 시험 정책을 운영 기본값으로 채택하지 않는다.
