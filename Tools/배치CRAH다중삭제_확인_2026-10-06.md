# 다중 CRAH 삭제 직접 확인 (2026-10-06)

고유 영향 Automation10종은 무경고 성공이다. 실제 그룹 삭제·Undo/Redo UI는 미검증이다. 두 런타임 CRAH를 만든 뒤 도구 사각형 드래그1회에서 선택 강조가 나타나지 않아 재시도를 멈췄다. 도구/제품 원인은 미확정이며 API 성공을 입력 전달 성공으로 해석하지 않는다. 미선택 Delete 거절과 확인용 추가 Undo 두 번(0/2)은 로그로 확인했다.

드라이버 안내는 아니오로 진행한다. 이번에는 클릭 geometry unavailable 뒤 Right 키→Alt+Print Screen에서 아니오 포커스 확인→Enter로 닫았다. 캡처는 기존 Alt+Print Screen→클립보드 PNG 저장→이미지 확인을 사용한다. 실행 월드만 확인하고 레벨 에셋을 저장하지 않는다.

1. CRAH 두 대를 Shift+클릭으로 선택해 모두 초록 강조인지 확인한다. 기존 배치(준비된 경우)·자동 전환·런타임 조합도 확인한다. Delete로 전체 제거→Ctrl+Z로 전체 복원→Ctrl+Y로 전체 재삭제가 한 기록이어야 한다.
2. 그룹 이동/R→Delete→Ctrl+Z 세 번→Ctrl+Y 세 번으로 이전 변환 기록의 참조 재연결을 확인한다. 설정·높이/방향/스케일·출처와 전환 원래 경계가 유지돼야 한다. 온도·적분·시계는 복사 대상이 아니다.
3. 다른 종류가 섞인 선택·미선택, 편집/패치/시뮬레이션 중 CRAH 삭제는 거절돼야 한다. 다른 종류만 선택했을 때는 그 종류의 기존 삭제 기능을 유지한다.
4. 마지막 실제 CRAH 전체를 삭제하면 자동 쿨러 계획/표시가 돌아와야 한다. Undo하면 삭제한 실제 전체로, Redo하면 자동 상태로 돌아간다. 냉각을 완전히 끄는 명령이 아니며 개수만큼 총풍량/용량이 비례 감소하지 않는다.
5. 삭제 전/후 배치를 서로 다른 파일로 저장한다. 반복 Load와 새 L_Test에서 Load해 삭제 의도·기존/런타임 장비·중복 없음·기록 초기화를 확인한다. 물리 정확도와 FPS는 화면만으로 판정하지 않는다.

복원 충돌/이름 점유·중간 생성/삭제 실패 전체 원복은 Automation으로 확인했다. 실제 UI에서는 별도 확인하지 않았다.
