## 2026-09-28 배치 입력 1단계 — 작은 커밋 진행

- 커서: 배치 모드에서 표시, 시뮬레이션 모드에서 숨김. 패치 평면도가 열린 동안 입력 모드를 덮어쓰지 않으며 닫으면 현재 모드로 복귀.
- 현재 커서 변경은 정적 diff 검사만 완료. 빌드/Automation은 카메라·F 구현 뒤 묶어서 실행할 예정이며 아직 통과로 세지 않는다.
- 이어서 할 일: 우클릭 회전 → WASD/QE·휠 → F 보기 → 빌드·전체 Automation·문서 갱신.
- 클릭 선택·드래그·팔레트·웹 대시보드는 이번 범위 밖. 기존 G/T는 다음 선택 단계까지 유지한다.

- 회전 구현: 배치 모드에서는 우클릭 중만 기본 Pawn의 마우스 회전을 허용. 패치 창에서는 회전 차단, 시뮬레이션 자유 시점은 유지. 빌드·실행 검증 대기.

- 이동 구현: 우클릭+WASD/QE, 우클릭+휠 속도 조절, 단독 휠 전후 이동. 기본 Pawn 중복 이동·관성 차단. 배치 E는 장비 탈착하지 않음. 콘솔·패치 창에서는 새 카메라 입력 차단. 빌드·검증 대기.
