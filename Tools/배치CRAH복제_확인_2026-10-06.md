# 단일 CRAH 복제 직접 확인 (2026-10-06)

런타임 원본 Ctrl+D·중첩 빨강/거절·R90°·주황 목적지·Esc·확정·원본 유지·Undo/Redo는 L_Test 일반 창에서 확인했다. 입력/저장/물리 고유9종 Automation 성공. 아래 나머지 UI 범위는 미검증이다. 복원 충돌/실제 생성 실패는 Automation 확인이며 실제 UI 확인과 구분한다. FPS 미측정.

실행 월드에서만 확인하고 레벨 에셋을 저장하지 않는다. 드라이버 안내는 아니오로 진행한다. 캡처는 Alt+Print Screen→클립보드 PNG 저장→이미지 확인이며 기존 캡처 API 실패를 재시도하지 않는다.

1. 기존 배치 CRAH 또는 인로우 추가로 전환된 CRAH 한 대를 선택→Ctrl+D. 중첩 빨강/생성 거절·빈 곳 주황·R90°·Esc 취소 후 다시 복제해 한 대만 확정되는지 확인한다.
2. Ctrl+Z/Y로 제거·복원, 원본 유지와 종류/설정/방향/높이/스케일을 확인한다. 복제본은 새 런타임 ID이고 자동 전환 출처/원래 경계를 계승하지 않는다.
3. 미선택/다중/혼합, 드래그/사각형/추가 중 새 CRAH 복제가 시작되지 않아야 한다. 미리보기 중 패치 창 또는 시뮬레이션 진입은 취소해야 한다. 다른 종류의 기존 복제는 유지된다.
4. 복제 후 별도 이름으로 배치 저장→반복 Load→새 L_Test 실행 후 Load. 동일 원본/복제본·한 대 증가·중복 없음·Ctrl+Z/Y 과거 기록 초기화를 확인한다. 온도·적분·시계는 저장 대상이 아니다.
5. 시뮬레이션의 쿨러/풍량/팬/코일 표시를 참고한다. 개수만으로 총풍량/용량이 비례 증가하지 않는다. 물리 정확도·FPS는 화면만으로 판정하지 않는다.
