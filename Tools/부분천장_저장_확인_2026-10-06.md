# 부분 천장 저장·Load 직접 확인

기존 부분 천장 UI·Undo/Redo는 사용자 직접 전체 정상 보고를 반영했다. 아래 새 저장/Load·새 실행 화면 절차는 아직 미확인이다. 도구 실패를 재시도하지 않는다. 정확한 목록 개수/중복과 고체 셀·물리 수치는 Automation 결과를 따른다.

1. L_Test를 새로 실행해 배치 모드에서 수동 방을 적용하고 부분 천장 한 장을 추가한다. 직전 직접 정상 확인 배치 그대로라면 시험 방은 X[-4,10]m·Y[-3,8]m·천장3.75m, 판은 X[-3.75,-3.25]m·Y[-2.75,-2.25]m·높이3m을 사용할 수 있다. 이는 해당 배치의 사용자 시험값이며 시설 규격/물성 기본값이 아니다. 배치가 달라 거절되면 표시된 이유를 따른다. 추가 뒤 다른 편집을 하지 않고 창을 닫는다.
2. `~`로 콘솔을 열어 `vrg.Layout.Save CeilingCheck`를 입력하고 Enter로 실행한다. 다시 `~`로 닫는다. 파일은 Saved/Layouts/CeilingCheck.json이며 장비·벽·방과 판 입력값만 저장한다.
3. 창/콘솔이 닫힌 상태에서 Ctrl+Z를 한 번 눌러 마지막 판 추가를 되돌린다. 판 선이 없어져야 한다. 다시 콘솔에서 `vrg.Layout.Load CeilingCheck`를 실행하고 닫으면 저장한 방과 판 선이 복원되어야 한다.
4. 성공 Load 직후 Ctrl+Z/Ctrl+Y는 과거 추가를 취소/재생하지 않아야 한다(기록 초기화). 같은 Load를 한 번 더 실행해 배치가 유지되고 장비가 중복되어 보이지 않는지 확인한다. 완전히 겹친 중복 판은 선만으로 개수를 판정할 수 없으므로 목록 개수는 자동화 근거를 사용한다.
5. 시뮬레이션에 들어갔다가 배치로 복귀할 수 있는지 확인한다. 실제 판 고체는 다음 진입에 적용하며, Load하는 순간 온도나 격자를 복원하는 기능은 아니다. 열수지/압력/FPS를 화면 인상으로 판정하지 않는다.
6. 플레이/실행을 종료한 뒤 L_Test를 새로 실행한다. 콘솔에서 같은 Load를 실행하고 닫아 수동 방과 판 선이 복원되는지 확인한다. 레벨 에셋을 저장할 필요는 없다.

보고 예: `부분 천장 저장 직접 확인: Save/같은 월드 Load/반복 Load/기록 초기화/시뮬레이션 전환/새 실행 Load [정상 또는 실패 단계와 문구]`.

필드 없는 이전 v1/v2는 현 판 목록 유지, 명시적 []는 제거다. 잘못된 파일의 거절·중간 실패 원복은 자동화로 검증한다. JSON을 직접 바꿀 필요는 없다. 판 선택/삭제/핸들·배기 구멍·외부 교환·플레넘·전체 테스트/FPS는 이번 범위 밖이다.
