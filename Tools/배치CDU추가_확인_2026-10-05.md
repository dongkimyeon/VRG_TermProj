# CDU 단일 추가 직접 확인 (2026-10-05)

코드/자동화: 관련8종 무경고 성공. 실제 L_Test의 아래 입력은 미검증이다. 기존 geometry unavailable 도구 실패를 재시도하지 않았다. 자동화 수치는 CLAUDE.md 마지막 절을 따른다. 그래픽 드라이버 안내는 아니오로 진행한다. FPS는 별도 측정하지 않았다.

1. 새 L_Test 실행 후 배치 모드에만 `CDU 추가` 버튼이 있는지 확인한다.
2. 버튼을 누르고 바닥을 가리킨다. 실제 CDU/배관은 아직 늘지 않고 주황 미리보기 하나가5cm 단위로 이동해야 한다. R90°·Esc 취소를 확인한다.
3. 장비와 겹치면 빨강/클릭 생성 거절, 빈 곳 클릭은 한 대 생성과 반복 클릭 중복 없음인지 확인한다. 편집 진행 중 버튼은 새 추가를 시작하지 않아야 한다.
4. Ctrl+Z 전체 추가 취소→Ctrl+Y 같은 CDU 복원. Undo 후 원래 자리로 장비를 옮겨 충돌시키면 Redo를 거절하고 기록이 남아야 한다. 장애물을 옮긴 뒤 Redo가 가능해야 한다.
5. 추가 미리보기 중 패치 창 열기/시뮬레이션 전환은 취소, 배치 복귀 시 미리보기가 남지 않아야 한다. CDU Delete/Ctrl+D는 이번 지원 범위가 아니다.
6. 줄의 첫 랙에 기존 CDU보다 가까운 위치에 추가해 담당 CDU/배관 끝이 새 CDU로 바뀌는지 확인한다. Undo는 기존 CDU로 돌아가야 한다. 시뮬레이션에서 펌프/유량/HX 표시를 확인한다. 새 CDU가 IT 장비처럼 추가돼서는 안 된다.
7. 콘솔 `vrg.Layout.Save cdu_check` → Undo → `vrg.Layout.Load cdu_check` → Load 반복. 저장된 CDU가 한 대만 복원되고 Ctrl+Z/Y는 기록이 없어 거절돼야 한다. 실행 종료 후 새 L_Test에서 같은 Load로 위치/방향·개수 유지도 확인한다. 저장은 Saved/Layouts/cdu_check.json이며 레벨 에셋을 수정하지 않는다.

화면 근거가 필요하면 검증된 Alt+Print Screen→클립보드 PNG 저장→이미지 확인 방법을 사용한다. 이 방법의 과거 성공을 이번 입력 확인으로 확대하지 않는다. 지원하지 않는 도구 입력은 반복하지 않는다.

보고 예시: `CDU 추가 직접 확인: [모두 정상]` 또는 실패한 번호·실제 동작.
펌프 전력은 전력 평가/PUE에 포함되지만 펌프 손실의 냉각수/공기 열 분배 모델은 기존 미구현 한계다. 이번 자동화의 열수지를 실제 시설 전체 열수지 보장으로 쓰지 않는다.
