## 측정 조건

Ryzen 7 8845HS (8코어/16스레드), RTX 4060 Laptop GPU, 시스템 RAM 15.25GiB. NVIDIA 드라이버 31.0.15.4632, 하이브리드 GPU의 실제 선택은 실행 로그로 확인한다. 전력 모드/TGP/백그라운드 앱을 통제하지 않으므로 하드웨어 보장값으로 사용하지 않는다.

L_Test 원본, Editor Development의 `-game -windowed -ResX=1280 -ResY=720 -unattended -nosplash -NoSound`. DX12/기존 렌더 설정, `r.VSync 0`, `t.MaxFPS 0`, 기존 온도 볼륨/기류 기본값, 디버그 오버레이 끔. 레벨/사용자 저장 파일을 수정하지 않는다. 모드별 별도 새 프로세스를 사용한다. 실제 게임 창이 렌더된 경우만 FPS로 기록한다.

계측 명령:

```text
배치: vrg.Perf.Capture 20 S7Final_Layout quit
시뮬레이션: vrg.Air.RunSteps 1500,vrg.Air.FrameDomain,vrg.Eval.ReportWhenDone S7Final_Sim,vrg.Perf.Capture 20 S7Final_Sim quit
```

`UVrgPerfSubsystem`은 예열이 끝날 때까지 수집을 보류하고 첫 최대 30프레임을 제외한다. Frame은 실시간 프레임 간격, Game은 OnBeginFrame~OnEndFrame, Draw/GPU는 기존 엔진 계측이다. 프레임별 SolverMs와 전체 예열의 스텝 평균은 다르므로 구분한다. FPS는 Frame 중앙값의 역수이며 화면 평균 FPS와 동일하지 않다. 초기 배관/셰이더 작업이 측정에 섞이면 로그/CSV로 명시하고 성능 병목으로 단정하지 않는다.

RTX4080 과거 참조는 32랙·h0.25m·33210셀·1280×720·1500스텝/30s 예열이다. 당시 코드/시각화·CPU·계측 창은 다르므로 조건의 일치 부분만 기술하고 GPU 성능 배율로 해석하지 않는다.

## 검증 구분과 재개
