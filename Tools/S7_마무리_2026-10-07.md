## 패키지 시작 호환 문제 진단 (재개 후)
재개 패키징은 BuildCookRun159.87s/Exit0, Cook0오류/0경고로 성공했다. DX12 일반 독립 실행은 배치 화면/팔레트/배관·최초 v2 저장까지 확인한 뒤 글로벌 컴퓨트 PSO 사전 준비 중 8007000e와 종료 코드 -1073740791(0xC0000409)가 발생했다. Windows SDK winerror.h의 8007000e는 E_OUTOFMEMORY다. 실패 셰이더 이름은 unknown이어서 특정 엔진 커널이나 드라이버 내부 원인까지 확인했다고 쓰지 않는다.

Config/DefaultEngine.ini의 r.PSOPrecache.GlobalShaders=0만 호환 설정으로 적용하며, 기존 컴포넌트/머티리얼 사전 준비·물리·GPU 계산 지원은 유지한다. 첫 글로벌 PSO 사용 지연은 가능하고 다른 드라이버/장비에 최적이라고 주장하지 않는다. 공개 API 의미: [Epic PSO Precaching](https://dev.epicgames.com/documentation/unreal-engine/pso-precaching-for-unreal-engine), 실제 동작값은 UE5.8 Engine/Private/PSOPrecacheSettings.cpp 확인. 0은 엔진의 기능 끄기 값이지 새 물성/오차 기준이 아니다.
