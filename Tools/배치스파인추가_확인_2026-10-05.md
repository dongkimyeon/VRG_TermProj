# 스파인 캐비닛 추가 직접 확인 (2026-10-05)

## 실제 확인 범위

- 새 L_Test 게임 창에서 드라이버 안내를 키보드 아니오로 종료했다.
- Alt+Print Screen → 클립보드 PNG 저장 → 이미지 확인으로 배치 화면의 기존 랙/배관과 스파인 캐비닛 추가 버튼 표시를 확인했다.
- 클릭 도구는 안내 버튼에서 `coordinate input geometry is unavailable` 오류가 났다. 같은 클릭/기존 WGC 캡처를 재시도하지 않았다. Enter 후 캡처도 배치 상태여서 입력 전달/모드 전환 성공으로 판단하지 않는다.
- 아래 클릭/미리보기/키 조작·Undo/Redo·저장 UI는 실제 입력 미검증이다. 제품 결함으로 단정하거나 차단/충돌 검사를 완화하지 않았다. FPS·장시간/전체 운전은 측정하지 않았다.
- 증거는 로컬 `Saved/SpineAddition_UI_2026-10-05/01_Button.png`, `Saved/Logs/SpineAddition_UI.log`이며 커밋에서 제외한다.

## 직접 확인 절차

임시 이름으로 저장하고 시작 배치를 별도로 보관한다. 추가/Undo/Load는 실행 월드만 바꾸며 레벨 에셋은 저장하지 않는다.

1. 새 L_Test를 실행하고 배치 모드에서 **스파인 캐비닛 추가**를 누른다. 커서를 바닥 위로 움직여 주황 미리보기 하나가 따라오는지 확인한다. 이때 실제 장비/케이블은 늘지 않아야 한다.
2. R로 미리보기만90° 회전하고 Esc로 취소한다. 다시 시작해 기존 장비 위에 겹치게 가져오면 빨간색이 보이고 클릭해도 실제 스파인이 늘지 않아야 한다.
3. 빈 곳에 클릭하면 한 대만 생성되고 선택된다. Ctrl+Z로 제거, Ctrl+Y로 같은 위치/방향에 복원되는지 확인한다. 복원 위치를 다른 장비가 차지하면 Redo가 거절되어야 한다.
4. 추가 미리보기 중 패치 창 진입과 시뮬레이션 전환을 각각 확인한다. 미확정 추가는 취소되고 배치로 돌아와도 남지 않아야 한다. 시뮬레이션에는 추가 버튼이 없어야 한다. 패치 창 종료/모드 키는 현재 도움말을 따른다.
5. 스파인을 랙 줄의 기존 배정 조건에 맞게 배치하고 패치 창에서 데이터 케이블/스파인 배정을 확인한다. 조건이 맞지 않는 위치에서는 기존 미연결 진단이 남는 것이 정상이다. 스파인은 공기 냉각 장비이므로 냉각수 배관 분기가 늘지 않는 것이 정상이다.
6. 콘솔에서 `vrg.Layout.Save spine_check`로 임시 저장한다. 추가 Undo로 스파인을 지운 뒤 `vrg.Layout.Load spine_check`를 실행해 복원되는지 확인한다. 다시 Load해 중복이 생기지 않고 Ctrl+Z/Y가 이전 기록을 실행하지 않아야 한다. 콘솔을 닫고 확인한다.
7. 별도로 시작 배치를 저장했다면 그 파일을 Load해 복원한다. 저장 파일은 `Saved/Layouts`에만 생긴다. 기존 스파인 Delete/복제는 이번 기능에 포함되지 않는다.

보고 예시: 버튼/미리보기/R/Esc/충돌/확정/Undo·Redo/패치·모드 취소/케이블/저장 반복·기록 초기화를 각각 정상 또는 관찰 결과로 적는다. 전체 정상 보고는 이 절차 범위만 확인한 것으로 기록한다.

## 자동화 근거

관련8종의 성공을 확인했다. 첫8건 실행의 SaveLoadRoundTrip 실패는 v1 파일에 남은 v2 기능 표식 처리 문제로 수정했고 영향4건 재검사 모두 성공했다. 스파인 결합 fixture의 가상 CDU 경고9건은 유지한다. 입력/수량·독립 ID/설정/초기 열 상태·이전 이동 기록 재연결·별도 월드/반복 Load·기록 초기화·케이블/IT/열수지/공기 결합 검사를 통과했다.

첫 스텝 IT 증감2408.217600W/상대오차0, 전역 잔차 절댓값 최대1.549e-13, 덕트2.140e-15, 정규화 발산3.564e-08·압력 수렴. 기존 기준/단위·정규화와 공개 QM9700 참고값은 CLAUDE.md 최신 절을 따른다. 축소 NullRHI 검사를 실제 L_Test 전체 열운전/FPS 결과로 계산하지 않는다.
