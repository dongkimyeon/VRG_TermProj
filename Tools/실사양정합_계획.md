## 2. 단계

### P0. 문서·주석 정정 (물리 변경 없음)
- `Tools/누수_실시간_계획.md` L4(①⑤)·L5(④a~c), `docs/기록/09`(⑨), `RackThermalModel.cpp` NVLink 트레이 주석(⑦).
- 완료: Editor 빌드 성공(주석 변경 확인용).

### P1. CDU 계측 채널 (D9)
- CDU 계측 지점에 냉각수(2차) 유량, 공급-회수 차압, 계통 압력(CDU 기준 노드), 펌프 상태를 추가. 주기·지연·잡음·분해능은 기존 계측 규약.
- 완료: 계측 테스트에서 참값 대비 판독(지연·분해능 안), 기존 계측 테스트 유지.

### P2. TCS 냉각수 PG25
- TCS 유체(밀도·비열·점도·표면장력)를 설비수(FWS·CHW·CW = 물)와 분리한 하나의 출처로 둔다(규약: 한 곳).
  지금은 `CoolantDensityKgM3` 하나가 TCS와 설비 물을 함께 맡고 있다.
- 값: 30 °C PG25 밀도 1027.8 kg/m³·비열 3890 J/kg·K(Interstate INTERCOOL DC-300 25 %), 점도·표면장력은 공개 표로 확인해 출처를 단다(없으면 추정 표기).
  온도 의존성은 넣지 않는다(운전 범위 27~36 °C에서 상수, 한계로 기록).
- 랙 설계 유량은 체적 기준 유지(약 2.3 L/s ≈ 138 L/min, OCP 1.25~2.0 L/min/kW 안). 냉각수 열용량(랙 9.2e4 J/K 등)은 같은 부피 × PG25 ρcp로 다시 계산.
- 배관 2차 저항 계수는 설계 압력 강하에 맞춘 값이므로 유지(점도 효과는 계수에 포함된 것으로 본다, 한계로 기록).
- 누수 분사(W2)는 누수 출처별 유체(TCS = PG25, 설비 = 물). 바닥 물(W3)은 한 유체 칸이라 물 물성을 유지하고 혼합을 한계로 기록.
- 완료: 열·누수·재고 장부 보존, 타당성 안전망(ΔT 5~15 K 등), 영향 테스트 재측정·`docs/오차기준.md` 갱신.

### P3. CDU 제어와 이중화
- (a) 공급 온도 제어: 1차측 유량(고정 경계 모드 = 설비수 유량, 설비 모드 = FWS 분기 2방 밸브 개도)을 PI로 조절해 TCS 공급 온도를 설정값에 맞춘다.
  설정값 = 설계 공급 온도(설비수 + 설계 접근 온도, 운전점에서 역산·임의 여유 없음). 설계 부하에서는 밸브 전개라 지금 정상상태와 같고, 부분 부하·과도에서 차이가 난다.
  밸브 행정 시간·PI 이득은 추정. 포화(전개인데 설정 미달)는 표시한다(D5 방식).
- (b) 펌프 VFD 차압 제어: 공급-회수 헤더 차압을 설계값으로 유지(FWS가 쓰는 바깥 반복 + D3 Newton 재사용). 회전수 상한·하한은 추정, 상한 포화 표시.
  기존 `5/6` 펌프 회전수 키는 차압 설정 배율로 바꾼다(조작 의미 변경, 문서 갱신).
- (c) N+1 펌프: 줄 CDU에 운전 1 + 대기 1(체크밸브), 운전 펌프 정지 시 대기 전환. W4 CDU 침수 트립은 CDU 전체 전원 차단으로 유지(두 펌프 모두 정지).
  위상이 바뀌므로 노드·배관 번호를 쓰는 곳(잠재 누수 지점, 결합 번호, 테스트)을 전수 확인한다(반복하지 말 것: 번호 밀림).
- 재고 고갈 → 펌프 정지, W4 CDU 전원, 누수 과도와의 상호작용을 검사.
- 완료: 제어 수렴·포화 표시 테스트, 누수 시 펌프 회전수 상승과 누수량 변화가 망 재풀이로 나옴(D4), 열수지·재고 장부, Tick/RunSteps 일치, 영향 테스트 재측정.

### P4. 전원 셸프 공용 버스바 (R2 = 지금 구현)
- 셸프마다 전원 상태, 버스바 가용 용량 = 살아 있는 셸프 × 33 kW. 부하 ≤ 용량이면 슬롯 영향 없음, 넘으면 랙 전체 차단(전원 차단 순서·캡핑은 공개 근거 없음, 추정).
  PSU 손실은 살아 있는 셸프가 나눈다(기존 분담 규칙).
- W4 경로: 셸프 슬롯의 침수 트립은 그 셸프 전원만 끈다(슬롯 대응표 없음). 결과는 버스바 용량 계산으로 나온다(D4).
- 완료: 셸프 1~4개 정지 시 IT 불변·PSU 손실 재분배, 용량 초과 시 랙 전체 차단, 열수지, Tick/RunSteps 일치.

### P5. 드립 트레이 + 바닥 배수 (R1 = 트레이 + 바닥 배수)
- CDU 발판 아래 드립 트레이: 부피(추정)만큼 담고 넘친 물만 W3 바닥으로. 트레이 안 스팟 센서(실제 물 판정, W5 (나)가 그대로 씀).
- 바닥 배수구: 위치·지름·배수 능력은 추정(배치 정보로 둔다). 배수량 = 칸 수심 기반 오리피스 식, 물 장부에 배수 유출 항목 추가.
- 2026-10-27 결정(경사 0·배수 없음)을 2026-11-03 사용자 결정으로 대체. 경사는 0 유지.
- 완료: 물 장부(분사 + 바닥 + 트레이 + 배수 = 누적 누수) 보존, 배수 없는 기존 테스트 결과 유지(배수구 0개일 때 비트 동일), 트레이 넘침 시각이 부피/유량과 일치.

### P6. 이슬점 검사 (R3 = 검사만)
- 방 이슬점(입력값 하나, 기본값은 ASHRAE 권장 범위 안의 값, 추정)과 냉각수·냉수 공급 온도 비교. 공급 < 이슬점 + 2 K면 경보·리포트 표시. 습도 수송·잠열 없음(한계).
- 완료: 경계값 테스트(이슬점 + 2 K 위/아래), 리포트 항목.
