# 수동 방 범위·공기 도메인 기반

이번 범위는 **설정 API와 검증된 공기 격자 연결**이다. 방 편집 UI/핸들, 벽·천장 판, Undo와 배치 저장 파일 연결은 아직 없다. 기존 `ADataCenterRoomActor`는 줄·배관을 계속 관리하고, 방 설정은 `ADataCenterSimulationActor`가 소유한다. 계획의 별도 RoomShell 액터 분리는 이번에 도입하지 않았다.

## 호출

배치 모드에서 C++로 설정한다. 기본 설정의 `bManual=false`는 기존 자동 맞춤이다.

```cpp
FRoomAirDomainSettings Settings;
Settings.bManual = true;
Settings.MinXYM = FVector2D(-5.5, -4.5);
Settings.MaxXYM = FVector2D(5.1, 4.6);
Settings.CeilingHeightM = 3.1;
FString Reason;
if (Sim->TrySetRoomAirDomain(Settings, Reason))
    Sim->EnterSimulationMode();
```

위 수치는 자동화용 합성 방이며 실제 시설 규격/추정 물성이 아니다. 최소/최대 XY는 월드 m, 바닥은 Z=0m, 천장 높이는 바닥에서의 m이다. 액터의 UE 위치 변환은 경계에서만 수행한다. `ValidateRoomAirDomain`은 적용 없이 계획 격자와 실제 경계를 반환한다. 거절 사유는 반환 문자열/`GetRoomAirDomainMessage()`로 확인한다. 시뮬레이션 진입 거절은 기존 로그와 화면 메시지에도 표시한다.

## 격자 결정

- 셀 크기 h는 기존 AirField의 `GridParams.CellSizeM`을 사용한다. 방 맞춤의 기존 최소0.01m, 축당128셀 정책을 공통 상수로 재사용한다. 잘못된 h나 한도 초과는 거절하며 h/범위를 자동 변경하지 않는다.
- 각 축 셀 수는 `ceil(요청 길이/h)`. 원점은 `(MinX, MinY, 0)`, 실제 최대는 `원점+셀 수*h`이다. 요청 최대를 안쪽으로 잘라내지 않는다. 각 최대 면의 확장은 0 이상 h 미만이며 부동소수점 경계에서는 한 셀까지 늘 수 있다. 실제 벽을 정확한 요청 좌표에 만드는 기능은 없다.
- 예: 요청10.6×9.1×3.1m, h0.25m → 43×37×13=20683셀, 실제10.75×9.25×3.25m. 원점(-5.5,-4.5,0), 최대(5.25,4.75,3.25)m.
- 수동 모드에는 자동 맞춤의 `vrg.Air.CellSize` 고정 span quantum을 적용하지 않는다. 자동 모드 알고리즘은 유지한다. GPU 자동 선택100000셀은 자원 상한이 아니며 기존 ResetSim의 선택 정책을 그대로 따른다. 이번 자동화는 NullRHI/균일 CPU 격자다.

## 포함 검사와 적용 순서

수동 설정을 받아들이기 전, 그리고 시뮬레이션 진입 직전에 다시 검사한다. 사이에 장비/셀 크기가 바뀌면 이전에 받은 설정도 거절될 수 있다.

장비의 기존 배치 상자 치수를 재사용하고 8개 모서리에 전체 회전/스케일/높이를 적용한다. 랙·스파인·CDU·CRAH 외형을 검사한다. 공기 결합에는 기존 솔버의 수평 방향/원래 치수에 의한 흡기·배기 표본 깊이와 팬 이웃 유체 셀도 포함한다. 인로우는 앞/뒤, 벽면형은 앞/위에 h 여유를 요구한다. 콜드아일 지붕을 쓰면 기존 한 셀 두께도 천장 안이어야 한다. **셀 올림으로 생긴 확장에 기대어 요청 방 밖 장비/덕트를 허용하지 않는다.**

실제 CRAH가 없으면 살아 있는 랙·스파인에서 기존 자동 CRAH 계획을 다시 구한다. 이전 격자에 맞춰 필터링하거나 액터로 전환하지 않는다. 계획 캐시도 복구한다. 기존 격자에서 누락될 자동 CRAH를 수동 방 검증에서 숨기지 않는다.

유효한 경우에만 기존 줄/수력 재구축 → 계획 격자 적용/Reset → 랙 Reset → 공기/열 결합으로 진행한다. 실패는 모드·시계·격자·모델·줄/배관을 변경하기 전에 반환한다. 예열 명령도 거절된 진입을 우회하지 않는다. AirField가 뒤늦게 BeginPlay해도 이미 구성된 수동 통합 격자를 독립 자동 맞춤/Reset으로 덮어쓰지 않는다.

## 제한과 다음 작업

- 현재 솔버의 장비 공기 고체/덕트는 수평 방향과 원래 치수를 사용한다. 수동 방 포함 검사가 전체 외형 변환을 검사한다는 사실을, 기울기/스케일을 반영한 새 유동 모델 구현으로 해석하지 않는다. 덕트 면 방향의 기존 최근접 격자축 정책도 유지한다.
- 경계 열 교환/벽 재료/플레넘/누기/정상상태/시설 전체 정확도는 이번에 추가하지 않았다. 기존 단열 공기 경계와 물리 모델 부채를 유지한다.
- 현재 배치 저장 v1/v2에는 방 설정이 없다. Save/Load 후에도 현 실행 월드의 방 설정은 그대로 남고, 새 실행에서는 별도 설정하지 않으면 자동 맞춤이다. 방 설정 Undo/저장 연동은 후속이다.
- 후속: 방 설정 UI·핸들, 방 설정 Undo/저장, 벽/천장 판과 고체 셀, 외부 열 교환·플레넘. 실제 화면/FPS/전체 Automation 반복은 수행하지 않는다.

실제 빌드/검사 결과와 정규화·측정값은 CLAUDE.md 최신 방 기반 절을 따른다.
