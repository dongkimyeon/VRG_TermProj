# 부분 천장 선택·삭제 직접 확인

기존 추가 UI/Undo 및 저장은 사용자 직접 정상 보고를 반영했다. 아래 새 선택/삭제 버튼·초록 강조·실제 클릭/입력은 아직 미확인이다. 기존 화면 도구 실패를 반복하지 않는다.

1. L_Test 배치 모드에서 직접 정상 확인한 수동 방/판을 준비한다. 방 범위 편집이 켜져 있으면 먼저 Esc로 종료하고 숫자 창/패치도 닫는다. 자동 방에서는 천장 선택·삭제 버튼이 비활성이다.
2. ‘천장 선택·삭제’를 누르면 버튼이 ‘천장 편집 끄기’로 바뀌고 안내에 선택 번호/판 수가 나온다. 카메라를 비스듬히 위에서 내려다보고 주황 판 상자의 내부를 클릭한다. 선택된 실제 계산 상자는 초록 굵은 선으로 강조되어야 한다. 요청 청록/일반 주황 선은 유지한다.
3. 이 모드에서는 장비 클릭/사각형 선택/장비 드래그/추가·복제·R·G·T가 시작되지 않아야 한다. 기존 우클릭 카메라/이동/휠은 사용할 수 있어야 한다. 빈 곳을 클릭하면 선택 번호0으로 돌아가고 초록 강조가 사라진다. 이때 Delete는 아무것도 삭제하지 않는다.
4. 판을 다시 클릭하고 Delete를 한 번 눌러 그 한 장만 삭제한다. 선택은 해제되고 판 수가 한 개 줄어야 한다. Ctrl+Z는 판을 복원, Ctrl+Y는 재삭제한다. 실제 공기 고체는 다음 시뮬레이션 진입에만 바뀐다.
5. 동일한 수치로 판을 두 장 추가한 사례에서는 같은 위치 클릭이 목록의 첫 번째 판을 선택한다. Delete 한 번 뒤에도 다른 판의 선이 남고 판 수만 한 개 줄어야 한다. 중첩된 판을 순환/다중 선택하는 기능은 이번에 없다. Ctrl+Z/Y로 목록 전체가 원래 순서대로 복원되어야 한다.
6. 판 선택 후 ‘부분 천장 추가’나 ‘방 설정’ 창을 열면 천장 편집이 종료되어야 한다. 숫자 입력 중 Delete/장비 단축키는 월드를 바꾸면 안 된다. 닫은 뒤 천장 편집에 다시 진입할 수 있어야 한다. 패치/시뮬레이션 전환도 편집·선택을 종료한다.
7. Esc 또는 ‘천장 편집 끄기’로 종료하면 일반 장비 클릭/드래그가 다시 동작해야 한다. 판 선은 장비 클릭을 가로막지 않아야 한다.
8. 삭제 결과를 `vrg.Layout.Save CeilingDeleteCheck`로 저장하고 `vrg.Layout.Load CeilingDeleteCheck`로 복원한다(콘솔은 ~로 열고 닫는다). 성공 Load는 선택·천장 편집·Undo/Redo를 초기화한다. 이전 선택으로 다른 판이 삭제되지 않아야 한다. 새 실행에서도 같은 Load로 삭제 결과가 유지된다. 정확한 목록 개수/중간 실패/물리 수치는 자동화 근거를 따른다.

보고 예: `부분 천장 선택·삭제 직접 확인: 버튼/클릭·빈 곳/초록 강조/한 장 삭제/중복 판/Undo·Redo/입력 차단·복귀/저장 Load [정상 또는 실패 단계와 문구]`.
