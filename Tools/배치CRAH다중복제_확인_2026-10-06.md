# 다중 CRAH 복제 직접 확인 (2026-10-06)

환경 변화 없는 다중 선택 도구 실패는 재시도하지 않았다. 이번 그룹 복제의 실제 화면/입력은 미검증이며, 아래 절차로 확인한다. 자동화 결과와 FPS 확인을 대신하지 않는다.

1. L_Test 배치 모드에서 실제 CRAH 두 대를 Shift+클릭해 모두 선택한다. 기존 배치·자동 전환·런타임 장비를 조합해 본다. 자동 쿨러가 아직 값 배치라면 기존 인로우 추가로 실제 장비로 전환한다.
2. Ctrl+D: 원본은 그대로 있고 미리보기 두 개가 상대 위치·높이·방향·스케일을 유지해야 한다. R을 눌러도 그룹 미리보기는 회전하지 않는다. 한 대만 선택하면 기존 R90°가 동작해야 한다.
3. 원본과 중첩시키면 빨강·클릭 거절, 빈 목적지는 주황이어야 한다. Esc로 두 미리보기가 모두 사라지고 개수는 유지되어야 한다. 패치 창/시뮬레이션 전환도 전체 취소여야 한다.
4. 다시 시작해 빈 곳 클릭: 두 대만 생성되고 원본은 유지된다. Ctrl+Z로 두 복제본만 제거, Ctrl+Y로 함께 복원해야 한다. 다른 장비가 섞인 선택은 Ctrl+D를 거절해야 한다.
5. 저장 후 배치를 바꾸고 같은 파일을 두 번 Load한다. 추가 개수·위치·종류·설정이 복원되며 중복 없음, Ctrl+Z/Y 과거 기록 초기화를 확인한다. 새로 실행한 L_Test에서도 같은 파일을 두 번 Load해 확인한다.

드라이버 안내가 나오면 아니오로 진행한다. 화면 기록은 Alt+Print Screen → 클립보드 PNG 저장 → 이미지 확인을 사용한다. 기존 캡처 API는 반복하지 않는다. 저장은 실행 배치 파일만 사용하며 레벨 에셋은 수정하지 않는다.
중간 실패 원복·복원 충돌·정량 열수지/압력은 자동화 검사 범위이며, 화면만으로 판정하지 않는다. 총풍량/냉각 용량이 대수에 비례 증가해야 한다는 기대는 두지 않는다.
