## 범위와 순서 결정

사용자 요청으로 W3.5 성능 검사/최적화를 후속 유예하고 W4-1에 착수한다. D10 목표60/최저30FPS·최신 정상50.446/누수12.715FPS 기록과 W3.5 전체 미완료는 유지한다. 성능 통과, W3.5/W4 전체 완료로 처리하지 않는다.

## 노출 집계

`Simulation/Water/WaterExposure.h/.cpp`의 Collect에 기존 Spray.GetGeometry/GetWetting, Floor.GetFloods, RackInteriorCoupling.GetWater 및 명시적 랙 ID 대응을 공급한다. 시간은 공통 SimTimeS의 동일 시점이어야 한다. 이 단계에서는 액터/Tick/RunSteps에 등록하지 않은 독립 API이다.

| 입력 | 의미 | 해석/한계 |
|---|---|---|
| SprayTouchedM3 | W2 상자 누적 접촉량 | 유일한 이동 질량 아님. 내부/바닥에 다시 나타날 수 있음. 슬롯 할당 불가 시 한 진단만 남기고 슬롯 값은0/미가용 |
| FloodImmersionM | max(0,발판 평균수심−명시한 접촉높이) | m; 국소 최대수심·전기 접점 형상은 추정하지 않음. 접촉높이는 바닥 bed 기준 간극+슬롯 높이 |
| InteriorPassedM3 | 정확한 슬롯의 기존 누적 통과량 | RearPassed가 포함된 이력. 물량 합산/새 유량 적분 없음 |
| InteriorHeld/MovingM3 | 현재 내부 보유·앞 경로 이동량 | 기존 SoA 복사만 함 |
| RearMoving/PassedM3 | 뒤쪽 현재 이동량/누적 노출 | 뒤쪽 우회가 내부 보드에 도달했다고 간주하지 않음 |

Available 비트로 ‘0을 관측함’과 ‘그 슬롯을 알 수 없음’을 구분한다. 장비 ID+슬롯은 중복 불가; source index/ID/높이/finite·nonnegative/SoA 오류는 이유와 함께 거절하고 Out을 유지한다. 동일 물이 여러 접촉 기록에 있어도 합계 물량 필드를 만들지 않는다. 관측은 물·열·수력 상태를 변경할 API가 없다.
