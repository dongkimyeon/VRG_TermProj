# W4-1 침수 관측·상태 독립 기반 (2026-11-01)

## 범위와 순서 결정

사용자 요청으로 W3.5 성능 검사/최적화를 후속 유예하고 W4-1에 착수한다. D10 목표60/최저30FPS·최신 정상50.446/누수12.715FPS 기록과 W3.5 전체 미완료는 유지한다. 성능 통과, W3.5/W4 전체 완료로 처리하지 않는다.

## 노출 집계

`Simulation/Water/WaterExposure.h/.cpp`의 Collect에 기존 Spray.GetGeometry/GetWetting, Floor.GetFloods, RackInteriorCoupling.GetWater 및 명시적 랙 ID 대응을 공급한다. 시간은 공통 SimTimeS의 동일 시점이어야 한다. 이 단계에서는 액터/Tick/RunSteps에 등록하지 않은 독립 API이다.

| 입력 | 의미 | 해석/한계 |
|---|---|---|
| SprayTouchedM3 | W2 상자 누적 접촉량 | 유일한 이동 질량 아님. 내부/바닥에 다시 나타날 수 있음. 슬롯 할당 불가 시 한 진단만 남기고 슬롯 값은0/미가용 |
| FloodImmersionM | max(0,발판 평균수심−명시한 접촉높이) | m; 국소 최대수심·전기 접점 형상은 추정하지 않음. 접촉높이는 바닥 bed 기준 간극+슬롯 높이 |
| InteriorPassedM3 | 정확한 슬롯의 기존 누적 통과량 | RearPassed가 포함된 이력. 물량 합산/새 유량 적분 없음 |
| InteriorHeld/MovingM3 | 현재 내부 보유·앞 경로 이동량 | 기존 SoA 복사만 함 |
| RearMoving/PassedM3 | 뒤쪽 현재 이동량/누적 노출 | 뒤쪽 우회가 내부 보드에 도달했다고 간주하지 않음 |

Available 비트로 ‘0을 관측함’과 ‘그 슬롯을 알 수 없음’을 구분한다. 장비 ID+슬롯은 중복 불가; source index/ID/높이/finite·nonnegative/SoA 오류는 이유와 함께 거절하고 Out을 유지한다. 동일 물이 여러 접촉 기록에 있어도 합계 물량 필드를 만들지 않는다. 관측은 물·열·수력 상태를 변경할 API가 없다.

## 상태 모델 API와 정책

`WaterImpactModel.h/.cpp`: `Reset(Baseline, Powered, Policy, Error)`와 `Step(Snapshot, Powered, Error)`를 제공한다. UObject/자체 시계/솔버 상태 접근은 없다. 같은 공통 SimTime 관측을 전달해야 한다. 소스의 실제 계산 시각이 서로 맞는지는 호출자가 보장해야 하며 현재 독립 API는 이를 추정하지 않는다.

- 장비 ID+슬롯+Available 대응을 고정한 flat SoA; 변경 시 명시적 Reset이 필요하다. 한 모델 인스턴스는 한 명시적 정책을 공유하는 대상 묶음이다. 다른 장비 정책은 별도 인스턴스로 구성할 수 있다. 장비별 운영 정책 레지스트리는 후속이다.
- Normal/Wet/Tripped/Damaged 상태·처음 노출/트립/손상 시각·활성 접촉 종류·전이 사건을 보관한다. Normal은 ‘설정된 소스에서 증거 없음’이며 미분류 슬롯의 전기적 안전을 보증하지 않는다.
- Spray는 **이번 관측 사이의 접촉 누적 증가분**, 내부는 현재 보유/앞쪽 이동 또는 새 통과량 중 뒤쪽 우회를 제외한 도착분, Rear는 현재 뒤쪽 이동/새 뒤쪽 노출, Flood는 현재 침수 깊이로 판독한다. Passed 전체/Rear 이력을 더하지 않는다. 관측 사이 이미 지나간 앞쪽 물을 놓치지 않되 뒤쪽 우회만으로 보드 접촉을 강제하지 않는다.
- 여러 종류가 겹쳐도 접촉 시간은 한 번만 센다. 문턱과 같으면 미전이, 초과하면 접촉으로 본다. 노출 마스크/각 m³·m 문턱/통전 연속 접촉 트립 시간/트립 후 연속 접촉 손상 시간/최대 관측 간격을 모두 명시한다. 누적 물량 손상 경로는 이번 기반 범위 밖이다.
- 시간 정책은 **이전 관측을 다음 관측까지 유지(hold)**하는 방식을 호출자가 명시적으로 선택한다. 새 도착에 과거 dt를 소급 적용하지 않는다. 연속 접촉 지속시간은 샘플링 가정이며 실제 전기 접촉 시간의 실측값이 아니다. 관측 간격이 문턱/유동 시간보다 크면 판정 오차가 커질 수 있어 MaxObservationGapS를 명시해야 한다. 분사/도착 펄스 문턱은 관측 간격에 의존한다; 서로 다른 샘플링의 동일 판정은 보장하지 않는다.
- 통전 중 연속 접촉이 트립 문턱을 채우고, 트립 후 연속 접촉이 손상 문턱을 채운다. 한 유효 간격 안 여러 전이의 정확한 교차 시각을 계산한다. 미접촉은 연속 시간 누적을 끊는다. 경고는 명시적 latch/건조 시 경고 해제 중 선택한다. 트립/손상은 수리나 건조로 자동 복구하지 않는다. Reset만 실행 상태를 초기화한다. 실제 물을 배수하지 않으므로 남은 물이 있는 baseline은 다시 Wet일 수 있다.
- 기본 policy는 모두 미설정(-1/Unspecified)이며 실행 거절한다. Basis와 설명은 필수다. SyntheticTest/UncalibratedEstimate/PublicSource를 구분하고 PublicSource는 출처 문자열 목록을 요구한다. 출처 자체의 품질은 호출자/팀 검토 대상이다. 이 구현은 공개 장비 고장 문턱을 새로 확정하지 않았다. 기존 L4의 ‘수 초’ 등은 추정 예시이며 운영 기본값으로 채택하지 않았다.
- 시험의 0 문턱·2s 트립·3s 손상·10s 최대 간격과 .01m 침수 문턱은 **결정성/경계 검사 전용 합성 수치**다. 실제 장비 고장 자료/추정 사양/공개 출처로 표현하지 않는다.
- 잘못된 policy·배열·nonfinite/음수·중복 대상·동일/역행/과도 간격 시각·누적 이력 역행·타깃/소스 대응 변경은 상태/사건/시계를 변경하지 않고 거절한다. 소스 재시작에는 새로운 baseline Reset을 함께 적용해야 한다.
