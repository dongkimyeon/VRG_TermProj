# 설비 장비 외형 모델링 요청 (2026-10-21)

이 문서만 읽고 바로 모델링을 시작할 수 있게 썼다. 막히면 아래 "참고할 기존 작업"의 CDU·CRAH 폴더를 그대로 따라 하면 된다.

## 배경 (1분 요약)

이 프로젝트는 AI 데이터센터 냉각 디지털 트윈이다(UE 5.8). 방 안 장비(랙·스파인·CDU·CRAH)는 이미 외형 모델이 있다.
2026-10-20~21에 **방 밖 설비 마당**(드라이쿨러·칠러·펌프·판형 열교환기)을 넣었는데, 지금 화면에는 **엔진 기본 큐브**만 보인다.
이번 작업은 이 장비들의 외형 메시를 만드는 것이다. **물리 계산은 바뀌지 않는다**(화면 표시만).

- 장비는 방 공기 영역의 +X 쪽 바깥 바닥에 줄지어 놓인다. 드라이쿨러는 L_Test 기준 수십 대(FWS 24 + CW 8)가 깔린다.
- 배치 모드에서 사용자가 옮기고 돌리고 추가·삭제한다(`APlantEquipmentActor`).
- 배관은 계산된 망을 코드가 실린더로 그린다. **배관은 모델링하지 않는다.**

## 지켜야 할 규칙 (모든 모델 공통)

1. **좌표계:** 원점 = **바닥 중심** (밑면 중앙, Z = 0). **+X = 전면**, +Y = 폭, +Z = 위.
   (Blender에서도 같은 축으로 만든다: 전면이 +X를 보게.)
2. **크기:** 손잡이·그릴·플랜지까지 전부 **명목 상자 안**(X: ±X/2, Y: ±Y/2, Z: 0~Z)에 들어가야 한다.
   경계 오차 1e-6 m 이하. 코드가 `실제 크기 / 명목 크기`로 스케일하므로 상자를 벗어나면 다른 장비와 겹쳐 보인다.
3. **단위:** Blender 원본·GLB는 **m**, FBX는 **cm**(아래 내보내기 설정).
4. **메시:** 장비 하나 = **단일 메시**(여러 부품을 하나로 합침), 삼각형화, **UV0 1개**, 충돌 없음, 뒤집힌 법선 없음.
5. **재질:** 텍스처 없이 **단색 PBR 재질 슬롯**만. 이름은 `MC_Plant_<부위>` (예: `MC_Plant_Body`, `MC_Plant_Grille`, `MC_Plant_Fan`,
   `MC_Plant_Pipe`, `MC_Plant_Panel`, `MC_Plant_Screen`, `MC_Plant_Hardware`). 여러 모델이 같은 재질을 공유해도 된다. 장비당 8개 이하.
6. **금지:** 제조사 로고·상표·글자·사진 텍스처. 제조사 CAD를 그대로 가져오지 않는다(사진은 외형 참고만).
7. **배관·케이블은 만들지 않는다.** 플랜지·노즐(짧은 원통)까지만.

## AI 도구로 만들 때 주의

AI 3D 생성(텍스트·이미지 → 메시)이나 Blender 자동화(스크립트 생성)를 써도 된다. 다만 결과물을 그대로 넣으면 안 되는 경우가 많다.

- **스크립트 방식 권장:** 기존 `Art/CRAH/build_crah.py`처럼 **Blender Python으로 상자·원통·링을 조합해 생성**하게 하면
  크기·원점·삼각형 수가 정확하게 나오고 다시 생성하기도 쉽다. AI에게 "이 파일 방식을 따라 드라이쿨러를 만드는 build_plant.py를 써 줘"라고 시키면 된다.
- **생성형 메시를 쓸 때:** 크기·원점을 다시 맞추고, 삼각형 수를 줄이고(Decimate), 구멍·뒤집힌 면을 고치고, 텍스처를 버리고 단색 재질 슬롯으로 바꾼다.
  생성형 메시는 대칭·평면이 깨져 있는 경우가 많아 데이터센터 장비답게 안 보이기 쉽다.
- 결과를 반드시 아래 "검사"로 확인한다.

## 내보내기 (CRAH와 같은 설정)

`Art/CRAH/build_crah.py`의 `export_model()`을 그대로 쓰면 된다. 요점:

- 부품을 합친 뒤 원점을 (0,0,0)에 두고 `transform_apply(location, rotation, scale)`, `uv.smart_project(island_margin=.008)`, 삼각형화.
- **GLB:** m 그대로 `export_scene.gltf(..., use_selection=True)`.
- **FBX:** 정점을 100배(cm) 한 뒤 `unit_settings.scale_length = .01`,
  `export_scene.fbx(..., object_types={'MESH'}, axis_forward='-Y', axis_up='Z', apply_unit_scale=True, apply_scale_options='FBX_SCALE_NONE', bake_space_transform=False, mesh_smooth_type='FACE', bake_anim=False)`, 그다음 원래대로 되돌린다.

## 넘겨줄 파일 (이 폴더 `Art/Plant/`에)

| 파일 | 내용 |
|---|---|
| `Plant_Reference.blend` | 부품별 편집 원본(장비마다 컬렉션 하나) |
| `build_plant.py` | (스크립트로 만들었다면) 원본·FBX·GLB·렌더 재생성 스크립트 |
| `SM_Plant_*.fbx`, `SM_Plant_*.glb` | 장비마다 하나씩 |
| `materials.json` | 재질 표. 형식은 `Art/CRAH/materials.json`과 같다: `{"MC_Plant_Body": [[R, G, B], 금속성, 거칠기], ...}` (0~1) |
| `verification.json` | 장비마다 명목 크기, 실제 경계 min/max, 최대 경계 오차, 정점·삼각형 수, 재질 목록, UV 수, 원점, 전면 축 (`Art/CRAH/verification.json` 형식) |
| `plant_*_preview.png` | Blender 렌더 미리보기(장비마다 앞 사선 1장, 가능하면 위에서 1장) |
| `README.md` | 무엇을 만들었는지, 참고한 사진 출처(외형 참고만), 한계 |

## 검사 (넘기기 전에)

- [ ] 원점이 바닥 중심이고 +X가 전면이다
- [ ] 경계 = 명목 상자 (오차 < 1e-6 m)
- [ ] 삼각형 수 ≤ 상한, UV0 있음, 단일 메시, 텍스처 없음
- [ ] 재질 이름이 `MC_Plant_*`이고 `materials.json`에 전부 있다
- [ ] 로고·글자 없음
- [ ] 미리보기 PNG에서 장비가 무엇인지 알아볼 수 있다(드라이쿨러 팬, 칠러 원통 두 개 등)

## 넘긴 뒤 우리(코드) 쪽에서 할 일

친구가 할 일이 아니다. 참고로만 적는다.

1. `Tools/install_plant_model.py`(= `Tools/install_crah_model.py` 방식): 재질과 메시를 `/Game/Connections`에 가져온다.
2. `APlantEquipmentActor`와 설비 마당 표시(`AFacilityPlantDisplayActor`)가 큐브 대신 이 메시를 쓰게 하고, 에셋이 없으면 큐브로 돌아가게 한다.
3. 지금 상태 색(운전·정지·고장)은 장비 위에 큰 상자를 덮어씌워 보여 주는데, 모델이 가려지므로 테두리·몸체 색 방식으로 바꾼다.
4. UE 5.8에서 임포트 검사(`verify_*` 스크립트), 영향 자동화 테스트, L_Test 화면 확인.
