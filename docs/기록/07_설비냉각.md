계획·근거 표·결정은 `Tools/설비냉각_계획.md`. 오차 기준은 `docs/오차기준.md`의 "S8 설비 냉각".

## 2026-10-20 F0: 근거 수집

ASHRAE W등급(2021 TC 9.9 백서), GB200 NVL72 냉각수 조건(QCT·Chilldyne 벤더 문서, NVIDIA 원문은 미확인), Liebert 드라이쿨러 성능 표(외기 35 °C 정격),
EnergyPlus 칠러 데이터셋(곡선 범위 냉수 ≤ 12.78 °C, 응축수 ≤ 35 °C)을 원문으로 확인해 근거 표에 정리했다.
사용자 결정: FWS 공급 32 °C(W32), 칠러는 카르노 비 외삽(추정), 설계 외기 35 °C, F8 진행.

## 2026-10-20 F1: 설비수(FWS) 수력망과 구성 빌더

`Simulation/Hydraulics/FacilityWaterLoop.*`: 흡입(팽창탱크 고정 압력) → 펌프 N+1(체크밸브 배관, 대기 펌프는 그 배관을 닫음) → 공급 본관 → 공급 헤더 →
CDU 분기(공급 배관·2방 밸브·열교환기 1차측·회수 배관) → 회수 헤더 → 회수 본관 → 드라이쿨러 코일(병렬) → 흡입. 같은 D3 Newton 솔버를 쓰는 별도 망이다.
- 구성은 빌더 입력(`EPlantTopology`). F1은 분리(Separate)만 만들고, 공용 냉수·직렬은 F6에서 같은 빌더에 넣는다.
- 크기 규칙(구성 공통, D8): 모든 요소 저항 = 설계 압력강하 / 설계 유량². 밸브 전개 설계 유량에서 권위 0.5, 동일 퍼센트 특성 `Kv/Kvs = Rv^(x−1)`(Rv 50),
  펌프 체절/설계 양정 1.25, 효율 0.7. 드라이쿨러 코일은 Liebert 940형 910 L/min·37 kPa(원문), 나머지 압력강하·권위·Rv·체절비·효율은 **추정값**(코드 주석).
  설계점(밸브 전개, 설정 차압)에서 각 분기가 정확히 설계 유량을 흐르고 펌프 속도가 1이 되게 맞춘다.
- 제어: 운전 펌프 공통 회전수로 공급-회수 헤더 차압을 설정(설계 분기 강하)에 맞춘다. 거짓 위치법(Illinois) + 상·하한 포화 표시(D5).
- 결합: `vrg.Plant.Enable 1`(기본 0)이면 CDU 그룹이 FWS 분기가 되고 열교환기가 분기 유량을 받는다. 설계 유량 = 기존 역산 유량이라 켜도 결과가 같다(회귀).
  FWS 공급 온도는 F2 전까지 CDU 고정값. FWS 펌프 전력은 로그·결과에만 있고 부분 PUE·전역 장부에는 F5에서 넣는다.
- 검증: 신규 `VRG.Plant.Fws.*` 5건 + 영향(`VRG.Hydraulics`·`Coupling`·`Web`·`Eval`) 합계 59건 성공(NullRHI, RTX 3060 노트북).
  설계점 분기 상대 오차 1.5e-14·속도 1, 차압 제어 아래 분기 유량 = √(Δp/R) 상대 1.8e-14, 밸브 0.05~1 단조·다른 분기 변화 1.7e-12,
  N+1 전환 차 0·고장 펌프 유량 정확히 0, 펌프 1대면 속도 1.2에서 포화(121.7/140 kPa) 표시, 설비 켬/끔 랙 냉각수 온도 차 0 K.
  타당성: 펌프 18.9 W/gpm(90.1 기준 22 W/gpm 대비, 2차 자료).
- L_Test -game(`vrg.Plant.Enable 1`): CDU 분기 4, 총 78.40 L/s(설계와 같음), 드라이쿨러 코일 6, 펌프 22.68 kW(IT 약 3.3 MW의 0.7 %), 제어 9회. 화면 확인 안 함(로그).

## 2026-10-20 F2: 설비수 열과 드라이쿨러

`Simulation/Plant/DryCooler.h`, `Simulation/Plant/FacilityPlant.*`.
- 드라이쿨러: 교차류 양측 비혼합 ε-NTU(Incropera 표 11.3 근사식). UA는 Liebert 940형 정격점(275 kW @ ITD 13.9 K, 외기 35 °C, 43,400 CFM, 910 L/min 40 % EG)에서
  역산해 66.0 kW/K(NTU 2.80, 공기가 C_min). 팬 회전수비 r에 대해 풍량 ∝ r, UA ∝ r^0.6(추정), 팬 전기 = 정격 모터 출력/효율 0.85(추정) × r³(같은 팬·같은 코일의 운전점, D8).
  EG 물성(1050 kg/m³, 3580 J/kgK)은 추정이며 정격점에서 C_max라 Cr로만 들어간다. 외기는 표준 대기압 이상기체.
- 설비 물: 공급 쪽·회수 쪽 두 혼합 체적(설계 유량 × 통과 시간 60 s, 추정). CDU가 공급 체적 온도를 보고, 결합이 한 번 계산한 듀티를 그대로 회수 체적에 넣는다(규약 6).
  `C_s ΔT_s + C_r ΔT_r = (Σ듀티 − 드라이쿨러) dt`가 구성상 성립해 설비 장부(유입 = 듀티, 유출 = 드라이쿨러, 축적 = 두 체적)가 반올림 수준으로 닫힌다.
  명시적 오일러, 짧은 시간 상수의 1/5 이하로 하위 스텝.
- 제어: 모든 드라이쿨러 팬 공통 속도로 출구 = 공급 설정(32 °C). 목표 속도는 현재 회수 온도에서 이분법, 적용은 변화율 0.05 /s(추정) 제한.
  목표가 최고 속도를 넘으면 "설정점 미달"(누적 시간), 최저 속도(0.1)에서도 차가우면 "과냉" 표시. 트림 칠러는 F3.
- 대수: 카탈로그 선정 규칙 `ceil(설계 열 / (정격 열 × ITD_설계 / ITD_정격))`, ITD_설계 = 설계 회수(설정 + 상승) − 설계 외기 35 °C(구성 공통 규칙).
- 결합: `vrg.Plant.Enable 1`이면 스텝마다 CDU 설비수 입구 = 설비 공급 체적, 결합 뒤 같은 듀티로 설비가 적분된다(일반·예열 경로 모두).
  `PlantThermalSpec.bFixedSupplyTemp`는 옛 고정 경계 비교 옵션(F1 회귀 테스트가 이것으로 돈다). 외기: `vrg.Plant.Ambient <C>`, 이벤트 `vrg.Eval.Event <t> ambient <C>`.
  전역 열수지 경계는 아직 CDU(설비 쪽은 자체 장부), 드라이쿨러 팬·FWS 펌프 전력은 부분 PUE에 아직 없다(F5).
- 검증: 신규 `VRG.Plant.DryCooler.CatalogRoundTrip`, `VRG.Plant.FwsThermal.*` 3건 포함 영향 63건 성공.
  정격 재현 1.9e-15, 제어 정상상태 공급 = 설정 < 1e-6 K, 포화 정상상태 = 닫힌 해 < 1e-6 K(외기 35 °C 공급 36.30 °C, 40 °C 41.33 °C), 설비 장부 ≤ 6e-13,
  결합 방: 설비 듀티 = CDU 듀티 정확 일치, 외기 40 °C가 20 °C보다 랙 냉각수 입구가 높음(39.14 > 31.86 °C, 고정 22 °C 경계 25.64 °C).
- L_Test -game(`vrg.Plant.Enable 1`, 외기 15 °C → 45 s에 35 °C, 90 s): 드라이쿨러 24대(팬 전체 126 kW = IT 3.27 MW의 3.9 %).
  외기 15 °C에서는 팬 최저에서도 과냉(공급 30.6 °C), 35 °C로 바뀐 뒤 팬 1.0 포화·설정점 미달, 90 s에 공급 32.9 °C로 오르는 중. 설비 장부 ≤ 1.7e-11. 화면 확인 안 함(로그).
- **한계:** 설비 물은 32 °C 설정에서, 랙 냉각수는 기존 초기값(약 22 °C)에서 시작해 처음 수십 초 CDU 듀티가 음수다(초기 조건 차이의 과도, 예열로 지나감).
  대수 단계 제어·바이패스가 없어 차가운 외기에서 과냉한다. 단열(분무) 예냉 없음. 드라이쿨러 수측 유량 변화에 따른 UA 변화 없음.

## 2026-10-20 F3 본체: 냉수(CHW)·응축수(CW) 루프와 칠러

`Simulation/Plant/Chiller.h`(DOE-2 곡선, EnergyPlus `Chillers.idf`의 Carrier 19XR 1558 kW/COP 5.81/VSD 계수를 원문에서 옮김), `FacilityPlant`를 세 루프로 확장.
- 칠러: 범위 밖 카르노 비 외삽, 전부하 COP 상한 = 범위 안 최고 7.46, 부분부하 EIRFPLR, `Q_cond = Q_evap + W`, 최소 PLR 아래 비례, 용량 부족 시 출구 상승·표시. N+1 단계 제어.
- CRAH: 유한 냉수 대향류 UA를 설계 열 보존으로 다시 구하고 공기 솔버에는 등가 UA를 넘긴다(솔버 무변경, 세 경로 공통).
- CW: 응축 열 → CW 체적 → 응축용 드라이쿨러(팬이 응축수 29.44 °C 유지, AHRI 표준 정격 입구, 원문 미확인).
- 근거 표 수정: F0 표의 칠러 CAPFT 계수가 웹 요약 도구 오류(다른 칠러 값)였다. 원문에서 다시 옮겼고 코드는 원문 값만 쓴다.
- 줄바꿈: F2 커밋에서 통합 액터 cpp가 CRLF·CR 섞인 채 저장소에 들어갔다(`text=auto`인데 홀로 CR이 있어 정규화가 안 됨). 이번 커밋에서 LF로 정규화(그 파일 전체가 diff에 나온다).
- 검증: 신규 `VRG.Plant.Chiller.*` 3건, `VRG.Plant.Chw.*` 2건 포함 영향 68건 성공. 기준점 CAPFT 0.993·COP 5.83(데이터셋 5.81), 경계 연속 6.3e-11, 응축 상승 단조, 격자 최고 COP = 상한,
  설비 단독: 외기 25 °C 냉수 18.000000 °C 유지·칠러가 CRAH 열을 상대 1e-6 안에서 받음·장부 3.7e-13, 외기 40 °C에서 COP 7.46 → 3.65로 하락, 1.6배 과부하에서 냉수 상승·용량 부족 표시.
  결합 방: 진입 때 등가 UA = 옛 UA(3.5e-15), 20 s 설비 장부 6.1e-14·전역 3.1e-14.
- L_Test -game(`vrg.Plant.Enable 1`, 외기 25 °C, 60 s): CHW 설계 556 kW·CRAH 8·칠러 2+1(기준 265 kW 각)·응축용 드라이쿨러 3대, 펌프 세 루프 합계 34.1 kW.
  냉수 18.000 °C 유지, 칠러 1대 부분부하 COP 9.3~12.7(범위 밖, 추정), 설비 장부 ≤ 8e-12. 처음 수십 초는 F2와 같은 초기 조건 과도. 화면 확인 안 함(로그).
- 남음: CRAH 2방 밸브로 급기 온도 제어, 칠러 고장·대기 전환 이벤트, 부분 PUE·전역 장부 반영(F5).
