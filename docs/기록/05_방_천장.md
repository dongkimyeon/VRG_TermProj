## 2026-10-06 수동 방 범위·공기 도메인 기반

통합 액터가 FRoomAirDomainSettings를 소유한다. 기본 bManual=false는 기존 자동 맞춤이며 배치 모드의 TrySetRoomAirDomain/ValidateRoomAirDomain C++ API로 수동 XY 최소/최대와 천장 높이를 검증한다. 바닥 Z=0m. 방 편집 UI/RoomShell 액터·벽/천장 판·Undo/배치 파일 저장은 아직 도입하지 않았다. 사용/격자/제한은 Tools/방편집_기반_2026-10-06.md.

기존 h와 방 맞춤 최소0.01m·축128셀 정책을 공통 상수로 사용한다. 수동은 각 축 ceil(길이/h), 실제 원점=(MinX,MinY,0), 최대=원점+N*h이며 자동 span quantum은 사용하지 않는다. 초과는 거절하며 범위/h를 잘라 적용하지 않는다. GPU 자동 선택100000셀은 상한이 아니며 기존 정책을 유지한다. 자동 모드 알고리즘/물성/공기 솔버 식은 그대로다.

기존 배치 상자의 전체 변환 8모서리와 기존 공기 결합의 수평/원래 치수 덕트 영역을 함께 검사한다. 실제·자동 CRAH의 앞/뒤 또는 위 이웃 유체 셀 h, 기존 랙 흡기/배기 표본 깊이와 콜드아일 지붕 한 셀 두께도 포함한다. 자동 계획은 새 월드 배치에서 재조회하고 이전 격자로 필터하지 않으며 계획 캐시는 복구한다. 셀 올림 확장으로 요청 방 밖 장비/덕트를 허용하지 않는다.

설정 수락은 격자/온도/시계/줄을 바꾸지 않는다. 진입 직전 재검증 실패는 모드/모델/재구축 이전에 이유를 반환·표시한다. 예열 우회도 막는다. 수동 통합 구성이 끝난 뒤 AirField BeginPlay가 호출되어도 독립 자동 맞춤/Reset으로 덮어쓰지 않는다. 자동 모드 복귀는 기존 Fit 경로이며 bAutoFitToRacks를 영구 변경하지 않는다.

## 2026-10-06 방 설정 UI·입력 소유

기존 비포커스 배치 팔레트의 방 설정 버튼이 모달 창을 연다. 자동 맞춤/수동 체크와 XY 최소/최대·천장 높이를 m로 입력한다. 입력은 초안이고 적용 버튼만 기존 TrySetRoomAirDomain으로 확정한다. 숫자는 FDefaultValueHelper로 전체 문자열을 파싱하고 유한값을 요구한다. 잘못된 숫자/포함·자원 오류는 빨간 이유로 표시하며 필드/적용 설정/실제 격자는 유지한다. 수동 적용 후 계획 원점·최대·축별/총 셀 수/h를 표시한다. 자동 모드는 기존 진입 시 맞춤으로 결정됨을 명시하며 자동 범위를 미리 확정했다고 표시하지 않는다.

처음 비어 있는 자동 입력은 현재 AirField 경계에서 초안을 채우며 Fit/Reset을 하지 않는다. 자동 적용의 비활성 숫자는 이전 적용값을 유지한다. m 값은 %.17g로 읽어 편집하지 않은 값이 표시 반올림 때문에 새 변경이 되지 않게 했다. 긴 오류/계획은 스크롤 영역이다. 별도 물성/방 치수 기본값 없음.

창이 열린 동안 UIOnly와 명시 입력 게이트를 사용한다. 장비 선택/추가/삭제/복제/이동/R·G/T·컨테인먼트·모드/열 손잡이·카메라/F·세계 Undo/Redo를 차단한다. 숫자 칸의 텍스트 편집 기능과 전역 배치 기록은 구분한다. 열기/닫기 때 남은 키를 비우고 Ctrl 상태를 초기화한다. 편집/우클릭 비행/패치/시뮬레이션 중 창 진입을 거절한다. Esc/닫기는 미확정 초안을 버리고 적용된 설정은 유지한다. 패치 진입·외부 모드 전환도 닫으며 기존 뷰포트 포커스/팔레트/커서를 복구한다. 오래된 위젯 Destruct는 새 창을 닫지 못하도록 자기 참조를 확인한다.

## 2026-10-06 방 설정 공유 Undo/Redo·최종 검증

Undo/Redo는 현재 값이 기록의 예상 값과 일치하는지 확인하고 기존 TrySetRoomAirDomain으로 현재 장비/자동 CRAH/덕트·자원 검증을 다시 수행한다. 거절 이유를 화면/로그로 표시하고 두 스택과 설정을 유지한다. 성공도 설정만 복원하며 실제 공기 격자/열모델 재구축은 기존 시뮬레이션 진입 경로에서 수행한다.
