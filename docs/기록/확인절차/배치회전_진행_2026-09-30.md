# 선택 장비 R 회전 (2026-09-30)

## 구현

- 배치 모드에서 클릭 선택한 장비에 R을 누르면 현재 yaw에 90°를 더한다.
  예: 17° → 107°. 90° 격자로 방향을 강제로 맞추지 않는다.
- 장비의 원점·높이·기울기·스케일을 유지한다. 90°는 사용자 지정 UI 동작이며 새 물리 수치가 아니다.
- 미선택, 드래그(버튼을 누른 대기 상태 포함), 패치 창, 우클릭 카메라, 기존 G 잡기 중에는 회전하지 않는다.
- 시뮬레이션 모드 R은 현재 배치로 시뮬레이션을 다시 구성하고 시계를 0으로 초기화하는 기존 동작이다.
- T 시선 회전은 기존 보조 조작으로 남는다. 다중 선택·겹침 방지·추가/삭제는 후속이다.
