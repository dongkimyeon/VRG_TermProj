# 다중 CDU 삭제 직접 확인 (2026-10-05)

Editor 빌드 성공, 영향11종 Automation 성공(9 무경고+2 기존 가상 CDU 경고 동반/실패0). 작성 당시 새 다중 삭제의 L_Test 실제 입력은 미검증이었으며, 이후 사용자가 아래 절차 모두 정상으로 보고했다(2026-10-05). 로그/캡처/FPS와 도구 오류 원인의 확인으로 확대하지 않는다. 네이티브 앱 직접 조작이 비활성이고 기존 geometry unavailable/조합 입력 제약의 해소 근거가 없어 같은 도구 실패를 반복하지 않았다. 사용자 단일 CDU 복제 모두 정상 보고와 구분한다. 아래는 새 기능의 직접 확인 절차이며 FPS/시설 전체 열수지 검증이 아니다. 그래픽 드라이버 안내가 나오면 아니오로 진행한다.

1. 새 L_Test의 배치 모드에서 콘솔 `vrg.Layout.Save cdu_batch_before`로 원래 상태를 저장한다. CDU 추가/복제로 런타임 CDU를 한 대 준비한 뒤 같은 명령으로 기존·런타임이 있는 시작 상태를 저장한다.
2. 기존 CDU와 런타임 CDU를 Shift+클릭으로 함께 선택한다. Delete는 두 대 모두 제거하고 선택 강조를 지워야 한다. Ctrl+Z는 함께 복원, Ctrl+Y는 함께 재삭제해야 한다. 복원된 위치·높이·방향·크기·설정과 기존/추가 출처가 같아야 한다.
3. Undo로 두 대를 복원한 뒤 그룹 이동과 R 회전을 확정하고 Delete한다. Ctrl+Z를 세 번 누르면 삭제→회전→이동 순서로 복원되고 Ctrl+Y로 재적용돼야 한다. Ctrl+Z로 삭제를 되돌려 다음 절차를 진행한다.
4. CDU와 랙 또는 스파인을 섞어 선택하면 Delete가 전체 거절돼야 한다. 미선택·드래그·사각형 선택·추가/복제 미리보기·패치 창·시뮬레이션에서도 삭제를 막아야 한다. CDU만 여러 대 선택한 삭제는 이제 지원한다. 랙만/스파인만 선택한 기존 전체 삭제는 유지한다.
5. 줄 가까운 CDU들을 선택해 삭제하고 다른 CDU 한 대를 남긴다. 기존 최근접 규칙으로 남은 CDU에 배관을 재배정해야 한다. Undo는 원래 배정으로 돌아가야 한다. CDU 전부를 선택해 삭제하면 기존 CDU 없음 진단과 라디에이터/가상 수력 루프가 남아야 한다. 가상 펌프 전력0을 기대하지 않는다.
6. 원하는 그룹을 삭제한 뒤 `vrg.Layout.Save cdu_batch_after`를 실행한다. `vrg.Layout.Load cdu_batch_before`→`vrg.Layout.Load cdu_batch_after`→후 파일 반복 Load로 삭제 목록/개수가 유지되고 중복 생성이 없어야 한다. Load 성공 뒤 Ctrl+Z/Y는 기록 없음으로 거절돼야 한다.
7. 실행을 끝내고 새 L_Test에서 후 파일을 Load한다. 기존 CDU 삭제와 런타임 목록이 복원돼야 한다. 전 파일 Load는 원래 CDU들을 복원하고 반복해도 중복이 없어야 한다. 실행 월드만 바뀌며 레벨 에셋 저장은 하지 않는다.

총1cm 복원 충돌·이름 점유·설정 변경 Redo 거절·중간 삭제/생성 실패·기록 유지와 원복은 자동화 검사 범위다. 장애물을 이동하는 새 편집은 Undo 기록을 추가하고 Redo를 비우므로 이를 같은 충돌 복원 절차로 혼동하지 않는다. 원복 자체의 연쇄 실패/극단 자원 고갈은 검사하지 않았다.

화면 증거가 필요하면 기존 Alt+Print Screen→클립보드 PNG 저장→이미지 확인 방식을 사용한다. 이번 작업에서 화면 캡처/실제 다중 입력/FPS는 확인하지 않았다. 펌프 손실 열 분배 모델은 기존 부채이며 확장하지 않았다.

보고 예시: `다중 CDU 삭제 직접 확인 결과: [모두 정상]` 또는 실패 번호·실제 동작.
