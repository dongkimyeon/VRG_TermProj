# 단일 CDU 복제 직접 확인 (2026-10-05)

새 L_Test 복제 입력은 미검증이다. 사용자 CDU 삭제 전부 정상 보고와 구분한다. 기존 geometry unavailable 해소 근거가 없어 같은 도구 실패를 반복하지 않았다. 아래 절차는 실제 입력 확인용이며 FPS/시설 전체 열수지 검증이 아니다. 그래픽 드라이버 안내는 아니오로 진행한다. 자동화 수치/범위는 CLAUDE.md 최신 CDU 복제 절을 따른다.

1. 새 L_Test의 배치 모드에서 기존 CDU 한 대 클릭→Ctrl+D. 원본은 그대로 있고 복제 미리보기 상자 하나만 나타나야 한다. 목적지 XY는5cm 스냅, 원본 높이/방향/스케일/크기를 유지한다.
2. 원본과 겹치면 빨강, 클릭해도 생성 거절. 빈 곳은 주황이고 R은 미리보기만90° 회전해야 한다. Esc 취소는 실제 CDU/배관 수를 바꾸지 않아야 한다.
3. 다시 복제를 시작해 빈 곳 클릭: 한 대만 생성, 원본/설정 유지·복제 선택·배관 재배정을 확인한다. Ctrl+Z로 복제만 제거, Ctrl+Y로 같은 복제 복원.
4. CDU 추가 버튼으로 만든 런타임 CDU도 같은 복제/R/Esc/확정/Undo/Redo를 확인한다. 비기본 설정이 있는 원본이면 그 설정·크기도 이어받아야 한다.
5. 미선택/여러 CDU/혼합 선택, 드래그/사각형/추가·복제 미리보기 중에는 새 CDU 복제를 거절해야 한다. 랙/스파인만 선택한 Ctrl+D는 기존 기능을 유지한다. 복제 중 패치 창 열기/시뮬레이션 전환은 취소하고 배치 복귀 시 미리보기가 남지 않아야 한다.
6. 줄 첫 랙에 원본보다 가까운 유효 위치로 복제하면 담당 CDU/배관이 복제로 재배정돼야 한다. Undo는 원본으로 돌아가야 한다. 복제 자체로 랙 수/IT 열원이 늘어나서는 안 된다. 펌프 전력은 위치/운전점에 따라 달라질 수 있다.
7. 복제 후 콘솔 `vrg.Layout.Save cdu_copy_check`→Undo→`vrg.Layout.Load cdu_copy_check`→같은 Load 반복. 원본과 복제가 각각 한 대만 유지되고 Ctrl+Z/Y는 기록 없음으로 거절돼야 한다. 새 L_Test 실행 후 같은 Load로 복원/재Load 중복 없음도 확인한다. Saved/Layouts 파일만 사용하고 레벨 에셋은 바뀌지 않는다.

복원 충돌/이름 점유/실제 생성 실패의 상태·기록 보존은 자동화에서 검사한다. 장애물 이동을 새 편집으로 확정하면 기록이 추가되고 Redo가 비워지므로 같은 실패 검사로 혼동하지 않는다.
화면 근거는 기존 Alt+Print Screen→클립보드 PNG 저장→이미지 확인 방법을 사용한다. 지원하지 않는 입력/동일 실패를 반복하지 않는다.
보고 예시: `단일 CDU 복제 직접 확인: [모두 정상]` 또는 실패 번호·실제 동작.
펌프 손실 열 분배 모델은 기존 부채로 유지한다. 이번 작업의 전역 열수지를 실제 시설 전체 열수지 완료로 해석하지 않는다.
