# 인로우 쿨러 추가 직접 확인 (2026-10-05)

현재 도구 네이티브 조작은 비활성이므로 L_Test 화면/입력은 미검증이다. 사용자 다중 CDU 복제 정상 보고는 해당 기존 기능 범위만 확인한 것이다. FPS 측정 없음. 드라이버 안내가 나오면 아니오로 진행한다.

1. L_Test 새 실행에서 배치 모드의 `인로우 쿨러 추가` 버튼을 확인한다. 시뮬레이션 모드에는 표시되지 않아야 한다. 원래 자동 CRAH의 개수·위치·방향을 기록한다(표시가 없으면 시뮬레이션 진입 후 배치로 돌아온다).
2. 버튼을 눌러 커서를 움직인다. 주황 상자만 움직이고 실제 쿨러/배관이 생기지 않아야 한다. 5cm 스냅과 R90°, Esc 취소를 확인한다.
3. 랙과 자동 CRAH 위치에 겹쳐 놓으면 빨강 표시이며 클릭해도 자동 전환/신규 생성이 없어야 한다.
4. 빈 유효 위치에서 확정한다. 원래 자동 장비가 같은 위치·방향·종류로 유지되고, 새 인로우 한 대만 늘어야 한다. 기존 자동 메시와 실제 장비가 중첩 표시되면 실패다.
5. Ctrl+Z는 새 인로우와 전환된 액터를 함께 제거해 원래 자동 표시로, Ctrl+Y는 전체를 같은 위치로 복원해야 한다. 반복 클릭은 한 대를 추가로 만들면 안 된다.
6. 실제 CRAH가 있는 상태에서 한 대를 더 추가한다. Undo/Redo는 그 신규 한 대만 제거/복원해야 한다. 편집/패치 중에는 시작하지 않고 패치·시뮬레이션 전환은 미확정 상자를 취소해야 한다.
7. 시뮬레이션에 진입해 쿨러 개수와 풍량·팬·냉각 표시 및 공기 결합을 확인한다. 입력 정상만으로 보존/압력/FPS를 통과했다고 하지 않는다. 물리 기준은 Automation 기록을 따른다.
8. 확인 결과를 `인로우 추가 직접 확인 결과: 모두 정상` 또는 실패 단계와 관찰로 전달한다. 캡처가 필요하면 기존 Alt+Print Screen→클립보드 PNG 저장→이미지 확인을 사용한다.

## 병합 후 저장 확인 (2026-10-05)

원격의 `crahInventory` 저장 확장을 통합했다. 새 CRAH 목록/ID/설정/변환과 자동 전환 출처·원래 공기 경계 정보를 저장한다. 온도·적분 상태·시계는 저장하지 않는다. 이전 v1/v2의 선택 필드가 없으면 기존 동작을 유지한다. 아래는 직접 확인 절차이며 화면 확인 완료 기록은 아니다.

1. 추가 전 자동 상태를 별도 파일에 저장하고, 추가 후 상태도 다른 파일에 저장한다.
2. 추가 후 파일을 같은 실행에서 두 번 불러온다. 쿨러 수·ID·설정·변환이 유지되고 중복 생성 없이 Undo/Redo 기록이 초기화되어야 한다.
3. 새 L_Test 실행에서 추가 후 파일을 불러온다. 전환된 기존 쿨러와 추가 한 대가 복원되어야 한다.
4. 추가 전 파일을 불러온다. 런타임 쿨러가 제거되고 원래 자동 배치로 돌아와야 한다. 시뮬레이션의 풍량·팬·냉각 표시도 확인한다.

자동 전환 뒤 이동한 CRAH는 이동 위치와 원래 자동 경계를 구분해 복원한다. 물리 판정은 CLAUDE.md 병합 검증 결과를 따르며 FPS는 별도 측정하지 않았다.
