# 부분 천장 구멍 XY 핸들 직접 확인

구멍 선택·삭제는 사용자 직접 확인 정상(2026-10-07)이다. 아래 신규 핸들의 화면/실제 입력은 별도로 확인한다. FPS 검증은 포함하지 않는다.

1. L_Test를 실행하고 배치 모드로 들어간다. 드라이버 안내는 ‘아니오’를 선택한다. 이전에 통과했던 수동 방 설정과 장비/덕트가 없는 부분 천장 판을 사용한다.
2. 예시 판은 빈 공간의 1m×1m, 높이2.625m다. ‘천장 선택·삭제’로 판을 선택하고 ‘선택 판 구멍 추가’에서 로컬 X/Y 최소0.125, 최대0.875m를 넣어 추가한다. 기존 구멍이 있다면 새 판을 만들 필요는 없다.
3. 창을 닫고 ‘구멍 선택·삭제’를 켠다. 보라색 계산 개방 상자를 클릭한다. 선택 구멍의 요청 윤곽과 실제 개방 상자가 초록색으로 바뀌고 요청 윤곽의 네 모서리에 점이 보인다. 판 모서리/높이 핸들은 표시되지 않아야 한다.
4. 모서리 점을 누른 상태로 조금 이동해 놓는다. 점은 5cm 월드 XY 스냅으로 움직이고 반대 모서리·판 범위/높이는 유지된다. 드래그 동안 요청 윤곽은 유효하면 주황, 거절이면 빨강이다. 상단 안내에서 선택 구멍 번호와 요청 로컬/월드 범위, 계산 개방 범위/셀 수를 구분해 확인한다. 미리보기 중 원래 보라 개방 표시가 남는 것은 실제 목록이 아직 바뀌지 않았기 때문이다.
5. 유효한 곳에 놓으면 한 변경만 확정한다. Ctrl+Z로 원래 구멍 크기, Ctrl+Y로 최종 크기를 복원한다. 기록 복원으로 판/구멍 선택이 초기화되면 다시 판과 구멍을 선택한다.
6. 모서리를 판 밖이나 반대 모서리 너머로 이동해 빨강·거절 이유를 확인한다. 아주 작게 줄여 실제 개방 셀이0개가 되어도 거절한다. 놓은 뒤 이전 목록과 Undo/Redo 기록이 그대로여야 한다. 장비/덕트를 관통하는 통로를 좁히면 전체 검증이 거절하므로 충돌 조건을 우회하지 않는다.
7. 유효한 미리보기 중 Esc를 누른다. 드래그만 취소되고 선택/구멍 편집은 남아야 한다. 다시 Esc를 누르면 구멍 편집이 종료된다. 점을 누르고 움직이지 않은 채 놓아도 기록이 늘지 않아야 한다.
8. 같은 좌표 구멍을 두 개 만들고 앞 구멍을 선택해 모서리를 조절한다. 한 항목만 바뀌고 다른 항목은 그대로 남아야 한다. 남은 중복 구멍 때문에 실제 개방 합집합이 요청 윤곽 변경과 다르게 보일 수 있다.
9. 드래그 중 Delete·Ctrl+Z/Y·장비 조작·카메라 이동은 실행되지 않아야 한다. Alt+Tab으로 포커스를 잃으면 미확정 드래그는 취소된다. 숫자 창/패치/모드 전환과 성공 Load도 취소 경로를 사용한다. UI 버튼이 드래그 중 비활성이라면 먼저 Esc로 취소하고 창을 연다. 같은 도구 실패는 재시도하지 않는다.
10. 확정 결과를 기존 Save로 저장하고 반복 Load 및 새 실행에서 복원한다. 기록/선택은 초기화된다. 시뮬레이션 진입 전 실제 공기 셀은 유지되고 다음 진입 때 구멍 합집합으로 적용한다. 이 구멍은 내부 공기 연결이며 외부 배기가 아니다.

보고 예: ‘구멍 XY 핸들 직접 확인: 스냅/반대 모서리/중복 한 항목/거절/Esc/Undo·Redo/저장 모두 정상’. 실패했다면 단계와 안내 문구를 보내면 된다.
