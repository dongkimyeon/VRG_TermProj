# 다중 스파인 복제 직접 확인 (2026-10-05)

새 다중 복제 UI는 미검증이다. Windows Computer Use 초기화·창 목록 조회는 이전 진단에서 성공했지만, 이전 좌표 geometry unavailable/Shift 유지 입력 제약이 해소됐다는 근거는 없어 같은 실패를 재시도하지 않았다. 단일 복제·다중 삭제의 사용자 정상 보고는 새 기능의 확인으로 확대하지 않는다. 드라이버 안내는 아니오로 진행한다.

## 직접 절차

1. L_Test 배치에서 콘솔 `vrg.Layout.Save spine_group_clone_before`로 원배치를 보관하고 콘솔을 닫는다. 기존 스파인과 실행 중 추가한 스파인을 Shift+클릭해 함께 선택한 뒤 Ctrl+D를 누른다. 미리보기 수와 상대 위치·높이·방향·스케일이 원본과 같아야 한다. R은 다중 미리보기를 회전하지 않아야 한다. Esc 후 장비 수와 원본은 그대로여야 한다.
2. 다시 복제하고 목적지 중 하나만 다른 장비와 겹치게 한다. 모든 목적지는 빨강으로 표시되고 클릭해도 한 대도 생성하지 않아야 한다. 빈 곳으로 옮겨 클릭하면 전체가 한 번에 생성되고 원본은 유지돼야 한다. 복제 전체가 선택돼야 하며 다시 클릭해 중복 생성하지 않아야 한다.
3. Ctrl+Z 한 번으로 복제 전체 제거, Ctrl+Y 한 번으로 전체 복원을 확인한다. 제거 후 복원 위치 하나를 막으면 Redo는 한 대도 복원하지 않아야 한다. 장애물을 비킨 후 같은 Redo를 재시도하면 전체 복원돼야 한다.
4. 미선택/스파인+다른 장비 혼합, 드래그/사각형/이미 미리보기·패치 창·시뮬레이션 중 Ctrl+D는 거절해야 한다. 미리보기 중 패치/시뮬레이션 진입은 전체 취소해야 한다. 단일 스파인 복제 R과 기존 랙 그룹 복제는 유지한다.
5. 줄 조건에 맞는 목적지에서 케이블/패치 장비 반영을 확인한다. 실제 케이블은 기존 줄 방향/포트 배정 순서를 따르므로 모든 복제가 케이블을 받는 것은 아니다. 기존 미연결 진단을 숨기면 안 된다. 랙·냉각수 배관은 유지돼야 한다.
6. `vrg.Layout.Save spine_group_cloned`로 저장한다. 원배치 Load → 복제 파일 Load → 같은 파일 재Load 및 새 L_Test 실행 Load로 원본/복제 설정·개수·변환 유지와 중복 없음·이전 Undo/Redo 초기화를 확인한다. 마지막에 원배치를 Load한다. 파일은 Saved/Layouts에 있으며 레벨 에셋은 바뀌지 않는다.

결과는 선택/미리보기·R 차단/Esc·충돌 전체 거절·확정/원본 유지·한 Undo/Redo·입력 차단/전환 취소·케이블·반복/새 실행 Load로 나눠 정상 또는 입력 순서와 관찰 결과로 알려주면 된다.

자동화 측정·정규화/단위는 CLAUDE.md 최신 절을 따른다. NullRHI 축소 fixture는 실제 전체 열운전/정상상태/FPS 검증을 대신하지 않는다. 다른 장비/Blueprint 복제는 이번 범위 밖이다.
