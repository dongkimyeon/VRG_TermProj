# 배치 모드 완전 검증 (2026-10-22, 진행 중)

CLAUDE.md "남은 순서" 2번. 배치 편집 전체(F8을 하기로 했으므로 설비 장비 포함)의 **자동화**와 **직접 확인 절차**를 빠짐없이 통과하는 단계다.
이 문서는 흩어져 있는 기능별 확인 문서(`docs/기록/확인절차/배치*.md`·`방*.md`·`부분천장*.md`·`천장*.md`·`설비장비배치*.md`)와

판정 규칙(CLAUDE.md 검증 규칙): 자동화 성공, 사용자 직접 확인, AI 화면 확인, 미검증을 구분한다. 자동화 성공을 화면 확인으로 바꿔 적지 않는다.

그래서 아래 B는 **사용자 직접 확인**으로만 닫힌다.

## B'. AI 화면 확인 (2026-10-23, RTX 4060 노트북, Editor `-game` L_Test 1280×720)

사용자 확인이 아니다(CLAUDE.md 검증 규칙의 "AI 화면 확인"). 입력은 PowerShell의 Win32 `SendInput` 계열(마우스·키, 수정 키는 스캔 코드 포함 왼쪽 Shift/Ctrl),
판정은 게임 창 캡처와 `[VrgLayout]`·`[Plant]` 로그로 했다. 위 B 항목은 사용자 확인 전까지 B에 그대로 남긴다.

도구 메모: 합성 입력으로 UE 콘솔(`~`)을 여닫는 것이 불안정했다. 콘솔이 안 열린 채 입력한 글자가 게임 단축키로 들어가거나(`r` → 회전) 전체 화면 콘솔이 닫히지 않아,
콘솔 명령은 결과 로그로 실행을 확인하고, 막히면 게임을 다시 띄웠다. 시작 때 "그래픽 드라이버 알려진 문제" 대화상자가 떠서 Enter로 넘겼다(드라이버 546.32).
