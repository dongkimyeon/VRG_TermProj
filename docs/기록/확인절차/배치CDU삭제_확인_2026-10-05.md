# 단일 CDU 삭제 직접 확인 (2026-10-05)

구현/자동화는 영향10종 성공(9 무경고+1 기존 가상 CDU 경고 동반), 실패0이다. 작성 당시 실제 L_Test 삭제 입력은 미검증이었으며, 이후 사용자가 아래 절차 전부 정상이라고 보고했다(2026-10-05). 로그/캡처/FPS 확인으로 확대하지 않는다. 환경 변화 없는 geometry unavailable 도구 실패를 반복하지 않았다. 아래 절차는 사용자 확인용이며 FPS/시설 전체 열수지 검증이 아니다. 드라이버 안내는 아니오로 진행한다.

1. L_Test를 새로 실행해 배치 모드로 둔다. 콘솔 `vrg.Layout.Save cdu_delete_before`로 시작 상태를 보관한다. 기존 CDU 한 대를 클릭하고 Delete: 한 대만 없어지고 선택 강조가 해제돼야 한다. 레벨 에셋은 바뀌지 않아야 한다.
2. Ctrl+Z로 같은 위치/방향/크기/설정의 CDU 복원, Ctrl+Y로 재삭제를 확인한다. Undo 후 CDU를 이동하고 R로 회전해 기록을 만든 뒤 삭제한다. Undo를 세 번 실행하면 삭제·회전·이동 순으로 복원되고 Redo로 다시 적용돼야 한다.
3. CDU 추가 버튼으로 만든 런타임 CDU도 Delete/Undo/Redo를 확인한다. 복원 충돌/이름 점유 시 기록 보존은 자동화에서 확인했다. 장애물 이동을 새 편집으로 확정하면 기록이 추가되고 Redo는 비워지므로, 그 조작을 같은 복원 충돌 절차로 혼동하지 않는다.
4. 미선택/여러 CDU 선택/혼합 선택에서는 CDU를 삭제하지 않아야 한다. 랙 또는 스파인만 선택한 경우에는 그 장비의 기존 Delete 기능이 그대로 동작한다. 드래그·사각형 선택·추가 미리보기·패치 창·시뮬레이션 중에는 삭제를 막아야 한다.
5. CDU 두 대가 있는 상태에서 한 줄을 담당하는 가까운 CDU를 삭제한다. 남은 최근접 CDU로 배관이 이어지는지 확인한다. Undo는 기존 담당 CDU로 돌아가야 한다. 마지막 CDU 삭제 시에는 기존 가상 수력/랙 라디에이터 경로와 CDU 없음 진단을 유지한다. 가상 펌프 전력이 0이라고 기대하지 않는다.
6. 기존 CDU와 런타임 CDU를 삭제한 상태에서 `vrg.Layout.Save cdu_delete_after`를 실행한다. 삭제 전 파일 Load→삭제 후 파일 Load→후 파일 반복 Load로 삭제 상태/개수가 유지되고 중복 없이 Ctrl+Z/Y는 기록 없음으로 거절돼야 한다. 콘솔 명령은 `vrg.Layout.Load cdu_delete_before`와 `vrg.Layout.Load cdu_delete_after`다.
7. 실행을 끝내고 새 L_Test에서 삭제 후 파일을 Load한다. 기존 CDU 삭제와 런타임 목록이 유지돼야 한다. 삭제 전 파일 Load는 원래 장비를 복원하고 재Load는 중복을 만들지 않아야 한다. 저장 파일은 Saved/Layouts에 있으며 실행 월드만 바뀐다.

화면 근거는 기존 Alt+Print Screen→클립보드 PNG 저장→이미지 확인 방법을 사용한다. 지원하지 않는 입력/같은 실패를 반복하지 않는다.

보고 예시: `단일 CDU 삭제 직접 확인: [모두 정상]` 또는 실패 번호·실제 동작. 펌프 손실의 냉각수/공기 열 분배는 기존 모델 부채이며 본 작업에서 확장하지 않았다.
