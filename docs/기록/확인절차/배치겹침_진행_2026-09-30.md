# 배치 장비 겹침 방지 (2026-09-30)

## 동작

- `PlaceableBoxM` 장비 상자를 월드 변환(회전·스케일 포함) 후 XY에 투영해 검사한다.
  기울어진 상자는 높이의 XY 투영도 포함한다. 바닥 배치 규칙이므로 서로 다른 Z라도 발자국이 겹치면 거절한다.
- 기존 배치 계획의 판정 여유 1 cm는 두 투영 상자 사이 **분리축에서 최소 1 cm 간격**으로 적용한다.
  각각 1 cm씩 확장하는 방식이 아니다. 축에 투영한 간격이 정확히 1 cm이면 허용한다.
  이는 사용자 지정 배치 안전 여유이며 새 물성·추정 물리 수치가 아니다.
- 겹치는 드래그 목적지는 빨간 상자, 허용 목적지는 기존 주황 상자다.
  미리보기 동안 실제 장비를 유지하고, 놓는 순간 월드를 다시 검사한다. 거절 시 원래 변환을 유지한다.
- R 선택 회전과 기존 T 시선 회전은 제안 회전을 검사한 뒤 허용된 경우만 적용한다.
- 기존 G 이동도 같은 이동 검사를 사용하며 막힌 위치에서는 마지막 허용 위치를 유지한다.
- 배관·물리 솔버는 수정하지 않았다. 확정된 액터 변환에 따른 기존 재구축 경로를 사용한다.
