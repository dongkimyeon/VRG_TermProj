# 부분 천장 구멍 전체 XY 이동 직접 확인

구멍 XY 모서리 핸들은 사용자 직접 정상 확인(2026-10-07)이다. 아래는 신규 내부 이동의 직접 절차이며 실제 화면/OS 포커스/FPS는 자동화 결과에 포함하지 않는다.

1. L_Test 배치 모드에서 전에 통과했던 수동 방·부분 천장 판·구멍을 사용한다. 드라이버 안내가 나오면 ‘아니오’를 선택한다. 예시 판1m×1m, 높이2.625m, 구멍 로컬 X/Y 최소0.125·최대0.875m는 기존 합성 예시다.
2. ‘천장 선택·삭제’로 판을 선택하고 ‘구멍 선택·삭제’를 켠다. 보라 계산 개방 범위 안을 클릭해 선택한다. 모서리 점과 초록 요청/계산 범위를 확인한다. 움직이지 않고 놓으면 새 기록이 없어야 한다.
3. 모서리 점에서 떨어진 구멍 내부를 누른 채 조금 옆으로 움직인다. 기존 계산 개방 상자가 클릭 대상이며 요청 윤곽의 좁은 바깥 여백은 선택 대상이 아닐 수 있다. 이동은 처음 잡은 위치의 오프셋을 유지하고 최소점을 월드5cm 스냅한다. 구멍 가로/세로 크기·판 범위/높이와 다른 구멍은 유지한다.
4. 유효 미리보기는 주황, 판 밖이나 실제 개방0셀·장비/덕트를 막는 위치는 빨강과 거절 이유를 표시한다. 안내의 요청 로컬/월드와 계산 개방 범위/셀 수는 서로 다를 수 있다. 미리보기 중 원래 표시가 남는 것은 실제 목록이 아직 유지되기 때문이다.
5. 유효할 때 놓으면 한 이동만 확정한다. Ctrl+Z로 원위치, Ctrl+Y로 목적지를 복원한다. 기록 복원으로 선택이 초기화되면 판과 구멍을 다시 선택한다. 실제 공기 셀은 다음 시뮬레이션 진입 때 바뀐다.
6. 같은 모서리 점을 드래그하면 기존 크기 조절이 우선하고 내부 이동으로 처리되지 않아야 한다. 동일 기하의 구멍 두 개가 있어도 한 항목만 이동한다. 남은 구멍/다른 고체 때문에 최종 통로는 단일 윤곽과 다를 수 있다.
7. 유효 미리보기 중 Esc는 이동만 취소하며 구멍 선택/편집은 유지한다. 다음 Esc는 구멍 모드를 종료한다. 판 밖 목적지를 놓아도 목록/기록은 그대로여야 한다. 빈 곳 클릭은 구멍 선택 해제이고 판은 유지한다.
8. 이동 중 Delete·Undo/Redo·장비/판·카메라 조작은 차단한다. Alt+Tab 포커스 상실, 숫자 창/패치/모드 전환·성공 Load는 미확정을 취소한다. 버튼이 드래그 중 비활성이라면 Esc 후 창을 연다. 실패 Load는 미확정을 유지한다. 도구 실패는 반복하지 않는다.
9. 단일 조작이 정상이면 판 이동→판 높이 변경→구멍 추가→구멍 크기 변경→구멍 이동→구멍 삭제를 유효한 빈 공간에서 실행한다. 판 이동은 구멍 로컬 좌표를 유지하고 높이 변경은 구멍 높이를 따르게 한다. 전부 Undo/Redo로 각각 처음/최종 목록이 복원되는지 확인한다. 기록 복원 후에는 필요할 때 다시 판/구멍을 선택한다.
10. 최종 배치를 Save한 뒤 반복 Load와 새 실행에서 Load한다. 중복 없이 복원되고 선택/미확정/기록이 초기화되어야 한다. 다음 시뮬레이션 진입 때 합집합을 반영하며 다른 판·벽·장비·콜드아일 지붕 고체를 지우지 않는다. 외부 배기 기능은 없다.

보고 예: ‘구멍 전체 이동·혼합 편집 직접 확인: 내부 이동/크기 유지/핸들 우선/중복 한 항목/거절/Esc/Undo·Redo/저장 모두 정상’. 실패 시 단계와 안내 문구를 보내면 된다.
