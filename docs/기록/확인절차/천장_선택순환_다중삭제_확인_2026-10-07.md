# 천장 선택 순환·다중 삭제 직접 확인

사용자 보고: 기존 구멍 전체 XY 이동은 정상(2026-10-07). 아래 신규 조작은 AI 실제 화면 미확인이다. 기존 화면 도구 실패를 재시도하지 않는다. FPS는 측정하지 않는다.

## 준비

1. L_Test를 실행하고 배치 모드로 전환한다. 방 설정에서 수동 방을 적용한다. 이미 정상 사용한 방 수치를 재사용한다. 장비/덕트 포함 거절이 나오면 표시된 필요 범위를 포함하도록 조정한다.
2. 부분 천장 추가 창에서 장비와 떨어진 유효 범위의 판 한 장을 추가한다. 그 창의 동일한 수치를 다시 입력해 같은 판을 한 장 더 추가한다. 동일한 기하도 별도 목록 항목이다.
3. 천장 편집을 켜고 위에서 판 내부를 보도록 카메라를 이동한다. 모서리 점·중앙 높이 점에서 떨어진 내부를 사용한다. 필요하면 선택 판에 유효한 구멍을 같은 수치로 두 번 추가한다. 구멍은 판 최소 XY 기준 로컬 m이며 실제 개방 셀이 한 개 이상이어야 한다.

## 1단계: 선택 순환

1. 판 내부를 클릭하면 HUD의 판 번호가 표시된다. 같은 위치에서 Alt를 누른 채 클릭할 때마다 겹침 순서와 판 번호가 바뀌고 끝에서 처음으로 돌아오는지 확인한다. Alt 클릭 자체로 드래그가 시작되거나 Undo 기록이 생기면 안 된다.
2. 두 번째 판을 고른 뒤 Alt를 놓고 내부를 조금 드래그한다. 선택한 판만 움직이는지 확인하고 Esc로 취소한다. 모서리/높이 핸들의 기존 조작도 유지돼야 한다.
3. 판 한 장을 선택하고 구멍 편집을 켠다. 실제 보라색 개방 범위의 내부에서 Alt+클릭하면 같은 판에 속한 겹친 구멍 번호가 순환한다. 다른 판의 구멍은 후보에 포함되지 않는다.
4. 구멍 모드의 빈 곳 클릭은 구멍 선택만 해제한다. Esc는 구멍 편집을 끝내고 다음 Esc는 천장 편집을 끝낸다. 숫자 창/패치가 열린 동안 선택 입력이 실행되면 안 된다.

## 2단계: 다중 선택·삭제

다중 선택/삭제 구현과 영향 자동화7종은 통과했다. 아래 실제 키·마우스·화면은 직접 미확인이다.

1. Shift+클릭으로 판 선택을 추가/제거한다. 동일 위치의 두 항목은 첫 항목을 일반 클릭한 뒤 Alt+Shift+클릭으로 다음 항목을 선택에 추가한다. 선택 개수와 모든 선택의 초록 강조를 확인한다.
2. 여러 항목 선택 상태에서 선택 내부·모서리·높이를 드래그해도 편집이 시작되지 않아야 한다. 일반 클릭으로 새 항목을 고르면 단일 선택으로 돌아갈 수 있다. 빈 곳 클릭은 전체 선택을 해제한다.
3. 두 판을 선택하고 Delete를 누른다. 둘이 함께 사라지고 Ctrl+Z는 둘을 함께 복원, Ctrl+Y는 둘을 함께 삭제해야 한다. 판에 포함된 구멍도 같은 목록으로 복원돼야 한다.
4. 단일 판의 구멍 편집에서 같은 방법으로 여러 구멍을 선택하고 Delete/Ctrl+Z/Ctrl+Y를 확인한다. 다른 판이나 판 자체가 선택/삭제에 섞이면 안 된다. 동일 구멍도 선택한 항목만 제거돼야 한다.
5. 삭제로 고체가 장비나 덕트를 막는 경우 빨간 거절 이유가 표시되고 전체 목록·선택·기록이 유지돼야 한다. 별도로 위험한 배치를 만들 필요는 없으며 자동화 확인 범위와 구분한다.
6. 최종 결과를 저장하고 Load한다. 목록에 중복 생성이 없고 선택·Undo/Redo 기록이 초기화되는지 확인한다. 시뮬레이션 진입 때 판/남은 구멍의 실제 셀 표시가 갱신돼야 한다.

결과 전달 예: `천장 선택 순환·다중 삭제 직접 확인 결과: [정상 / 실패한 항목 번호와 관찰 내용]`.
