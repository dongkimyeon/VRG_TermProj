# 다중 선택 및 그룹 드래그 (2026-09-30)

## 조작과 확정

- Shift+클릭은 장비 선택을 추가/제거만 한다. 일반 클릭은 새 장비면 단일 선택으로 바꾸고,
  이미 선택된 장비면 그룹을 유지해 드래그를 시작한다. 빈 곳은 Shift 여부와 관계없이 전체 해제한다.
- 유효한 선택을 모두 초록 상자로 표시한다. F는 선택 그룹(스케일 포함)을 맞춰 보고,
  유효한 선택이 없으면 전체 장비를 본다. 파괴된 약한 참조는 무시한다.
- 드래그 시작 때 클릭한 장비가 앵커다. 그 장비의 목적지 XY만 기존 5 cm 격자로 맞춘 뒤
  같은 이동량을 모든 멤버의 시작 위치에 적용한다. 상대 위치·높이·방향·스케일을 유지한다.
- 실제 액터는 미리보기 동안 유지한다. 유효 목적지는 주황, 하나라도 충돌하면 그룹 전체가 빨강이다.
- 멤버의 이전 위치는 충돌 대상에서 제외하고, 제안 위치의 멤버끼리 및 외부 장비를 기존 총 1 cm 분리축 여유로 검사한다.
- 놓는 순간 전체 충돌과 원래 변환, 살아 있는 멤버·이동 가능한 루트를 다시 확인한 뒤 함께 확정한다.
  한 멤버의 충돌·외부 변환 변경·파괴·정적 루트는 전체를 거절한다. 적용 실패 시 이미 적용한 멤버를 복구한다.
- Esc/패치/F/모드 전환 등 기존 취소는 그룹 전체에 적용된다. 취소는 실제 원래 변환을 유지한다.
- 다중 선택 중 R/G/T와 공통 단일 이동·회전 함수는 막는다. 시뮬레이션 R 리셋은 유지한다.
- 5 cm, 1 cm, 4픽셀은 기존 사용자 지정 UI 기준이다. 새 물리 수치나 물리 솔버 변경은 없다.

사용자 요청에 따라 환경 변화 근거가 없는 실제 UI 확인은 재시도하지 않았다.
실제 Shift/마우스 캡처/포커스·그룹 색상·F·드래그 FPS는 미검증이다.
자동화는 커서 광선 이후 로직·카메라 시야 기하 검사이며 OS/Slate 입력 검증을 대체하지 않는다.

사각형 선택·그룹 회전·줄 붙이기·추가/삭제·Undo·패키징은 후속이다.
장비 액터 상자 기준이며 세부 메시·벽·배관·가상 자동 CRAH와 이동 중 스윕은 검사하지 않는다.
기존부터 겹치는 멤버 그룹은 상대 위치를 유지하는 이동으로 충돌을 해결할 수 없으므로 그대로 거절한다.
