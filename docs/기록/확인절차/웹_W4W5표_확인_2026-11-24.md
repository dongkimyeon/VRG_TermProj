# 웹 대시보드 W4·W5 표 화면 확인 절차 (2026-11-24, 미검증)

자동화(`VRG.Web.StatusWaterAndDetectorTables`, `/api/status`의 값과 리포트가 같은지)와 페이지 스크립트 문법 검사(headless Edge)는 통과했다.
실제 브라우저 화면과 패키지 exe는 사용자 요청으로 확인하지 않았다(창·마우스·키보드 사용 안 함). 확인하면 날짜와 확인자(사용자 / AI 화면 확인)를 적는다.

## 준비

```powershell
& 'E:\UE_5.8\Engine\Binaries\Win64\UnrealEditor.exe' 'C:\GitGit\VRG_TermProj\VRG_TermProj.uproject' /Game/Maps/L_Test -game -windowed -ResX=1600 -ResY=900 '-ExecCmds=vrg.Leak.AutoIsolate 1,vrg.Water.Impact 1'
```

Enter로 시뮬레이션을 시작하면 기본 브라우저에 `http://127.0.0.1:18080/dashboard`가 열린다. **센서·검증** 탭(`#check`)을 연다.
