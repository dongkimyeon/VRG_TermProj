# 수동 방 모서리 드래그 직접 확인

기존 방 설정 저장 직접 절차는 사용자가 정상 보고했다(2026-10-06). XY 핸들 직접 절차도 사용자가 정상 보고했다(2026-10-06). 해당 직접 절차 범위이며 신규 높이 핸들/로그/캡처/FPS 확인으로 확대하지 않는다. 기존 도구 환경의 좌표 입력 실패는 반복하지 않았다. 자동화 결과를 실제 화면 확인으로 대신하지 않는다.

1. L_Test 배치 모드에서 이미 정상 확인한 수동 방 설정을 적용한다. 방 창을 닫고 카메라로 바닥 네 모서리가 보이게 한 뒤 `방 범위 편집` 버튼을 누른다. 범위/네 주황 점과 이유·계획 셀 수를 확인한다. 자동 맞춤일 때 버튼은 수동을 먼저 적용하라는 안내만 보여야 한다.
2. 모서리 하나를 바깥으로 끌어본다. 반대 모서리/천장/장비는 유지되고 선택 모서리의 XY만 5cm 스냅으로 움직여야 한다. 드래그 중 카메라·장비 선택/사각형/추가/R·G/T·Delete·Ctrl+D가 실행되지 않아야 한다. 미리보기 중 실제 방 값/공기 계산은 바뀌지 않는다.
3. 드래그 중 Esc를 누르면 원래 범위로 돌아간다. 장비/방 값과 과거 Undo/Redo는 유지돼야 한다. 유효 위치에 놓으면 한 번 확정하고 Ctrl+Z/Y로 이전/다음 방 범위를 복원한다. 미리보기 중 Ctrl+Z/Y는 막혀야 한다.
4. 장비/쿨러/덕트를 포함하지 못하는 작은 범위 또는 자원 한도를 넘는 큰 범위로 끌어본다. 빨강·거절 이유가 나오고 놓아도 실제 범위/기록은 유지돼야 한다. 모서리를 반대편 너머로 끌어도 자동 정렬하지 않고 거절한다.
5. 미확정 드래그 중 패치 진입/Enter 전환·포커스 상실을 확인한다. 미확정은 취소돼야 한다. 유휴 Esc/버튼은 편집을 종료하고 장비 선택/기즈모와 기존 카메라 입력이 복귀해야 한다. 유휴 상태에서는 기존 카메라 조작이 가능하다. 방 설정 창을 열면 핸들 모드는 종료된다.
6. 확정한 방을 `vrg.Layout.Save RoomCorner`로 저장한 뒤 범위를 바꾸고 `vrg.Layout.Load RoomCorner`한다. 방/장비/벽 복원과 기록 초기화를 확인한다. 성공 Load는 핸들 편집도 종료한다. 다음 시뮬레이션 진입 때만 실제 격자를 적용한다.

보고 예: `방 모서리 드래그 직접 확인: 표시/5cm/고정 모서리/확정/거절/Esc/Undo·Redo/저장/입력 복귀 [정상 또는 실패 절차]`.
천장 핸들/판·벽 확장·외부 열 교환/플레넘·전체 테스트·FPS는 이번 범위 밖이다.
