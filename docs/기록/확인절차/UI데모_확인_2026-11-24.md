# UI 데모 확인 절차 (2026-11-24)

2026-11-25부터 새 UI가 기본이다(`vrg.Ui.Style` 기본 1). 실행 중 `F2`로 이전 UI와 번갈아 본다.

## 실행

- 스크립트: `powershell -ExecutionPolicy Bypass -File Tools\UI데모_실행.ps1` (엔진 경로가 다르면 `-Engine D:\UE_5.8`, 시나리오를 바로 보려면 `-Scenario leakprotect`)
- 에디터에서: L_Test 열고 Play → 게임 화면에서 `F2` (또는 `` ` `` 콘솔에 `vrg.Ui.Style 1`)
