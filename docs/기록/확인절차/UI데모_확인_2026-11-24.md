# UI 데모 확인 절차 (2026-11-24)

새 UI는 `vrg.Ui.Style 1`일 때만 보이고 기본은 기존 UI다. 실행 중 `F2`로 번갈아 본다.

## 실행

- 스크립트: `powershell -ExecutionPolicy Bypass -File Tools\UI데모_실행.ps1` (엔진 경로가 다르면 `-Engine D:\UE_5.8`, 시나리오를 바로 보려면 `-Scenario leakprotect`)
- 에디터에서: L_Test 열고 Play → 게임 화면에서 `F2` (또는 `` ` `` 콘솔에 `vrg.Ui.Style 1`)

## 확인 항목 (A = AI 화면 확인, - = 미검증)

| # | 항목 | 상태 |
|---|---|---|
| 1 | 배치 모드: 상단 바, 왼쪽 팔레트(탭 4개), 아래 키 안내 막대 | A |
| 2 | 팔레트 탭 전환, 항목 클릭 → 배치 시작(팔레트에 "배치 중" 줄), 클릭 확정 | - |
| 3 | 장비 1개 선택 → 오른쪽 속성 패널(종류·위치·크기·방향), 여러 개 → 종류별 수 | - |
| 4 | 방 설정을 수동으로 → 방·천장 탭에 부분 천장 항목, 천장 편집 → 구멍 항목·안내 띠 | - |
| 5 | Enter → 시뮬레이션: 상단 바, 지표 카드 4개 + 추이선, 열 제거 분담, 사건 기록, 도구 막대 | A |
| 6 | `vrg.Demo leakprotect`/`flood` → 사건 기록 최신순, 짧은 랙 이름 | A |
| 7 | V 공기 보기 → 도구 막대 강조, 새 범례 | A |
| 8 | L 누수 도구 → 도구 막대 강조, 랙 내부 지점 조준 시 상세 패널이 지표 카드와 겹치지 않음 | - |
| 9 | H → 두 열 단축키 오버레이, H로 닫기 | - |
| 10 | F2 → 기존 UI(왼쪽 위 글자, 아래 버튼 3줄)로 돌아가고 다시 F2로 새 UI | 기존 UI 모습만 A |
| 11 | 1920×1080·1280×720에서 겹침 없음 | - |
