# 그룹 랙 줄 붙이기 확인 (2026-10-04)

사용자 직접 그룹 복제 확인: 두 랙 선택·두 미리보기/상대 위치·R 차단·Esc 취소·중첩 빨강/거절·두 대 생성/원본/배관·Undo/Redo 모두 정상 보고. 이 보고는 새 그룹 줄 붙이기의 화면 검증은 아니다.

## 구현 범위

- 랙만 선택한 그룹을 평행 이동한다. 실제 클릭해 드래그를 시작한 랙이 앵커다. 모든 선택 랙을 기준 줄 조회에서 제외하며 기준 줄에 남은 랙이 두 대 이상이어야 간격을 추론한다.
- 기존 단일 줄 붙이기의 이웃 양의 간격 중간값과 `RowGroupToleranceM`(기존 최소0.05m)을 재사용한다. 그룹 중 한 멤버가 기준 줄의 양 끝 한 간격 이내에 들어와야 한다. `RackPitchM`/L_Test0.66m를 붙이기 값으로 쓰지 않는다.
- 기준 줄과 모든 목적지의 평면 방향·물리 뒷면 선·실제 줄 묶기 키가 일치하고, 줄 방향 좌표가 관측 간격의 정수 슬롯에 있을 때만 붙인다. 빠진 슬롯을 가진 그룹도 상대 배치를 유지한 채 들어갈 수 있다.
- 비교의 `UE_DOUBLE_KINDA_SMALL_NUMBER`는 기존 엔진 부동소수점 UI 비교 오차다(뒷면 cm, 슬롯 번호/평면 단위 방향은 무차원). 물성·정밀도 피팅이나 새 하드웨어 추정값이 아니다. 방향/뒷면/간격이 맞지 않으면 원래 그룹5cm 스냅으로 돌아간다.
- 자동 회전·간격 재배열 없이 위치 차이만 공통 적용한다. 높이·방향·스케일과 상대 위치 유지. Alt는 줄 붙이기를 끄며 가이드가 사라진다. 기준 줄과 전체 목적지를 포함하는 뒷면 가이드를 그린다.
- 미리보기 중 실제 랙/배관은 유지한다. 총1cm 외부/내부 충돌이면 전체 빨강/확정 거절. Esc 전체 취소. 놓는 순간 기준 줄/Alt/호환성을 다시 확인한다.
- 기존 그룹 이동 명령으로 한 Undo/Redo를 기록한다. 확정 후 기존 방의 변경 감지/디바운스 재구축, Undo/Redo·Load 및 시뮬레이션 진입의 명시적 재구축을 유지한다. 월드 틱을 돌리지 않는 자동화 fixture는 확정 후 기존 `RebuildRoomNow`를 호출한다. 저장 v2의 형식/기본값은 바꾸지 않는다. 단일 랙의 방향 맞춤과 기존 그룹 자유 드래그는 유지한다.

## 직접 확인 절차 (새 기능의 실제 그룹 입력은 미검증)

Editor136.47s 성공. 실행 중 에디터의 Live Coding으로 막힌 최초 빌드19.65s는 환경 실패이며 정상 종료 후 해결했다. 검증 사전 보강의 증분 빌드10.02s/9.62s도 성공. 입력3종(RackGroupRowSnap/SingleRackRowSnap/MultiSelectionAndGroupDrag)은 같은 영향6종 실행에서 무경고 성공했다. 신규 목적지 오차0cm·전체 변환 Equals1e-9(액터cm 경계), 관측0.80m/설정0.66m 분리·가이드 범위·Alt·취소·호환 실패·선택 제외·1cm 판정·놓기 재확인·실제 줄 묶기 통과.

신규 RackGroupRowSnapPersistence/기존 GroupMoveUndoRedo/InventorySaveLoad도 무경고 성공. 한 Undo/Redo·둘째 충돌 전체 Redo 거절/기록 유지·줄2→1→2→1/배관14→15→14→15와4랙/독립 분기/CDU/패치/열·공기·덕트 결합을 확인했다. 기존 v2 Save→Undo→Load·재Load는 ID/설정/전체 변환/새 시계0·기록 초기화/중복 생성 없음 확인. 위치 복원 최대8.882e-16cm. 같은 초기조건 첫0.02s IT438189.754385W 유지·상대오차0, 각t0.82s 전역 잔차 최대3.128e-14/덕트9.875e-16/발산7.135e-08·압력 수렴으로 기존 기준 통과. 3대 전부하+1대 합성 저부하의 기존 전력 안전망342000~504000W 적용, 새 물성/피팅 없음.

6건을 한 번 실행해 성공/실패0/미실행0/진행0/종료0, 전체 반복 없음. 정규화/단위/기준은 CLAUDE.md 마지막 표. 근거: `Saved/Build_GroupRowSnap*.log`, `Saved/Logs/GroupRowSnap_Tests.log`, `Saved/Automation/GroupRowSnap`. NullRHI 축소 fixture이며 실제 L_Test 전체 운전·새 그룹 드래그 화면·FPS를 검증한 것은 아니다.

1. L_Test 배치 모드에서 같은 줄의 연속 두 랙을 선택한다. Ctrl+D로 빈 공간에 복제하면 방향/간격이 호환되는 시험 그룹을 만들 수 있다.
2. 복제 그룹의 한 랙을 드래그해 원래 줄의 빈 끝 슬롯 근처로 옮긴다. 가이드와 두 목적지, 상대 위치·방향/높이/스케일 유지, 미리보기 중 실제 랙이 움직이지 않는지 확인한다.
3. Alt를 누르면 가이드가 사라지고5cm 스냅으로 돌아가며, 해제하면 다시 붙어야 한다. Esc는 전체 취소. 한 목적지만 다른 장비에 겹쳐도 전체 빨강이며 놓아도 둘 다 이동하지 않아야 한다.
4. 빈 끝 슬롯에 확정한다. 두 랙/배관이 함께 반영되고 Ctrl+Z/Y가 둘을 함께 되돌리고 다시 붙이는지 확인한다.
5. 콘솔에서 `vrg.Layout.Save group_row_check` 후 그룹 이동을 Undo하고 `vrg.Layout.Load group_row_check`로 저장한 위치를 복원한다. 다시 Load해도 랙이 늘지 않고, 성공 Load 뒤 Ctrl+Z는 이전 기록을 실행하지 않아야 한다.

현재 도구의 Shift 유지+클릭/그룹 드래그 실패는 반복하지 않았다. 자동화 API 검사와 실제 입력 확인을 구분한다. FPS·전체 테스트·자동 그룹 회전·간격 재배열·다른 장비·방 편집은 범위 밖이다.
