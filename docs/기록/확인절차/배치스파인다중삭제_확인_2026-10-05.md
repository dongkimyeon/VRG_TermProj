# 스파인 다중 삭제 직접 확인 (2026-10-05)

사용자 후속 보고(2026-10-05): 아래 절차 모두 정상. 전체 삭제·Undo/Redo·충돌/이전 그룹 이동/R·혼합/입력 차단·케이블/미연결·반복/새 실행 Load만 사용자 확인으로 기록한다. 로그/캡처/FPS와 도구 오류 원인 확인으로 확대하지 않는다. 아래 미검증 문구는 당시 도구 확인 범위다.

새 다중 삭제 실제 UI는 미검증이다. 기존 클릭 geometry unavailable·Shift 유지 입력 실패에 환경 변화 근거가 없어 재시도하지 않았다. 단일 복제 직접 절차의 사용자 정상 보고는 새 다중 삭제 확인으로 확대하지 않는다. 드라이버 안내는 아니오로 진행한다.

## 직접 절차

1. 새 L_Test 배치 모드에서 콘솔 `vrg.Layout.Save spine_batch_before`로 원배치를 보관하고 콘솔을 닫는다. 기존 스파인과 실행 중 추가한 스파인을 Shift+클릭해 함께 선택한다. Delete 한 번으로 선택 전체와 해당 케이블/패치 표시가 사라져야 한다. 랙·냉각수 배관은 유지되고, 스파인이 없어진 줄은 기존 미연결 진단을 표시해야 한다.
2. Ctrl+Z 한 번으로 모든 스파인의 이름·설정·변환·기존/런타임 출처가 복원되고, Ctrl+Y 한 번으로 모두 다시 삭제되는지 확인한다. 스파인들에 이전 그룹 이동/R 편집이 있으면 삭제 Undo 후 그 편집들도 차례대로 Undo/Redo되어야 한다.
3. 삭제 후 복원 위치 하나를 다른 장비로 막고 Ctrl+Z를 누른다. 한 대도 복원하지 않아야 한다. 장애물을 비킨 뒤 같은 Undo를 재시도하면 전체 복원되어야 한다. 총1cm 판정 여유를 유지한다.
4. 스파인+랙/CDU/쿨러 혼합 선택 Delete는 전체 거절해야 한다. 미선택·드래그/사각형 선택·추가/복제 미리보기·패치 창·시뮬레이션에서도 스파인 삭제를 시작하지 않아야 한다. 기존 랙만 선택한 다중 삭제는 유지한다.
5. 기존/런타임 스파인이 함께 삭제된 상태를 `vrg.Layout.Save spine_batch_deleted`로 저장한다. 원배치 Load → 삭제 파일 Load → 같은 삭제 파일 재Load 및 새 L_Test 실행 Load로 삭제 반영·중복 변화 없음·이전 Undo/Redo 초기화를 확인한다. 원배치 파일 Load는 전체를 복원해야 한다. 마지막에 원배치를 Load한다. 임시 파일은 Saved/Layouts에 있으며 레벨 에셋은 바뀌지 않는다.

결과는 전체 삭제·Undo/Redo·충돌 전체 거절·이전 이동/R·혼합/입력 차단·케이블/미연결·저장 반복/새 실행 Load로 나눠 정상 또는 입력 순서와 관찰 내용으로 알려주면 된다.

## 검증 범위

자동화 측정과 단위/정규화는 CLAUDE.md 최신 다중 스파인 삭제 절을 따른다. NullRHI 축소 fixture의 열수지·압력 검사는 L_Test 전체 열운전/정상상태/FPS 확인을 대신하지 않는다. 성공 Undo는 새 열 상태를 사용한다. 실패 원복에만 직전 상태를 보존하는 메모리 백업을 사용한다. 다중 스파인 복제·다른 장비 기능·레벨 에셋 변경은 이번 범위 밖이다.
