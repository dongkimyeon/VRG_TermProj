# 부분 천장 구멍 선택·삭제 직접 확인

기존 구멍 추가 UI는 사용자 직접 확인 정상(2026-10-07). 아래는 새 기능의 별도 절차다. 화면/FPS는 자동화 결과에 포함하지 않는다.

1. L_Test를 실행하고 배치 모드로 들어간다. 그래픽 드라이버 안내가 나오면 ‘아니오’를 선택한다. 먼저 기존처럼 수동 방을 적용한다. 방 검증이 통과했던 값을 그대로 사용한다.
2. ‘부분 천장 추가’에서 장비/덕트와 겹치지 않는 판을 만든다. 예: 방 안의 빈 1m×1m 구역, 높이 2.625m. 기존 직접 확인 때 통과했던 판을 사용해도 된다.
3. ‘천장 선택·삭제’를 누르고 판의 청록/주황 외곽 내부를 클릭해 초록 선택을 확인한다. ‘선택 판 구멍 추가’를 열어 로컬 X 최소/최대, Y 최소/최대에 각각 0.125/0.875, 0.125/0.875m를 입력하고 추가 후 닫는다. 판이 1m×1m여야 이 예시가 들어간다. 개방 셀 0개면 거절 안내에 따라 셀 크기보다 큰 범위로 입력한다.
4. ‘구멍 선택·삭제’를 누른다. 판의 모서리/높이 핸들은 사라지고 판 선택은 유지된다. 보라색 계산 개방 상자를 클릭하면 그 구멍만 초록색으로 강조된다. 요청 청록 윤곽과 실제 보라 개방 범위는 다를 수 있다.
5. 판의 구멍 바깥이나 빈 곳을 클릭한다. 구멍 초록 강조만 해제되고 판은 그대로 선택된다. Delete를 눌러도 판/구멍 개수가 바뀌지 않아야 한다.
6. 구멍을 다시 클릭한 뒤 Delete를 한 번 누른다. 구멍 한 개만 사라지고 판은 유지된다. Ctrl+Z로 구멍을 복원, Ctrl+Y로 다시 삭제한다. 기록 복원 뒤에는 판/구멍을 다시 선택해야 한다.
7. 동일 좌표의 구멍을 두 번 추가한다. 겹친 보라 상자를 클릭하고 Delete를 누르면 목록의 앞 구멍 한 개만 삭제되고 다른 구멍 때문에 개방 표시가 남는다. 다시 클릭 후 Delete하면 마지막 구멍이 사라진다. 한 번의 Undo마다 하나씩 돌아온다.
8. 구멍 편집 중 Esc를 누르면 구멍 편집만 종료된다. 판의 모서리/높이 핸들이 다시 보이며 다음 Esc는 천장 편집을 종료한다. 숫자 창을 열면 구멍 편집은 끝나고 숫자 입력 중 Delete/장비 단축키는 차단된다. 패치/시뮬레이션 전환 뒤에는 구멍 편집이 종료된다.
9. 삭제 결과를 기존 Save로 저장하고 Load한다. 목록이 중복되지 않고 선택/편집·Undo/Redo 기록이 초기화되어야 한다. 시뮬레이션 진입 전에는 실제 공기 셀을 변경하지 않는다. 다음 진입 때 남은 구멍들의 합집합을 적용한다.
10. 거절 검증은 자동화에서 실제 CDU 외형을 통과하는 판의 구멍을 닫아 검사한다. UI에서 임의로 장비를 겹치게 만들 필요는 없다. 같은 상황을 재현했다면 삭제 거절 이유가 표시되고 선택·목록·기록이 유지되어야 한다.

결과 보고 예: ‘구멍 선택·삭제 직접 확인: 빈 곳/단일 삭제/중복/Undo·Redo/Esc/숫자·패치/저장 모두 정상’ 또는 실패한 단계와 안내 문구를 보내면 된다.
