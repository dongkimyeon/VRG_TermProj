# 설비 장비 배치 직접 확인 (S8 F8-1, 2026-10-21)

자동화(`VRG.Plant.Layout.*`)는 통과했다. 아래는 화면에서 사람이 확인할 항목이며 아직 아무도 확인하지 않았다(미검증).
F8-2(팔레트 추가·삭제) 전이라 설비 장비는 배치 파일로만 만든다.

## 준비

1. 패키지 또는 Editor `-game`으로 L_Test를 연다. 콘솔에서 `vrg.Layout.Save f8base`.
2. `Saved/Layouts/f8base.json`을 열어 `"plantEquipment": []`를 아래처럼 바꾼다. 위치는 방 +X 바깥이어야 한다
   (로그 `[VrgAir]` 격자 범위 또는 시뮬레이션 진입 로그의 방 범위를 보고 방 최대 X보다 2 m 이상 크게 잡는다).

```json
"plantEquipment": [
  {"name":"PlantFws0","plantId":"plant/fws0","kind":0,"x_m":40,"y_m":0,"z_m":0,"yaw_deg":0,"pitch_deg":0,"roll_deg":0,"size_x_m":2.4,"size_y_m":1.2,"size_z_m":1.3},
  {"name":"PlantFws1","plantId":"plant/fws1","kind":0,"x_m":43,"y_m":0,"z_m":0,"yaw_deg":0,"pitch_deg":0,"roll_deg":0,"size_x_m":2.4,"size_y_m":1.2,"size_z_m":1.3},
  {"name":"PlantChiller0","plantId":"plant/ch0","kind":2,"x_m":40,"y_m":4,"z_m":0,"yaw_deg":90,"pitch_deg":0,"roll_deg":0,"size_x_m":2.4,"size_y_m":1.2,"size_z_m":1.8}
]
```

   종류: 0 FWS 드라이쿨러, 1 CW 드라이쿨러, 2 냉수 칠러, 3 트림 칠러. 같은 파일 `settings`에 `"plantEnabled": true`로 바꾼다.
3. 콘솔 `vrg.Layout.Load f8base`. 로그에 `설비 장비 3대 (이전 0대 교체)`, `설비 켬`이 나와야 한다.

## 확인 항목

| # | 조작 | 기대 | 결과 |
|---|---|---|---|
| 1 | 배치 모드에서 `F`(선택 없음) | 방과 설비 장비 3대가 함께 보인다(드라이쿨러 주황 회색, 칠러 파랑) | 미확인 |
| 2 | 드라이쿨러 클릭 → 드래그로 방 쪽으로 | 방과 겹치는 순간 빨강 표시, 놓으면 제자리 | 미확인 |
| 3 | 방 바깥으로 드래그 → 놓기 → `Ctrl+Z` → `Ctrl+Y` | 5 cm 스냅 이동, 한 번에 되돌림·다시 | 미확인 |
| 4 | 칠러 선택 후 `R` | 90° 회전(방과 겹치면 거절 로그 `회전 거절`) | 미확인 |
| 5 | `Enter`로 시뮬레이션 진입 | 로그 `[Plant] 배치한 설비 장비: FWS 드라이쿨러 2, ... 냉수 칠러 1`, `드라이쿨러 2대` | 미확인 |
| 6 | 시뮬레이션 화면에서 설비 장비 쪽을 본다 | 배치한 자리에 상태 색 상자가 겹쳐 보이고 FWS 리턴 배관이 각 드라이쿨러를 지난다 | 미확인 |
| 7 | `vrg.Layout.Save f8after` → 장비를 옮긴 뒤 `vrg.Layout.Load f8after` | 저장한 자리로 돌아온다 | 미확인 |

드라이쿨러 2대는 L_Test 설계 열보다 훨씬 적어서 5번 뒤 로그에 FWS "설정점 미달"이 나오는 것이 정상이다(대당 크기가 카탈로그 한 대로 고정).
