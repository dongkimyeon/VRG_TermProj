# 설비 장비 배치 직접 확인 (S8 F8-1·F8-2, 2026-10-21)

자동화(`VRG.Plant.Layout.*` 4건)는 통과했다. 아래는 화면에서 사람이 확인할 항목이며 아직 아무도 확인하지 않았다(미검증).

## 준비

1. 패키지 또는 Editor `-game`으로 L_Test를 연다. 콘솔 `vrg.Plant.Enable 1`.
2. `Enter`로 시뮬레이션에 한 번 들어갔다가(설비 자동 대수가 이때 정해진다) `Enter`로 배치 모드로 돌아온다.
   로그 `[Plant] 드라이쿨러 N대`의 N을 적어 둔다.

## 확인 항목

| # | 조작 | 기대 | 결과 |
|---|---|---|---|
| 0 | (준비 2 전에) 팔레트 `FWS 드라이쿨러` | 추가가 시작되지 않고 빨간 문구 "설비 자동 대수를 아직 모른다…" | 미확인 |
| 1 | 팔레트 `FWS 드라이쿨러` | 커서에 주황 상자, 방 +X 바깥에 하늘색 상자 N개(실제 장비로 바뀔 자동 배치) | 미확인 |
| 2 | 상자를 방 위로 가져간다 / 하늘색 상자 위로 가져간다 | 빨강, 클릭해도 추가 안 됨 | 미확인 |
| 3 | 빈 바깥 자리에서 `R` 후 클릭 | 90° 돌아간 장비 1대 추가, 하늘색 자리에 N대가 실제 장비(주황 회색)로 생김. 로그 `자동 배치 N대를 실제 장비로 전환` | 미확인 |
| 4 | `Ctrl+Z` → `Ctrl+Y` | 한 번에 N+1대가 모두 사라졌다가 다시 생김 | 미확인 |
| 5 | 한 대 클릭 후 드래그로 방 쪽 / 바깥 | 방과 겹치면 빨강·제자리, 바깥은 5 cm 스냅 이동 | 미확인 |
| 6 | 한 대 선택 후 `Delete` → `Ctrl+Z` | 사라졌다가 같은 자리로 돌아옴 | 미확인 |
| 7 | `F`(선택 없음) | 방과 설비 장비가 모두 보이는 시점 | 미확인 |
| 8 | `Enter`로 시뮬레이션 진입 | 로그 `[Plant] 배치한 설비 장비: FWS 드라이쿨러 N+1`, 설비 마당에서 배치한 자리에 상태 색 상자, FWS 리턴 배관이 각 드라이쿨러를 지남 | 미확인 |
| 9 | 배치 모드에서 `vrg.Layout.Save f8ui` → 장비 하나 옮김 → `vrg.Layout.Load f8ui` | 저장한 자리로 돌아오고 로그 `설비 장비 N+1대 (이전 N+1대 교체)`, `설비 켬` | 미확인 |

같은 순서로 `냉수 칠러`(분리 구성에서 칠러 자동 3대: 운전 2 + 대기 1)도 한 번 해 본다. 칠러를 1대만 남기면 운전 1·대기 0이 되고 대당 용량이 커진다(합계 용량은 그대로).
