## N0 음향 자료·소스 대응 조사 (2026-11-24)

소음 계획의 N0 조사 완료. 조사한 계산 코드는 `ba2836f` 기준이며 계획 문서 커밋은 `34fda41`이다. 공식 제품 자료와 소스의 입력·집계·기하를 대조해 첫 계산 대상으로 Liebert 940 60 Hz Standard의 유닛 전체 광대역 음원을 선정했다. 아래 값은 자료 전사와 손계산 검증이며 게임에서 계산한 소음 결과는 N1부터 검증한다. 다음 단계는 N1 음원 계산이다. [단계 계획](../../Tools/소음_계획.md)

### 3. 수량·정지 상태에서 발견한 연결 주의점

**드라이쿨러 유닛과 팬 개수.** `FDryCoolerCatalog::Fans=8`이며 정격 팬 전력도 8개를 이미 합친 값이다. `FDryCoolerBank::Units`는 카탈로그 유닛 개수다. `SetTrippedDryCoolers`는 유닛 개수만큼 Tripped를 늘리고 해당 유닛 팬 모두를 정지시킨다. 따라서 시연 기록의 '24개'를 기준으로 팬 음원24개를 만들면 집계가 틀어진다. 예를 들어 FWS24유닛이면 물리 팬은192개에 해당하며, 음향 프로필을 유닛 단위로 쓰면 음원24개로 합산한다. 실제 대수는 실행 시 getter로 읽는다.

**정확한 속도 입력.** `PlantDisplay.cpp`는 CW의 표시용 bRunning에 방출 열의 유무를 사용한다. 소음은 그 색상 플래그를 사용하지 않고 `GetDryCoolerTruth(Cw,k).FanRatio`를 사용한다. 물이 흐르지 않아 방출열0인 경우에도 팬 상태는 별도일 수 있다. 배치 모드/설비 끔의 구조만 표시된 마당은 운전 중 음원 목록과 구분한다.

**랙 팬 개수.** 현재 프리셋은 컴퓨트 트레이18×8, 전원 셸프8×6, 관리 스위치2×4로 랙당200팬이다. NVLink 트레이9개는 코드의 fanless 장비다. Quantum 스파인은 슬롯당 대표 팬6개다. 이 수량은 현재 모델이며 실제 제품의 모든 팬 배치가 확인됐다는 뜻은 아니다. 케이스 전체 소음 프로필을 채택하면 팬별 프로필 합계를 함께 더하지 않는다.

**음원 ID.** 배치 설비는 종류별 Identity 정렬 순서가 모델 UnitIndex와 대응한다. 액터 Identity와 Loop/Kind/Index를 연결하고 재진입 시 다시 만든다. 자동 설비의 실행별 키는 저장용 영속 ID와 구분한다. 삭제/복제/종류별 자동→액터 전환에서 같은 유닛을 한 번만 등록하는 검사를 N2/N5에 둔다.

### 4. 첫 프로필의 단위·산술 대조

첫 프로필 제안 키는 `liebert-940-60hz-standard-unit`이며 유닛 전체의 광대역 LwA97.4 dB를 저장한다. 아래 W 값은 A 보정된 파워의 선형 등가값이다. 주파수 보정 전 실제 음향 파워·기존 열 장부의 입력값과 구분한다.

| 항목 | 산술 결과 | 의미 |
|---|---|---|
| 유닛1대의 A 보정 등가 파워 | 0.00549540873858 W | `1e-12 * 10^(97.4/10)` |
| 같은 팬8개로 균등 분할 | 88.3691001301 dB/팬 | `97.4 - 10log10(8)`, 실제 팬별 측정값은 미확보 |
| 같은 유닛24대의 파워 합계 | 111.202112417 dB | 총 음원 파워 합계. 수신점의 음압은 거리·방향을 적용해 계산 |
| 유닛1대 속도비0.5 | 82.3485002168 dB | 후보 팬 속도식의 손계산. 해당 장비의 다중속도 실측 검증은 후속 |
| 유닛24대 속도비0.5 | 96.1506126339 dB | 같은 속도 근사의 파워 합계 |

N0 검증은 공식 표와 코드 상수·정렬/집계 경로 대조, 위 로그 변환/선형 재합산의 독립 산술 확인과 문서 링크·`git diff --check`다. 이 숫자는 런타임 소음 구현의 측정 오차표를 대신하지 않는다. N1에서 C++ Automation 검사의 실제 오차·허용치를 `docs/오차기준.md`에 기록한다.

### 6. N1 인수 항목과 남은 자료 조사

- 첫 구현은 유닛 단위의 S1 광대역 프로필로 dB↔선형 변환·비상관 합성·속도 근사·정지·미확보 상태를 만든다. 프로필에는 측정량·A 보정 여부·집계 범위·운전 기준·출처를 보존한다.
- 대역 프로필을 지원할 때 S5의 대역별 PWL/A 보정 합계로 보정 중복 검사를 구성한다. 채택 전 본문/주석을 확인하고 허용 차이는 실제 대조 결과로 정한다.
- S2/S3의 음압→파워 변환은 해당 모델의 측정 환경/지향성이 확인되거나 명시적인 추정 프로필이 정의됐을 때 진행한다. 상온78.4 dBA도 같은 원칙을 적용한다.
- 실내 제품 SKU·흡음률, 펌프·Carrier19XR 계열 음향 자료, 모든 시작 음원의 다중속도/부하별 파워 곡선은 후속 조사 목록이다. 자료가 있는 음원만의 합계에는 누락 음원을 표시한다.
- N0 완료는 시작 음원과 소스 대응표 선정·미확보 목록 작성까지다. 전체 시설 소음의 정확도는 각 전달 단계와 실제 자료 대조로 검증한다.

## N1 음원 계산 기반 구현·수치 검증 (2026-11-24)

`Simulation/Acoustics/NoiseSource.h/.cpp`에 일반 C++ 계산 기반을 추가했다. `TryDbToLinear`/`TryLinearToDb`는 파워W와 평균제곱 음압Pa²를 구분하고 오류 시 호출자 출력을 보존한다. 지수 안에 기준값을 넣어 중간 pow overflow를 피하고 합성은 최대 dB를 기준으로 스케일링한다. 음원과 대역 계산은 상태를 누적하지 않는 함수다.

첫 프로필 `Liebert940Standard60Hz()`는 N0의 유닛 전체 LwA97.4 dB와 출처·모델·표/페이지·운전 조건·정격 대비 속도 기준을 보존한다. `Evaluate`는 한 유닛의 파워를 계산하며 `Combine`은 동일 측정량/보정의 비상관 레벨을 합산한다. 대역은 명목63/125/250/500/1000/2000/4000/8000 Hz를 지원하고 중복·뒤섞인 주파수/길이 불일치/미지원 중심 주파수를 거절한다. A 보정된 입력은 그대로 합산해 중복 보정을 방지한다. 스펙트럼 없는 광대역의 보정 변경은 MissingData로 표시한다.

결과는 Known/Silent/MissingData/InvalidInput, 선택적 유한 dB, 확보/정지/미확보 음원 개수와 추정 여부를 갖는다. 0 dB는 유한한 기준 파워이며 정지 상태와 구별한다. 부분 합계에는 누락 개수가 남고 중첩 합계도 개수를 유지한다. 음압 자료를 파워 프로필에 넣거나 서로 다른 측정량·보정을 합치는 입력은 거절한다. 잘못된 프로필은 정지 상태에서도 거절한다. 음원 ID의 중복 제거는 N2 수집 경로에서 다룬다.

팬 속도 보정은 `50log10(r/rref)` 후보 근사다. 다른 속도를 평가할 때 bEstimated를 표시하고, 근사를 허용하지 않은 프로필은 MissingData를 반환한다. 실제 제품의 다중속도 실측 검증은 자료 후속으로 남긴다. 현재 단계는 정격 자료와 공식 근사·해석값을 검증한 계산 기반 완료다. N1 계획의 제품별 다중운전점 대조는 자료 확보 후 이어간다.

검증은 첫 Editor555.70s와 소음6종 측정 후 허용치1e-12를 설정해 최종 Editor56.01s/소음6종+관련 기존5종 총11종 무경고 성공했다. 최종 파워 상대1.177e-14, 평균제곱 음압 상대1.144e-14, 왕복0.000e+00 dB·합산0.000e+00 dB·속도0.000e+00 dB·대역0.000e+00 dB다. 단위·정규화·기준·미검증 범위는 [오차 기록](../오차기준.md)의 소음N1 절을 따른다. 빌드 경고3건은 기존 GPU API 폐기 예정·FloorCm 초기화·Name 가림 경고이며 새 소음 파일의 경고는 없었다.

공식 보정 자료를 다시 확인했다. [ASHRAE Fundamentals2021 chapter8 table5](https://handbook.ashrae.org/Handbooks/F21/SI/F21_Ch08/F21_Ch08_si.aspx), [AMCA Basics of Fan Noise slide56](https://www.amca.org/assets/resources/public/assets/uploads/FINAL-_AMCA_Fan_Noise_RG.pdf). 수치 fixture는 표의 계수와 별도 합성 입력을 사용하며 실제 실내/실외 음압 자료는 이후 단계에서 연결한다.

다음은 N2 실제 FWS/CW 유닛 상태·위치/ID 수집과 자유장 수신점 계산이다. 이번 N1은 독립 계산 API이며 게임/HUD·웹의 소음 표시와 실외 전파는 아직 연결하지 않았다. Game 빌드·전체 VRG·UI/FPS 반복은 실행하지 않았다.

## N2 실외 드라이쿨러 수신점 (2026-11-24)

`NoiseOutdoor`는 3차원 거리와 전구면 또는 이상적 반구면 가정으로 유닛별 LwA를 수신점 LpA로 변환하고, N1의 비상관 에너지 합산을 사용한다. FWS/CW 각각의 운전·고장·팬 속도는 `GetDryCoolerTruth`에서 읽는다. 60 Hz Liebert 940 장비 전체 97.4 dB LwA 프로필을 유닛당 한 번 적용한다. 열 카탈로그의 모델을 식별할 정격 항목이 기본값과 달라진 능동 유닛은 미확보로 기록한다. 정지는 선형 기여 0이며, 가동 유닛의 자료·전달 누락은 개수와 부분 합계로 표시한다.

배치 설비는 `VrgPlantEquipment::Identity`와 기존 야드 표시의 세계 좌표 중심(m)을, 자동 설비는 FWS/CW 유닛 인덱스 기반 ID와 도식 위치를 사용한다. 유닛 외곽 상자 대각선 두 배 미만의 거리는 근접으로 집계한다. 이 기하 기준은 유한 크기 장비의 원거리 조건을 검증한 값과 별개다. 자동 위치는 현장 측량값이 확보되면 교체할 수 있다. 회전 방향별 방사·기상·지면·차폐·배경 소음과 다른 장비의 기여는 N2 결과의 범위 밖이다.

1. 설비가 켜진 시뮬레이션에서 플레이 콘솔에 `vrg.Noise.Probe 45 25 2`를 입력한다. 좌표 단위는 월드 원점 기준 미터다. 끝에 `hemisphere`를 붙이면 이상적 반구면을 사용한다. 기본값은 `sphere`다.
2. 진행 후 `vrg.Noise.Status 10`을 입력하면 최근 스텝 10개의 LpA, 설비 활성 상태, 확보/정지/미확보/근접 수와 속도 추정 표시, 팬 전력 W, 방열 W, FWS/CW 공급 K가 로그에 나온다. 개수 생략 시 최신 1개다.
3. 지정한 한 점에 대해 최근 512 스텝을 보관한다. Tick과 예열 모두 완료된 스텝만 기록한다. 시뮬레이션 시계가 초기화되면 기존 수신점에서 새 이력을 시작한다. 좌표 재입력은 이력을 비우며 `vrg.Noise.Probe clear`는 수집을 끈다.

검증 월드의 같은 수신점에서 FWS/CW 2+2대 정상 38.426287 dBA, FWS 1대 고장 37.444432 dBA, 전부 정지 시 기여 0을 확인했다. 로그 공간 계산과 독립 선형합의 차이는 최대 7.105e-15 dB였다. 자동화 결과와 수치 기준은 [오차 기록](../오차기준.md)을 따른다. 이 예비 모델의 현장 음압·제품 속도별 실측 대조는 후속이다.

## N3 실외 환경 전달과 부지 경계 (2026-11-25)

FWS/CW 드라이쿨러의 실제 팬 운전점과 배치 중심을 N2에서 재사용한다. Liebert 940의 공개 자료는 유닛 전체 LwA 97.4 dB를 제공한다. 대역은 Airedale DR95 수평형 표준 팬 정속 운전의 63 Hz~8 kHz 옥타브 음향 파워 형태를 차용한다. A 보정 총량 87.2002 dB에서 약 +10.1998 dB를 각 대역에 적용해 전체 97.4 dB를 보존한다. 모든 N3 소음값은 스펙트럼 추정으로 표시한다. [Vertiv Table 2.1](https://www.vertiv.com/48ea08/globalassets/shared/liebert-air-cooled-direct-drive-drycoolers-technical-design-manual_00.pdf) · [Airedale 문서 9308503 V2_06_2020, 22쪽 DR95 Power](https://www.airedale.com/wp-content/uploads/2020/01/TM_DRYCOOLER_D10-D95_9308503_V2_06_2020.pdf)

- 대기 흡수는 ISO 9613-1:1993의 순음식을 정확한 옥타브 중심주파수에서 평가한다. 기상 입력은 설비 외기 온도(−20~50 °C), 사용자 상대습도·기압이다. 구면 확산에 ISO 9613-2:1996 §7.3.1 Table 3의 음원·수신점 인근과 중간 경로 지면 효과를 더한다. 각 구간은 같은 평탄·균질 지면 계수 G를 사용한다. [ISO 9613-1](https://www.iso.org/standard/17426.html) · [ISO 9613-2:1996 공개 참고본](https://puc.sd.gov/commission/dockets/electric/2019/el19-003/KMExhibit9.pdf)
- 차폐판은 세계 XY의 두 끝점과 지상 높이로 정의한 불투과 수직면이다. 시선을 가리고 투영 폭이 파장보다 넓은 대역에서 위·양쪽 모서리의 단일 회절 에너지를 합산한다(§7.4, `Kmet=1`, 경로별 회절 `Dz≤20 dB`). 상단 회절은 지면 효과 중복분을 상쇄한다. 다중 차폐는 가장 큰 개별 삽입 손실을 채택한다. 반사 에너지율이 0.2를 넘는 면은 §7.5의 유효 크기 조건과 양쪽 구간의 가시성을 통과한 1차 정반사를 합산한다. 콘솔의 반사 증가량은 차폐를 반영한 직접 경로 수준에서 반사를 합쳤을 때의 dB 증가다. 건물 외벽은 차폐판으로 명시한다. [ISO 9613-2:1996 §7.4~7.5](https://puc.sd.gov/commission/dockets/electric/2019/el19-003/KMExhibit9.pdf)
- 대역별 경로를 계산하고 A 보정을 한 번 적용해 유닛별 전달 계수로 합성한다. 실행 중에는 기존 속도 보정과 유닛 비상관 합산을 적용한다. 기하·기상 입력이 바뀌면 경로를 다시 계산한다. 새 실행은 설정을 유지하고 최신 결과를 초기화한다. 지면 아래 음원, 근접 음원 또는 지원 온도 밖의 가동 기여는 미확보로 기록한다.

플레이 콘솔에서 설비를 켜고 아래와 같이 설정한다. 세계 단위는 m이며 경계와 벽의 높이는 지정한 지면 기준이다.

```text
vrg.Noise.Environment 0 0 70 101.325
vrg.Noise.Boundary 10 2 45 -10 45 10
vrg.Noise.Barrier add 35 -40 35 40 6
vrg.Noise.BoundaryStatus
vrg.Noise.Path 1 0
```

`Environment` 인수는 지면 Z, 균질 지면 계수 G(0=단단함, 1=다공성), 상대습도 %, 기압 kPa다. 예시는 기본값이다. `Boundary`는 최대 간격, 지상 수신 높이, XY 좌표 쌍의 순서다. 마지막에 첫 좌표를 반복하면 닫힌 경계가 되며 최대 수신점은 64개다. `Barrier add` 뒤에 반사 에너지율 0~1을 선택적으로 붙일 수 있다(기본 0). 최근 완료 스텝의 LpA는 `BoundaryStatus [수신점 번호]`, 항별 dB는 `Path 수신점번호 음원번호`로 읽는다. 번호는 0부터 시작한다. `Barrier clear`와 `Boundary clear`로 해당 설정을 지운다.

정상 예제 중간 수신점은 차폐 전 40.068559 dBA, 차폐 후 24.743729 dBA였다. 경계는 최근 스텝의 결과를 갖고 N2 단일점은 별도 이력을 보관한다. 적용 범위는 평탄한 지면, 독립 점음원, 입력한 차폐면과 1차 반사다. 복합 지형·다중 가장자리/반사·현장 스펙트럼과 기상 검증, 2024판 적합성, 지도·저장은 후속이다. [검증 기록](../오차기준.md)

기존 균일 공기 격자 고체 마스크에서 면으로 연결된 공기 셀을 한 잔향 구획으로 묶고 노출 면적을 합산한다. 고체를 가로지르는 직접음은 제외한다. 송풍 경로를 모사하는 장비와 벽·커튼·천장·구멍은 실제 계산 격자의 형상을 따른다. 작은 개구가 격자로 해상되면 같은 확산장을 공유하고, 밀폐 구획은 다른 음원의 잔향을 전달하지 않는다. 재질 기본은 콘크리트와 판금의 참고 흡음률이며 8 kHz는 4 kHz 값을 연장했다. 광대역 음원에는 1 kHz 잔향 계수를 사용한다. [ASHRAE 2023 Applications ch.49 Table 12](https://handbook.ashrae.org/handbooks/A23/SI/a23_ch49/a23_ch49_si.aspx) · [ASHRAE 2025 Fundamentals ch.8](https://handbook.ashrae.org/handbooks/F25/IP/F25_Ch08/F25_Ch08_ip.aspx)

수신점은 바닥 위 높이(기본 1.5 m)에서 계산한다. 슬롯 팬 0.5 m, CRAH·CDU 1 m 미만의 가시 경로는 점음원 근접으로 분류한다. 구획에 배치할 수 없는 가동 음원 수와 고체/실외 수신점을 표시한다. 실내 값은 예비 추정이다. 물리적 투과·개구 크기에 따른 구획 간 전달·잔향의 시간응답·현장 소음과의 대조는 후속이다.

| 플레이 콘솔 | 인수와 결과 |
|---|---|
| `vrg.Noise.IndoorProbe x y [height]` | 세계 XY m와 바닥 위 m로 한 점을 지정한다. `clear`는 실내 수집을 해제한다. |
| `vrg.Noise.IndoorMap spacing [height]` | 방 수평면을 최대 간격 m로 샘플링한다. 최대 256점이다. |
| `vrg.Noise.IndoorStatus [index]` | 마지막 완료 스텝의 위치·구획·dBA·누락·근접·직접음 차폐를 출력한다. 기본은 전체, 인덱스는 0부터다. |
| `vrg.Noise.IndoorAbsorption a63 ... a8000` | 각 옥타브의 모든 면에 적용할 0~1 흡음률 8개를 지정한다. `reset`으로 기본값을 복원한다. |
| `vrg.Noise.IndoorCduLwA level` | 가동 CDU의 유닛 전체 A 보정 음향 파워 dB를 지정한다. `clear`로 미확보 상태로 돌린다. |

설정과 배치가 같을 때 경로를 재사용하고, 스냅샷은 완료 스텝에서 시뮬레이션 시간 0.2 s 이상 간격으로 갱신한다. 새 실행은 같은 수신 설정으로 기하와 결과를 다시 만든다. 통합 시험의 한 점에서 추정 흡음률을 0.5로 올리자 98.276384→83.802814 dBA가 됐다. [검증 기록](../오차기준.md)

## N5 게임·웹 소음 지도와 리포트 (2026-11-26)

| 작업 | 사용 방법 |
|---|---|
| 수신점 설정 | 예시 `vrg.Noise.IndoorMap 1 1.5`. 실외는 `vrg.Noise.Probe`와 `vrg.Noise.Boundary`로 지정한다. |
| 게임 표시 | `vrg.Noise.Show 1`로 켜고 `0`으로 끈다. 화면 중앙에 가까운 점에서 순간 LpA, LAeq, 시각과 누락 수를 본다. |
| 웹 표시 | 대시보드 소음 탭 `/dashboard#noise`에서 수신점을 고른다. 실내는 평면도 배경과 함께 표시하고, 선택점의 순간값·LAeq·시간·상태·시계열을 읽는다. |
| 배치 설정 | `vrg.Layout.Save <이름>`과 `vrg.Layout.Load <이름>`. v2 `settings.noise`에 위치·경계 간격/높이·대기·지면·차폐판·실내 흡음률·CDU LwA를 저장한다. 예전 파일에서 필드가 없으면 음향 설정을 유지한다. |
| 리포트·A/B | 웹 저장 및 비교 탭 또는 `vrg.Eval.Report <이름>`과 `vrg.Eval.Compare <A> <B>`. `Saved/Reports`의 JSON에 전체 수신점의 최근 시계열, 모델·설정, 구간 집계를 저장한다. Markdown은 수신점 요약과 A/B를 제공한다. |

HUD와 웹 지도는 40~100 dBA 색 범위를 공유한다. 회색은 정지 무음, 보라는 자료 누락이며, 지도 범례 밖의 수치도 선택하면 읽을 수 있다. LAeq는 완료된 고정 스텝 시간과 음압 제곱 에너지의 누적값이다. 실내 모델은 최신 스냅샷을 다음 샘플까지 유지한다. 표본은 수신점당 0.2 s 이상 간격의 최근 256개를 보관한다. 그래프와 별개로 LAeq는 수집 구간 전체를 누적한다.

정지 무음은 에너지 0으로 처리한다. 유한한 0 dBA, 부분값, 자료 없음, 수신점 위치가 계산 범위 밖인 상태를 구분한다. 부분 LAeq에는 전체 경과 시간을 분모에 두고 확보된 에너지만 포함한 하한값과 불완전 시간을 기록한다. 일시정지 동안 누적 시간은 늘지 않는다. 재시작, 새 실행, 음향 설정 적용 시 이력이 초기화된다. 설정을 잘못 입력한 배치 파일은 적용 전에 거절한다.

A/B는 수신 유형, 세계 XYZ 좌표, 시뮬레이션 시작·끝이 같은 점을 비교한다. 양쪽의 LAeq가 완전할 때 차이를 내고 IT·냉각 전력 및 최고 흡기 온도의 구간 평균을 함께 표시한다. 비교 기준은 시뮬레이션 시간이며 물리 추정과 측정 범위는 N2~N4 모델을 따른다. [수치 검증](../오차기준.md)

## N6 통합 검증과 시연 (2026-11-27)

2랙·CDU·FWS 드라이쿨러 2대·CW 드라이쿨러 1대의 동일한 배치를 새 월드에서 두 번 실행했다. 온도·압력·유량·열과 물 장부를 완료 스텝마다 비교했다. 물 검증에는 냉각판과 랙 공급 분기 3 mm 누수를 사용했다. 같은 시점에 부하와 고장을 적용하고, 소음 수집을 켠 실행에서만 음향 설정을 변경했다.

| 장면 | 같은 수신점의 관측 |
|---|---|
| 정상 → 랙 부하율 0.4→0.95 | IT 122.714→223.833 kW, 랙 팬 383.616→383.616 W, 통로 LpA 97.239325→97.239325 dBA. 짧은 과도 구간에서 기록한 값이다. |
| FWS 1대 고장 | 경계 LpA 42.006740→40.299793 dBA. FWS 1대 정지 후 남은 FWS 1대와 CW 1대의 기여가 남았다. FWS 공급 305.127537→304.992695 K. |

게임 HUD의 흰 테두리는 화면 중앙에 가까운 선택점을 가리킨다. 순간 LpA·LAeq와 누락 수는 하단 범례 위에서 읽는다. 웹에서는 소음 탭의 수신점을 골라 시계열을 본다. 화면과 숫자는 모델 추정이며 제품별 회전수 음향 곡선과 실제 시설의 음압은 추가 자료가 필요하다.
