## 2. 문제와 목표 — 배치와 냉각 조건을 바꿔 보는 가상 실험 공간 (1분 30초)

**멘트**
> AI 서버 랙 한 대는 전기난로 약 60대만큼, 약 120킬로와트의 열을 냅니다. 이 열은 두 길로 빠져나갑니다. 하나는 칩에 붙은 냉각수, 다른 하나는 방 안의 공기입니다.

> 다만 아직 실제 데이터센터 측정값으로 보정하기 전 단계입니다. 공개된 장비 사양으로 계산하는 학습·실험용 프로그램이라는 점을 먼저 말씀드립니다.

## 4. 계산의 원리 — 어떤 물리 모델로 만들었나 (1분 30초)

**멘트**
> 화면의 온도는 미리 만든 애니메이션이 아니라 네 가지 물리 모델로 계산한 결과입니다.
>
> 첫째, 서버의 열입니다. 냄비가 불 위에서 서서히 데워지듯, 랙을 칩 단위 613개 부분으로 나눠 시간에 따라 온도가 오르내리는 것을 계산합니다.
>
> 둘째, 배관의 물입니다. 수도꼭지를 여러 개 틀면 물이 나뉘듯, 펌프의 힘과 배관 저항이 맞는 지점을 찾아 랙마다 흐르는 물의 양을 구합니다.
>
> 셋째, 방 안의 공기입니다. 방을 25센티미터 칸으로 잘게 나눠 칸마다 온도와 바람을 계산합니다. 뜨거운 공기가 위로 뜨는 효과와 팬 바람, 난류까지 넣었습니다.
>
> 넷째, 냉각 장치입니다. 열교환기는 아무리 키워도 효율에 한계가 있는데, 그 특성을 반영했습니다.
>
> 이 네 모델은 0.02초마다 같은 시계로 함께 계산됩니다. 들어온 열이 나간 열과 쌓인 열의 합과 맞는지도 계속 확인합니다. 이 부분은 뒤에서 다시 말씀드리겠습니다.

## 5. 기능 1 — 장비 배치·편집 (3분)

**멘트**
> 첫 번째 기능은 장비 배치입니다. 랙, 네트워크 장비, CDU, 공조기를 추가·이동·회전·복제·삭제할 수 있습니다. 여러 대를 한꺼번에 골라 옮길 수 있고, 5센티미터 격자에 맞춰 놓이며, 장비끼리 겹치면 놓이지 않습니다. 실행 취소와 다시 실행도 됩니다.
>
> 중요한 점은, 여기서 놓은 위치가 그대로 이후 열 계산의 입력이 된다는 것입니다. 그럼 직접 보여 드리겠습니다.

**시연** (배치 모드에서 시작)
1. `F`를 눌러 전체 장비가 보이게 합니다. 카메라는 마우스 오른쪽 버튼을 누른 채 움직이고 WASD로 이동, 휠로 확대·축소합니다.
2. **랙 이동:** 랙 하나를 클릭하고(초록 상자) 끌어서 옆으로 옮깁니다. 다른 랙과 겹치는 곳으로 끌면 빨갛게 바뀌고 놓이지 않는 것을 보여 줍니다.
   - 말할 것: "겹치면 빨갛게 표시되고 놓이지 않습니다."
3. **그룹 이동:** Shift+클릭으로 랙 2대를 함께 선택하고 끌어서 같이 옮깁니다.
4. **복제 미리보기:** 2대를 선택한 상태에서 `Ctrl+D` → 마우스를 빈 바닥으로 옮기면 주황 상자가 따라옵니다. 빈 곳을 클릭해 복제합니다.
   - 말할 것: "복제하면 배관과 케이블도 자동으로 다시 연결됩니다."
5. **복원:** `Ctrl+Z`를 몇 번 눌러 복제와 이동을 되돌리고, `Ctrl+Y`로 다시 실행해 보인 뒤 다시 `Ctrl+Z`로 원래대로 돌려놓습니다.

> 시연 팁: 복제 미리보기 중에 그만두려면 `Esc`. 선택을 풀려면 빈 곳을 클릭합니다.

## 6. 기능 2 — 방·천장·구멍 편집 (2분 30초)

**멘트**
> 두 번째는 방 자체를 편집하는 기능입니다. 방 크기는 장비에 맞춰 자동으로 정할 수도 있고, 직접 지정할 수도 있습니다. 천장 높이를 바꿀 수 있고, 천장 일부를 판으로 막거나 그 판에 구멍을 뚫을 수 있습니다.
>
> 바뀐 방 모양은 다음 계산을 시작할 때 공기 계산 격자에 반영됩니다. 구멍은 방 안에서 공기가 통하는 길입니다. 공기를 건물 밖으로 빼는 배기 팬은 아직 구현 범위가 아닙니다.

**시연** (배치 모드)
1. 콘솔에서 `vrg.Layout.Load PPT_Shoot` → 수동 방, 천장 판 1장, 구멍 2개가 있는 배치가 불러와집니다.
2. **방 크기:** `[방 범위 편집]` → 바닥 모서리의 노란 점을 끌면 방 윤곽(주황)이 따라 움직이고, 화면 왼쪽 위에 계산 격자 크기가 바뀌어 표시됩니다. 놓으면 확정됩니다.
3. **천장 높이:** 같은 모드에서 천장 가운데의 높이 점을 위아래로 끕니다. `Esc`를 두 번 눌러 모드를 끝냅니다.
4. **천장 판:** `[천장 선택·삭제]` → 천장 판을 클릭하면 초록으로 선택됩니다. 판 안쪽을 끌어 옮겨 봅니다.
5. **구멍:** `[구멍 선택·삭제]` → 보라색 구멍을 클릭해 선택하고 끌어 옮깁니다.
6. **되돌리기:** `Ctrl+Z`를 여러 번 눌러 방·판·구멍 변경을 순서대로 되돌립니다.
   - 말할 것: "방 편집도 장비 편집과 같은 실행 취소 기록에 들어갑니다."
7. 끝나면 `[구멍 편집 끄기]`, `[천장 편집 끄기]`로 모드를 닫습니다.

> 주의: 다음 시연을 원래 배치로 하려면 `vrg.Layout.Load base`로 기본 배치를 다시 불러옵니다(발표 전 준비 4번에서 저장).

## 7. 기능 3 — 배관·케이블 연결과 진단 (2분)

**멘트**
> 세 번째는 배관과 케이블입니다. 랙과 CDU 사이의 냉각수 배관, 랙과 네트워크 장비 사이의 데이터 케이블이 자동으로 연결되고, 장비를 옮기면 경로도 다시 만들어집니다.
>
> 또 포트가 겹쳐 쓰였는지, 연결이 안 된 선이 있는지, 선끼리 부딪히는지를 찾아 줍니다. 다만 이건 배선 계획과 진단 기능입니다. 모든 장애물을 자동으로 피하거나 케이블의 굽힘·장력까지 계산하지는 않습니다.

**시연** (배치 모드)
1. 오른쪽 버튼 + WASD로 카메라를 랙 뒤쪽으로 돌려, 파랑(공급)·빨강(회수) 배관과 위쪽 케이블 트레이를 보여 줍니다.
2. 콘솔에서 `vrg.Patch.Map` → 패치 맵(위에서 본 평면도)이 열립니다.
3. 케이블을 클릭하거나 `←/→`로 하나씩 고르면 노랗게 강조되고, 아래에 "어느 랙의 몇 번 포트 → 스파인 몇 번 포트, 길이 몇 m"가 나옵니다.
4. 위쪽 요약 줄의 "케이블 수 / 미연결 / 포트 중복 / 간섭"을 가리키며 설명합니다.
   - 말할 것: "스파인이 없는 줄은 미연결로, 겹치는 선은 간섭으로 표시됩니다."
5. `Esc`로 닫습니다.

## 8. 기능 4 — 부하·냉각수·공기 통합 반응 (3분)

**멘트**
> 네 번째는 이 프로그램의 핵심입니다. 서버 사용량, 펌프 속도를 바꾸거나 서버 한 칸을 빼면, 칩의 발열, 배관의 물 흐름, 방 안의 공기가 함께 반응합니다.
>
> 정해진 애니메이션을 재생하는 게 아니라, 앞에서 말씀드린 네 모델이 매 순간 계산한 결과입니다. 사용량과 펌프 조절은 모든 랙에 함께 적용되고, 서버 빼기는 바라보는 칸 하나에만 적용됩니다.

**시연**
1. `Enter` → 시뮬레이션 모드로 들어갑니다. 콘솔에서 `vrg.Air.RunSteps 1500`(30초 분량을 빠르게 계산, 약 20초 소요) → 방 안에 온도 색이 채워집니다.
2. 콘솔에서 `vrg.Pipes.Temperature 1` → 랙 배관이 온도 색으로 바뀝니다(파랑 = 차가운 공급수, 빨강 = 데워진 회수수).
3. **부하 낮추기:** `9`를 여러 번 눌러 서버 사용량을 낮춘 뒤 `vrg.Air.RunSteps 1500` → 회수 배관 색과 방 안 빨간 영역이 줄어드는 것을 보여 줍니다. `0`으로 다시 올릴 수 있습니다.
   - 말할 것: "사용량을 낮추니 열이 줄고, 배관 물과 방 공기가 같이 식습니다."
4. **펌프 조절:** `5`를 몇 번 눌러 펌프를 느리게 한 뒤 다시 `vrg.Air.RunSteps 1500` → 물이 덜 흐르니 회수수가 더 뜨거워집니다(`6`으로 원래대로).
5. **서버 빼기:** 랙 앞에 카메라를 가까이 대고 한 칸을 바라본 상태에서 `E` → 그 서버 한 칸이 앞으로 빠지고 열이 사라집니다. 다시 `E`로 꽂습니다.
6. 필요하면 `R`로 처음부터 다시 계산합니다.

> 시연 팁: 온도 변화는 실제 시간 속도로 천천히 일어나서, 조건을 바꾼 뒤 `vrg.Air.RunSteps 1500`으로 30초를 앞당겨야 차이가 잘 보입니다. 수치를 화면에 띄우고 싶으면 `vrg.Hud.Debug 1`(글자가 많아지니 끝나면 `0`).

## 9. 기능 5 — 온도·기류·분기관 표시 (2분)

**멘트**
> 다섯 번째는 계산 결과를 눈으로 보는 기능입니다. 방 안 공기 온도를 3차원 색으로 보여 줍니다. 파란색이 차갑고 빨간색이 뜨겁습니다. 바람이 흐르는 방향을 따라 움직이는 무늬도 보여 주고, 랙으로 들어가고 나오는 배관의 물 온도도 색으로 보여 줍니다.
>
> 흐르는 무늬는 바람 방향을 이해하기 쉽게 만든 표시이지, 실제 공기 입자의 경로는 아닙니다. 배관은 랙 분기관만 온도를 표시하고, 헤더와 펌프는 회색으로 둡니다.

**시연** (시뮬레이션 모드, 앞 장에서 이어서)
1. 오른쪽 버튼 + 마우스로 카메라를 돌리며 온도 볼륨을 관찰합니다. 랙 뒤쪽(배기)이 빨갛고 앞쪽(흡기)이 파란 것을 가리킵니다.
   - 말할 것: "랙 앞은 차가운 공기를 마시고, 뒤로 뜨거운 공기를 내뿜습니다."
2. 콘솔에서 `vrg.Flow.Draw 0` → 기류 무늬가 꺼집니다. `vrg.Flow.Draw 1` → 다시 켜서 무늬가 흐르는 방향을 보여 줍니다.
3. 배관 온도 표시(`vrg.Pipes.Temperature 1` 상태)에서 공급관과 회수관의 색 차이를 보여 줍니다.
4. `vrg.Pipes.Temperature 0` → 기본 표시(공급/회수 구분색)로 돌아갑니다.

## 10. 기능 6 — 저장·가상 센서·평가 리포트 (2분)

**멘트**
> 여섯 번째는 결과를 남기고 비교하는 기능입니다. 배치를 파일로 저장하고 불러올 수 있습니다. 랙 흡기마다 가상 온도계를 두는데, 실제 센서처럼 반응이 조금 늦고 값이 약간 흔들리게 만들었습니다.
>
> 계산 결과는 리포트 파일로 저장하고, 두 조건을 나란히 비교할 수 있습니다. 오른쪽 표가 실제 리포트입니다. 공기 차단막이 없을 때와, 랙 사이 틈을 막고 차가운 통로 위에 지붕을 덮었을 때를 각각 300초 계산해 비교했습니다. 가장 뜨거운 흡기가 31도에서 23.9도로 내려가고, 권장 온도 27도를 넘던 곳이 9곳에서 0곳이 됐습니다.
>
> 표의 부분 PUE는 서버, 공조기 팬, 펌프 전력만 넣은 값입니다. 칠러나 냉각탑, 배전 손실 등이 빠져 있어서 실제 건물 전체의 PUE와는 비교할 수 없습니다. 결과를 웹 화면으로 보는 대시보드는 앞으로 만들 계획입니다.

**시연**
1. 시뮬레이션 모드에서 콘솔 `vrg.Eval.Report demo` → `Saved/Reports/demo.md`가 만들어집니다. 파일 탐색기나 메모장으로 열어 흡기 온도, 전력, 센서 경보, 열 장부 오차 항목을 보여 줍니다.
2. 미리 만든 `Saved/Reports/AB_ppt_a_vs_ppt_b.md`를 열어 A/B 비교 표를 보여 줍니다.
   - 말할 것: "같은 조건에서 차단막 유무만 바꿔 비교한 결과입니다."
3. **배치 저장·복원:** `Enter`로 배치 모드에 돌아와 `vrg.Layout.Save demo` → 랙 하나를 옮기거나 삭제 → `vrg.Layout.Load demo` → 원래 배치로 돌아오는 것을 보여 줍니다.

## 11. 기술·검증 성과 — 화면뿐 아니라 자동화 검사와 열 장부로 검증 (1분 30초)

**멘트**
> 화면이 그럴듯해 보이는 것만으로는 계산이 맞는지 알 수 없습니다. 그래서 두 가지 방법으로 확인했습니다.
>
> 첫째, 자동 검사 222가지입니다. 코드를 고칠 때마다 계산이 이론값과 맞는지, 저장하고 불러와도 결과가 같은지 등을 프로그램이 스스로 다시 확인합니다.
>
> 둘째, 열 장부입니다. 들어온 열이 나간 열과 쌓인 열의 합과 같아야 합니다. 그 오차가 1.27 곱하기 10의 마이너스 14승, 100조분의 1 수준입니다. 계산 도중에 열이 새거나 생기지 않는다는 뜻입니다.
>
> 다만 이 값은 계산이 앞뒤가 맞는다는 뜻이지, 실제 데이터센터 온도와 맞는다는 뜻은 아닙니다. 그건 실측 보정이 필요한 다음 과제입니다.
>
> 마지막으로, 개발 도구 없이 윈도우 실행 파일만으로 배치, 온도 표시, 저장·불러오기까지 동작하는 것을 확인했습니다.

## 예상 질문과 답변

- **"실제 데이터센터와 온도가 맞나요?"**
  아직 실측 보정을 하지 않았습니다. 공개 사양과 일부 가정으로 계산했고, 지금 보장하는 것은 계산이 앞뒤가 맞는다는 것(열 장부 오차 약 10⁻¹⁴)까지입니다. 실측 보정은 다음 과제입니다.
- **"공기 계산은 어떤 방법인가요?"**
  방을 0.25 m 균일 격자로 나눠 비압축 유동을 투영법으로 풉니다. 압력은 멀티그리드 전처리 켤레기울기법으로 풀고, 부력과 Chen-Xu 0-방정식 난류 모델을 넣었습니다. 자세한 식은 4번 슬라이드 발표자 노트에 있습니다.
- **"A/B 비교에서 PUE가 왜 같은가요?"**
  공조기 풍량이 고정이고, 온도 여유만큼 풍량이나 공급 온도를 줄이는 제어가 아직 없습니다. 그래서 차단막의 이득이 흡기 온도로만 나타나고 전력에는 나타나지 않습니다.
- **"A/B 표에서 IT 전력이 왜 조금 다른가요?"**
  온도가 다르면 서버 팬 속도가 달라져 팬 전력이 바뀌기 때문입니다(약 0.2% 차이).
- **"VR은 어디 있나요?"**
  팀 결정으로 HMD(VR 헤드셋) 환경은 구현하지 않고, 데스크톱 화면에서 3D로 조작·관찰하는 형태로 만들었습니다.
- **"왜 옥트리 대신 균일 격자를 쓰나요?"**
  같은 방에서 비교해 보니 랙 주변만 잘게 나눠서는 정확도가 거의 좋아지지 않고 계산은 더 느렸습니다. 그래서 정밀 계산은 GPU 균일 격자로 하고, 옥트리는 실험·검증용으로 남겼습니다.
